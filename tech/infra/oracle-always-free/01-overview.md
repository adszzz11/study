# Overview: What / Why / 특징

> **한 줄 정의**: 정해진 무료 자원 범위 안에서 앱 실행 기반을 제공하는 방식으로 소개된다.

## What

Oracle Always Free의 무료 제공 기간은 문서 발췌상 계정 유지 기간이다. 기간과 자원 한도는 함께 읽어야 한다. 계정 유지 조건과 정책 변경 조건은 자료에 없다.

## Why

앱과 자동화 Workflow를 개인 컴퓨터의 실행 상태와 분리하려는 필요가 출발점이다. 서버 확보 후에도 실행 환경 구성, 배포, 업무 흐름 연결, 외부 접속 확인이 남는다.

## 특징과 미확인 항목

| 항목 | 확인된 내용 | 추가 확인할 내용 |
|---|---|---|
| 무료 범위 | 정해진 자원 범위 | 자원별 한도, 초과 처리 |
| Compute | 영상의 메모리 12GB·2코어 | shape, CPU architecture, CPU 성능, 전체 할당량 |
| Storage | 정보 없음 | 용량, Disk I/O, 백업 범위 |
| Network | 80·443 및 ports 항목 등장 | 트래픽 한도, 과금, 공개 접속 구성 |
| 운영 보장 | 밤새 실행할 서버라는 활용 목적 | SLA, 자원 회수, 가동률 |

Always Free라는 이름은 무제한 사용이나 무중단 운영의 근거가 아니다. 메모리와 코어 수만으로 실행 가능한 앱 개수나 동시 접속자 수를 계산할 수 없다.

## 활용 관계

```text
Oracle 서버 → 실행 환경(Docker) → 배포 관리(Coolify)
                                  → 업무 앱(Twenty) / Workflow(n8n)
                                  → 외부 접속 별도 확인
```

이는 역할을 설명하는 개념도다. 모든 도구가 동일 서버에서 동시에 안정적으로 실행되었다는 검증된 배포 구조가 아니다.

## 접속 검증의 경계

영상 마지막에는 접속 실패 화면과 80·443, ports 설정 항목이 등장한다. 특정 Firewall, 앱 설정, TLS 문제로 원인을 확정할 수 없다. 포트 표시만으로 HTTP·HTTPS가 정상 제공되었다고 판단할 수도 없다.
