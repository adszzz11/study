## 제공 자료

| 자료 | 뒷받침하는 내용 | 제한 |
|---|---|---|
| dossier의 문서 발췌 요약 | 계정 유지 기간 동안 정해진 범위에서 무료 | 원문·정책 기준일·세부 조건 없음 |
| dossier의 영상 요약 | 12GB·2코어, Docker·Coolify·Twenty·n8n 등장 | 원본 URL·측정 결과·실제 비용 내역 없음 |
| 영상 마지막 장면의 설명 | 접속 실패와 80·443, ports 항목 등장 | 접속 실패 원인과 해결 결과 불명 |

## 인용·해석 원칙

- 12GB·2코어는 **영상에서 소개한 구성**으로 표현한다.
- 전체 무료 한도, CPU architecture, Storage, Network 수치를 추정하지 않는다.
- 운영 사례와 성능 검증을 구분한다. 동시 안정 실행은 확인되지 않았다.
- 외부 자료로 최신 정책을 검증한 것으로 표현하지 않는다.

## 후속 확인 목록

- [ ] 원문 URL과 영상 제목·게시일·관련 시점 확보
- [ ] 실제 이용 시점의 공식 무료 한도와 계정 유지 조건 확인
- [ ] 개별 인스턴스 사양과 계정 전체 할당량 구분
- [ ] 초과 과금, 자원 회수, SLA, 백업·트래픽 조건 확인
- [ ] 공식 문서 URL 및 열람일과 실제 환경의 측정 기록 보관

원문 URL이 제공되지 않아 URL 목록을 만들 수 없다. 확인되지 않은 주소를 출처로 대체하지 않는다.
