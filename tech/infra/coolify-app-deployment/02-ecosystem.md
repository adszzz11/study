# Ecosystem: 역할 중심 비교

## 비교 범위

자료에는 직접적인 경쟁 배포 플랫폼이 없다. 아래 표는 기능·가격·성능 순위가 아니라 등장 도구가 담당하는 문제를 비교한다.

| 대상 | 주된 역할 | Coolify와의 관계 | 자료로 가능한 판단 |
|---|---|---|---|
| Oracle Always Free | 서버 자원 제공 | 배포 실행 환경 | 서버 확보와 배포는 별도 문제 |
| 터미널·Docker | Docker 학습·활용 | 인접한 실습 영역 | 수동 배포와의 작업량 비교 불가 |
| Coolify | 앱·대학 프로젝트 배포 | 학습 대상 | 활용 사례는 확인, 세부 기능 비교 불가 |
| Twenty | 고객 관리 | 다른 서버 활용 예시 | 배포 도구의 직접 대안이 아님 |
| n8n | 문의 자동 응답 | 다른 서버 활용 예시 | 자동화 활용에 초점 |
| 다른 배포 서비스 | 자료에 등장하지 않음 | 비교 대상 미확보 | 제품별 우열·비용 비교 불가 |

## 선택에 적용하기

자료가 뒷받침하는 경로는 “Always Free 서버 확보 후 Coolify로 프로젝트 배포 시도”다. 다른 선택지보다 우수하다는 결론은 내릴 수 없다.

추가 비교가 필요하면 실제 사용하려는 버전에 대해 다음 항목을 조사한다.

- 서버·배포·접속 설정 중 사용자가 직접 관리할 범위.
- 필요한 배포 방식과 지원 여부, 장애 복구 방법.
- 자원 사용량, 무료 범위, 범위 초과 시 비용.
- 동일한 앱과 조건에서의 배포 결과 및 운영 부담.

위 항목은 후속 조사 계획이며 확인된 Coolify 기능 목록이 아니다.
