# References: 근거와 확인 대기 항목

## 제공 자료

| 자료 | 확보 상태 | 사용 범위 |
|---|---|---|
| 사용자 제공 dossier | 본문 제공 | 모든 노트의 직접 근거 |
| 원본 영상 | 요약만 제공, URL 없음 | 직접 재생·화면 검증 불가 |
| 영상에 표시된 Always Free 문서 | 발췌 요약만 제공 | 현재 정책·전체 조건 검증 불가 |
| Coolify 공식 문서 | 제공되지 않음 | 설치·기능·버전 동작 확정 불가 |

## 근거 수준 구분

- **요약에서 확인:** Coolify 앱·대학 프로젝트 배포 활용, 메모리 12GB·코어 2개 제시, 외부 접속 실패 화면 및 80·443 표시.
- **자료에서 확장한 학습 제안:** 배포·접속 분리 검증, 장애 기록 양식, 운영 구성 검토 프로젝트.
- **미확인:** 실제 접속 실패 원인, 할당 가능 자원, 전체 비용, 내부 아키텍처, 성능, 동시 운영 구성.

## 추가 자료 확보 체크리스트

- [ ] 원본 영상 URL·제목·게시일과 관련 장면의 시각 기록.
- [ ] 현재 Oracle Always Free 공식 정책 URL과 확인일 기록.
- [ ] 사용 버전에 맞는 Coolify 공식 설치·배포 문서 URL 기록.
- [ ] 네트워크와 접속 설정에 관한 공식 문서 URL 기록.
- [ ] 각 주장의 출처 위치와 직접 확인한 결과 구분.

URL을 추정하거나 미열람 문서를 근거로 인용하지 않는다. 아래 양식은 실제 자료 확보 후 채운다.

```text
자료 제목:
URL:
게시일 / 확인일:
대상 제품·버전:
주장을 뒷받침하는 위치:
직접 확인한 내용:
남은 불확실성:
```
