# References

## 원본 자료 상태

제공 dossier에는 영상과 문서 발췌의 원본 URL이 없다. 영상 제목·제작자·게시일도 제공되지 않았으므로 임의로 채우지 않는다. 아래 URL은 후속 학습용 공식 문서이며 원본 영상 출처가 아니다.

## 확인할 자료

| 공식 자료 | 확인 과제 |
|---|---|
| Docker Docs | 환경별 설치, 실행 절차, image/container 및 저장·네트워크 개념 |
| Oracle Always Free 문서 | 현재 무료 자원 범위, 조건, 실제 계정의 할당 상태 |
| Coolify Docs | 선택한 앱의 배포 절차와 실제 Docker 연결 구성 |
| Twenty Docs | 고객 관리 시범에 필요한 구성과 데이터 관리 |
| n8n Docs | 문의 응답 흐름의 입력·처리·출력 설정 |

문서의 최신 내용과 자신의 환경을 대조한 뒤 확인 날짜와 적용 조건을 실습 기록에 남긴다. 공식 URL을 나열한 것만으로 해당 절차를 검증한 것은 아니다.

## 근거 구분

- **자료 사실:** dossier에 명시된 사양, 도구 역할, 접속 실패 장면.
- **미확인:** 할당 조건, 실제 설치 구조, 실패 원인, 해결 여부.
- **추가 검증:** 공식 문서를 바탕으로 직접 실행해 관찰한 결과.
