# References와 검증 기록

> 이 노트는 제공된 dossier와 기존 지식에 기반한 초안이다. 제품 기능·구현·지원 범위는 **확인 필요**이며, 최신 버전·운영 상태·성능 수치를 주장하지 않는다.

## 근거 상태

제공된 수집 자료와 URL은 없다. 이 묶음은 dossier를 구조화한 학습 초안이며 외부 검색·URL 열기를 수행하지 않았다. 공식 문서 URL은 후속 확인의 출발점일 뿐이다.

## 확인할 자료와 질문

| 우선순위 | 확인 대상 | 남길 근거 |
|---|---|---|
| 1 | 사용할 버전의 설치·라이선스·실행 방식 | 버전, 문서 URL, 확인일 |
| 2 | 지원 Engine Adapter와 설정 구조 | 해당 버전 문서·소스 위치 |
| 3 | timeout·동시성·부분 실패 | 설정 정의와 관찰 결과 |
| 4 | 중복 제거·가중치·정렬 | 소스·테스트 또는 문서의 설명 |
| 5 | 로그·쿠키·헤더·접근 제어 | 기본값과 배포 환경의 실제 동작 |
| 6 | 구조화 출력·API 사용 | 활성화 조건, 필드, 외부 이용 조건 |

## 기록 양식

```text
검증 항목:
사용 버전 / 배포 방식:
문서 URL / 소스 revision:
확인일:
문서상 설명:
실제 관찰:
판정 및 남은 불확실성:
```

검증 후에는 해당 주장 옆에 근거를 연결한다. 배포 환경의 관찰을 모든 Instance의 기본 동작으로 일반화하지 않는다.
