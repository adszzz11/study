# SearXNG Cheatsheet

> 이 노트는 제공된 dossier와 기존 지식에 기반한 초안이다. 제품 기능·구현·지원 범위는 **확인 필요**이며, 최신 버전·운영 상태·성능 수치를 주장하지 않는다.

## 빠른 판단

| 질문 | 기억할 점 |
|---|---|
| 자체 검색 인덱스인가? | 외부 결과 통합 계층으로 이해하되 실제 범위 확인 |
| Self-hosting이면 독립적인가? | 외부 엔진의 정책·차단·장애에 여전히 영향받음 |
| 익명성이 보장되는가? | 질의 내용·Proxy·앱·네트워크 전체를 점검 |
| 엔진이 많을수록 좋은가? | 유용한 결과·지연·실패·요청량을 함께 평가 |
| 사내 문서 검색을 해결하는가? | 수집·권한·인덱싱을 별도로 설계 |
| AI 답변 근거로 충분한가? | snippet 이후 원문 수집·검증 필요 |

## 배포·연동 전 체크

- [ ] 버전·라이선스·설치 방식·지원 엔진 확인
- [ ] 소수 엔진으로 대표 질의 평가
- [ ] timeout·동시성·부분 실패 동작 확인
- [ ] 인증·접근 범위·Rate Limiting 제공 계층 확인
- [ ] Proxy·앱·모니터링 로그와 보존 정책 확인
- [ ] 구조화 출력 지원·활성화 조건·필드 확인
- [ ] 외부 엔진 및 원문 수집 이용 조건 확인

## 증상별 조사 방향

| 증상 | 먼저 확인할 것 |
|---|---|
| 검색 지연 | 엔진별 응답·timeout·대기 정책 |
| 일부 결과 누락 | 소스 실패·차단·지원 상태·파싱 변경 |
| 중복 결과 | URL 변형·추적 파라미터·실제 통합 규칙 |
| 프로그램 연동 실패 | 출력 형식 지원·허용 설정·응답 필드 |
| 민감한 질의 기록 | Proxy 접근 로그·앱 로그·모니터링 |

검증되지 않은 설치 명령이나 설정 키는 이 Cheatsheet에 포함하지 않는다.
