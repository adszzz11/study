# Ecosystem과 대안 비교

> 이 노트는 제공된 dossier와 기존 지식에 기반한 초안이다. 제품 기능·구현·지원 범위는 **확인 필요**이며, 최신 버전·운영 상태·성능 수치를 주장하지 않는다.

## 접근 방식 비교

현재 기능·라이선스·지원 상태의 비교가 아니라 검색 기반과 운영 책임의 비교다.

| 접근 / 대안 | 검색 기반 | 통제 범위 | 적합한 상황 | 주요 부담 |
|---|---|---|---|---|
| SearXNG | 외부 엔진 결과 통합 | Instance·검색 소스 구성 | 검색 창구 통합 | 외부 의존·Adapter 유지보수 |
| Searx | 유사한 Metasearch 계열 | 자체 운영 구성 | 계보·설계 비교 | 차이와 현재 상태 확인 필요 |
| 검색 엔진 직접 이용 | 해당 서비스 인덱스 | 서비스 제공 설정 | 간단한 일반 검색 | 통합·정책 통제 제한 |
| 상용 Search API | 공급자 검색 데이터 | API 사용·후처리 | 계약·문서화된 연동 | 비용·쿼터·이용 조건 |
| YaCy 같은 자체 검색 시스템 | 자체 크롤링·인덱싱 계열 | 수집·인덱스·검색 | 검색 데이터 자체 운영 | 수집 범위·인덱스 유지 |
| OpenSearch / Elasticsearch | 직접 적재한 데이터 | 문서·인덱스·검색 로직 | 사내 문서·특정 corpus | 데이터 확보·수집 별도 설계 |

## 선택 질문

1. **외부 웹 검색 결과 통합인가?** Metasearch와 Search API를 검토한다.
2. **보유 문서 검색인가?** 수집·권한·인덱싱을 중심으로 설계한다.
3. **독립 웹 인덱스인가?** 크롤링과 인덱스 유지 비용을 별도로 산정한다.

SearXNG를 사내 문서 검색의 완성형 대안으로 간주하면 권한 관리와 데이터 수집 과제를 놓칠 수 있다. API 계약이 필요한 경우에도 외부 엔진 자동화 이용 조건을 별도로 검토한다.
