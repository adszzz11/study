# 시작하기: 작은 검색 실험

> 이 노트는 제공된 dossier와 기존 지식에 기반한 초안이다. 제품 기능·구현·지원 범위는 **확인 필요**이며, 최신 버전·운영 상태·성능 수치를 주장하지 않는다.

## 준비

설치 명령·설정 키는 검증 자료가 없으므로 제공하지 않는다. 사용할 버전의 공식 설치 문서와 라이선스·지원 엔진을 먼저 확인한다. 초기 실험은 접근 범위가 제한된 환경을 기준으로 계획한다.

## 실습 순서

- [ ] 버전·실행 방식·설정 파일 위치·지원 엔진을 기록한다.
- [ ] 소수 엔진으로 시작해 엔진별 결과와 통합 결과를 비교한다.
- [ ] 아래 질의 유형별로 실제 유용한 상위 문서를 표시한다.
- [ ] 통제 가능한 환경에서 일부 소스 실패와 timeout 영향을 관찰한다.
- [ ] 브라우저·Proxy·앱·외부 엔진의 질의 저장 경로를 점검한다.
- [ ] 구조화 출력의 지원 여부·활성화 조건·응답 필드를 확인한 뒤 프로그램 연동을 시도한다.

| 질의 유형 | 예시 | 평가 질문 |
|---|---|---|
| 한국어 | 리버스 프록시 접근 로그 설정 | 한국어 자료가 유용한가? |
| 정확한 기술 용어 | HTTP cache-control stale-while-revalidate | 공식 문서가 상위에 오는가? |
| 긴 질문 | 여러 검색 소스 중 하나가 실패하면 어떻게 처리하는가 | 질문 의도와 결과가 맞는가? |
| 특정 사이트 탐색 | 공식 문서 사이트에서 timeout 문서 찾기 | 목표 문서에 도달하는가? |

## 관찰 기록

```text
질의 / 언어 / 지역 / 실행 시점:
Instance 버전 / 엔진 조합:
유용한 상위 결과와 이유:
중복 URL / 실패 엔진:
응답 시간 및 측정 범위:
질의가 남는 위치:
```

## 완료 기준

대표 질의에서 필요한 문서를 찾고, 일부 소스 실패 시 결과를 설명하며, 질의 저장 경로를 추적할 수 있다. JSON 등의 출력 지원과 기본 활성화 상태는 **확인 필요**다.
