## 증거 수준별 읽기

1. **소개 확인:** CRM(00:48), 성과 대시보드(00:53), 지식 그래프, 사전 구성 에이전트, 부서별 조직도. 시점은 제공 요약에 근거한다.
2. **구상:** 여러 AI 클라이언트가 하나의 메모리를 공유한다.
3. **설계 제안:** Lead → CRM → Outreach → 응답 → 집계, 지표 계층, ID 모델, 아래 실습들.
4. **미확인:** 실제 실행·데이터 연동·지표 정의·정확성·성과 개선.

## 후속 검증 질문

- 원본 영상 URL과 제품 공식 문서·버전은 무엇인가?
- Lead 생성부터 CRM 반영까지 동일 ID로 추적하는 실행 시연이 있는가?
- 발송 성공과 실제 고객 응답은 어떤 이벤트로 기록되는가?
- 지표의 기간, 분모, 중복 제거, 실패·재시도 처리 규칙이 공개되어 있는가?
- 부서 이동·공동 기여는 어떻게 집계하고, 원본 근거로 이동할 수 있는가?
- Shared Memory의 데이터 모델·동기화·접근 권한은 무엇인가?

원본 자료를 확보하기 전에는 추정한 URL이나 제품 기술스택을 채워 넣지 않는다.
