# Overview: 음성 처리와 기록 저장

## What

SQLite는 애플리케이션에 내장해 사용하는 SQL database engine이다. 이 노트에서 SQLite의 역할은 음성 인식이 생성한 기록을 기기에 영속 보관하는 것이다. 음성을 텍스트로 변환하는 역할은 음성 인식·Whisper가 담당한다.

## Why

받아쓰기 화면의 현재 텍스트와 앱을 종료한 뒤 남는 기록은 다르다. 중간 결과는 수정될 수 있으므로 무엇을 하나의 확정 기록으로 남길지 별도로 정의해야 한다. 자료는 Sokki가 최종 결과만 저장하는지, 중간 결과와 시간 정보도 저장하는지 설명하지 않는다.

## 특징과 확인 범위

| 요소 | 확인되는 역할 | 미확인 항목 |
|---|---|---|
| 음성 인식·Whisper | 기기 내 음성 처리 | 모델 버전, 실행 방식, 성능 |
| 받아쓰기 오버레이 | 파형·경과 시간·한국어 텍스트 표시 | 표시 항목과 저장 항목의 일치 여부 |
| 로컬 SQLite | 기록 저장 | schema, 파일 경로, 검색·수정·삭제 기능 |
| 오디오 처리 경계 | Mac 밖으로 나가지 않는다고 설명 | 오디오 파일 보관 여부와 기간 |

## 세 가지 경계

- **처리 경계**: 기기 내 연산이라는 설명이다. 모든 기능의 offline 동작을 입증하지 않는다.
- **저장 경계**: SQLite라는 기술과 로컬이라는 위치를 나타낸다. 저장 범위와 보관 기간은 별도다.
- **전송 경계**: 외부 전송이 없다는 설명의 대상은 오디오다. 인식 텍스트·진단 정보·백업의 취급은 미확인이다.

Obsidian 노트 작업 화면과 ChatGPT Work 화면이 영상 배경에 등장한다. 이는 공식 연동이나 두 제품으로의 데이터 전송을 입증하지 않는다.
