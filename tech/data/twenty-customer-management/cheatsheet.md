# Cheatsheet: Twenty 고객 관리 학습 점검표

## 빠른 구분

| 확인 사실 | 단정하면 안 되는 내용 |
|---|---|
| Twenty가 고객 관리로 소개됨 | 세부 기능·API·권한·저장 방식 |
| Coolify가 앱 배포로 소개됨 | Twenty를 Coolify로 배포했다는 주장 |
| n8n이 문의 자동 응답으로 소개됨 | Twenty와 직접 연결되었다는 주장 |
| 영상상 메모리 12GB·2코어 | 현재 무료 조건·Twenty 권장 사양 |
| 접속 실패와 포트 설정 등장 | 확정 장애 원인·해결 완료 |

## 검증 체크리스트

- [ ] 가상 고객으로 필요한 작업을 정의했다.
- [ ] 기능별 가능·불가·미확인 근거가 있다.
- [ ] 서버 실행과 외부 접속 결과를 따로 기록했다.
- [ ] 연동 수단과 고객 식별 기준을 확인했다.
- [ ] 누락·중복·실패 처리를 시험했다.
- [ ] 도구별 CPU·메모리와 응답 상태를 측정했다.
- [ ] 접근 권한과 백업 복원을 검증했다.
- [ ] 재시작·업데이트 이후 업무 상태를 확인했다.

## 판단 규칙

```text
함께 등장함 ≠ 직접 연동됨
서버 실행 중 ≠ 웹앱 외부 접근 가능
영상의 자원 수치 ≠ 현재 제공 조건 또는 권장 사양
기능 미확인 ≠ 기능 없음
```
