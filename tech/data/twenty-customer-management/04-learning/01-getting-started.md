# 시작하기: 고객 관리 최소 검증

## 목표와 준비

실제 고객 대신 가상 데이터를 사용해 필요한 업무와 Twenty의 지원 범위를 대조한다. 이 자료에는 설치 명령이나 검증된 배포 구성이 없으므로 설치 단계는 공식 안내를 확인한 후 별도로 정한다.

## 실습 순서

1. 고객 식별, 정보 수정, 문의 확인 등 필요한 작업을 정의한다.
2. 각 작업의 입력과 기대 결과를 적는다.
3. Twenty의 공식 안내와 실습 환경에서 지원 여부를 확인한다.
4. 결과를 가능·불가·미확인으로 기록하고 근거를 붙인다.
5. 필요한 기능이 확인된 뒤 접속·운영·자동화 검증으로 진행한다.

가상 입력 예시이며 Twenty의 실제 schema 또는 import 형식이 아니다.

```json
{"test_customer_id":"demo-001","display_name":"가상 고객 A","inquiry":"이용 시간 문의"}
```

| 요구사항 | 기대 결과 | 판정 | 근거 |
|---|---|---|---|
| 고객 식별 | 동일 고객을 구분 | 미확인 | 실습 후 작성 |
| 정보 수정 | 수정된 값 확인 | 미확인 | 실습 후 작성 |
| 문의 확인 | 대상 고객과 문의 확인 | 미확인 | 실습 후 작성 |

## 완료 기준

- [ ] 필요한 작업마다 판정과 근거를 남겼다.
- [ ] 지원하지 않는 작업과 아직 시험하지 않은 작업을 구분했다.
- [ ] 다음 실습에 필요한 기능 공백을 정리했다.
