# Overview: Twenty의 역할과 운영 맥락

## What

Twenty는 제공 영상에서 고객 관리 용도로 소개된 도구다. 고객 정보 등록, 상담 이력, 영업 단계 관리 등의 지원 범위는 자료에서 설명하지 않는다.

## Why

밤새 켜 둘 서버가 있으면 개인 컴퓨터와 별개로 앱과 자동화 도구를 운영하는 시도를 할 수 있다. 영상은 Docker 터미널 실습, Coolify 앱·대학 프로젝트 배포, Twenty 고객 관리, n8n 문의 자동 응답을 그 사용처로 제시한다.

## 특징과 아키텍처

```text
상시 가동 서버 환경
  → 앱 운영 사례로서의 고객 관리
  → 웹앱 접근 설정 점검
```

이는 활용 맥락을 요약한 흐름이며 검증된 배포 토폴로지가 아니다.

| 관점 | 확인된 내용 | 남은 검증 |
|---|---|---|
| 업무 | Twenty 고객 관리, n8n 문의 자동 응답 | 데이터 교환 여부와 고객 식별 방식 |
| 기반 | Oracle Always Free 소개 | 현재 조건·가용성·운영 보장 |
| 자원 | 영상상 메모리 12GB·2코어 | Twenty 권장 사양·동시 운영 수용량 |
| 접속 | 접속 실패 화면, 80·443 및 ports 설정 등장 | 장애 계층·해결 결과 |

**Coolify로 Twenty를 배포하고 n8n이 고객 데이터를 조회한다**는 구성은 확인되지 않은 설계 후보다. 데이터 구조, API, 권한, 저장 방식도 확인되지 않았다.

## 도입 판단 질문

- 고객 정보를 어떤 단위로 저장·검색할 수 있는가?
- 고객 정보와 문의 처리 과정을 연결할 수 있는가?
- 열람·수정 권한을 어떻게 제한하는가?
- 백업을 복원하고 재시작·업데이트 이후 업무를 이어갈 수 있는가?

위 질문은 검증 항목이며 지원 기능 목록이 아니다.
