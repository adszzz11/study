# Ecosystem: 함께 등장한 도구의 역할 비교

## 비교 범위

자료에 직접 비교할 다른 고객 관리 제품은 없다. 아래는 경쟁 제품 비교가 아니라 역할 비교다.

| 도구·환경 | 영상에서의 역할 | 고객 관리와의 관계 | Twenty 대안 여부 |
|---|---|---|---|
| Twenty | 고객 관리 | 중심 업무 도구 | 비교 기준 |
| n8n | 문의 자동 응답 | 고객 대응 자동화의 인접 영역 | 대체 관계 확인 불가 |
| Coolify | 앱·대학 프로젝트 배포 | 배포 영역 | 역할이 다름 |
| Docker | 터미널 실습 | 실행 환경 학습 소재 | 역할이 다름 |
| Oracle Always Free | 상시 서버 자원 | 운영 기반 | 역할이 다름 |

## 선택 기준

- 고객 관리 기능은 필요한 업무 목록을 만들고 Twenty에서 검증한다.
- 자동화는 문의 입력·출력과 실패 처리를 정의한 뒤 검토한다.
- 배포 도구와 서버는 배포 지원 여부, 현재 제공 조건, 실제 부하를 따로 확인한다.

자료만으로 경쟁 우위, 비용, 기능 범위, 도입 난이도 순위를 매길 수 없다. 함께 등장했다는 사실은 호환성이나 연동 완료의 증거가 아니다.
