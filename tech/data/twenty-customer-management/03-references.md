# References: 근거와 추가 확인 경로

## 제공 자료의 범위

근거는 사용자가 제공한 dossier의 영상 요약과 시간 표기 **00:25, 00:30**이다. 원본 제목·게시일·URL이 없어 원문 대조가 불가능하다. 개별 주장에 정확한 타임스탬프를 임의로 배정하지 않는다.

## 근거 기록 방법

공식 문서의 URL·확인일·버전·실험 결과를 함께 남긴다. 문서상 지원과 실제 환경에서의 성공은 구분한다. 특히 12GB·2코어는 영상상 조건으로만 인용한다.
