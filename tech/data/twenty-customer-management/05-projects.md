| 프로젝트 | 구현·검증 범위 | 완료 기준 |
|---|---|---|

## 권장 순서

고객 관리 최소 실습을 먼저 수행한다. 필요한 기능이 확인되어야 자동 응답에 전달할 정보를 결정할 수 있다. 접속 점검과 n8n 독립 실습을 거쳐 통합 가능성을 검증한다. 연결 수단이 확인되지 않으면 통합 결과물은 구현물이 아닌 가능성 검토서다.

## 결과 기록 양식

```text
목표 / 환경·버전 / 확인일:
가상 입력 / 기대 결과:
관측 결과 / 로그·문서 근거:
판정: 가능 | 불가 | 미확인
남은 제약 / 다음 검증:
```

실제 고객 데이터 사용 전에는 접근 권한, 백업·복원, 재시작·업데이트 이후의 업무 연속성을 추가로 검증한다.
