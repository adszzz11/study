# References: 근거와 후속 확인

## 제공 자료

사용자 제공 dossier가 이 노트의 직접 근거다. 원본 영상 URL·게시일·타임스탬프는 제공되지 않았다. 출처 주소를 추정하거나 영상의 실제 구현을 재현했다고 주장하지 않는다.

| 확인할 주장 | 현재 근거 | 추가로 필요한 자료 |
|---|---|---|
| n8n 문의 자동 응답 | 수집 요약 | 실제 Workflow, 입력·응답 예시 |
| 12GB·2코어 소개 | 수집 요약 | 당시 조건, 현재 배정 조건 |
| Always Free 무료 범위 | 화면 문서 발췌 요약 | 현재 공식 약관·자원 범위 |
| 도구 간 연결 | 근거 없음 | 구성 파일·연동 설정·실행 기록 |
| 접속 실패 원인 | 실패 화면·ports 단서 | 로그·네트워크 경로·재현 결과 |

## 후속 문서 읽기

다음 URL은 공식 확인 출발점이다. 영상에서 실제로 사용한 구성이나 현재 가격을 확인했다는 의미는 아니다.

- n8n: https://docs.n8n.io/ — Workflow, Trigger, 실행 및 운영 방식.
- Oracle: https://www.oracle.com/cloud/free/ — Free Tier 범위와 제한.
- Docker: https://docs.docker.com/ — Container 실행과 Port publishing.
- Coolify: https://coolify.io/docs/ — 배포와 접속 설정.
- Twenty: https://docs.twenty.com/ — 고객 데이터와 연계 가능성.

## 기록 원칙

문서를 읽은 뒤 확인 날짜, 제품 버전, 적용 환경, 확인한 항목을 남긴다. 개인정보·Credential·Token을 공개 vault에 넣지 않는다. 원본 URL이 확보되면 영상 주장과 공식 문서의 설명을 구분해 보완한다.

## Sources

- 사용자 제공 dossier: 영상 수집 요약. 원본 영상 URL은 제공되지 않아 원문 대조가 불가능하다.
- n8n 공식 문서: https://docs.n8n.io/ — 후속 확인용이며 영상 구현의 증거는 아니다.
- Oracle Free Tier 공식 안내: https://www.oracle.com/cloud/free/ — 현재 조건을 별도로 확인할 자료다.
