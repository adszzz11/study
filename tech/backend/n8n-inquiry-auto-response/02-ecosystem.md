# Ecosystem: 역할 비교

## 비교 범위

자료에 직접 경쟁 제품은 없다. 아래 표는 성능·가격 순위가 아니라 인프라, 배포, 고객 관리, 자동화의 역할 분화다.

| 도구·서비스 | 자료상 역할 | 문의 자동 응답과의 관계 | 주의점 |
|---|---|---|---|
| n8n | 문의 자동 응답 | 중심 도구 | 구체 구현 미제시 |
| Twenty | 고객 관리 | 관련 업무 영역 | 자동 응답 대체재로 제시되지 않음 |
| Coolify | 앱 배포 | 운영 환경 | n8n 관리 여부 미확인 |
| Docker | 서버 실습 | 실행 환경 학습 | 실제 서비스 구성 미확인 |
| Oracle Always Free | 서버 자원 | 상시 운영 기반 선택지 | 영상 사양을 현재 조건으로 일반화 금지 |

## 선택을 위한 질문

- 자동화에 필요한 입력·분기·전달 기능을 실제로 지원하는가?
- 서버 자원과 운영 부담이 요구 조건에 맞는가?
- 고객 관리 시스템과 연결해야 할 정보가 실제로 있는가?
- 무료 자원의 범위와 확보 조건을 현재 공식 안내에서 확인했는가?

특정 조합의 우수성이나 필수성을 판단할 근거는 없다. 도구 연동은 실제 설정과 실행 결과가 확인된 뒤 기록한다.
