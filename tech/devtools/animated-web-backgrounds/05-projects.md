# Projects: 검증을 위한 실전 제안

## 범위

아래는 학습 프로젝트이며 threeui의 지원 기능을 뜻하지 않는다. 지금 바로 완료할 수 있는 것은 명세와 평가 계획이다. 구현과 도구 비교는 실제 복사 내용이나 코드 확보 후 진행한다.

| 프로젝트 | 실행 내용 | 산출물·완료 기준 | 선행 조건 |
|---|---|---|---|
| 배경 효과 명세 | 사실·미확인·원하는 움직임 분리 | 관찰과 요구사항이 구분된 명세 | dossier |
| 최소 통합 prototype | 제목·본문·버튼 화면에 적용 | 실행 절차·dependency·동작 기록 | 실제 구현 자료와 사용 조건 |
| AI 코딩 도구 비교 | 같은 입력·요구사항을 두 도구에 제공 | 실행 가능성·수정량·충족 여부 비교 | payload·시작 환경 확보 |
| 사용성 검증 | 정적·애니메이션 배경의 표시와 입력 비교 | 가독성·상호작용·움직임 제어 기록 | 실행 가능한 prototype |

## 권장 진행 순서

1. 명세에서 미확인 항목과 증거 확보 방법을 적는다.
2. 전달 형식과 실행 환경을 확인하고 최소 통합을 재현한다.
3. 도구별 결과를 같은 평가 기준으로 기록한다.
4. 정적 배경과 비교해 동작·가독성 문제와 미해결 항목을 남긴다.

## 완료 판정

테스트하지 않은 항목은 `미실행`, 근거가 없는 항목은 `미확인`으로 표시한다. 명세 프로젝트의 완료가 구현 성공을 뜻하지 않으며, 한 환경에서의 성공이 production 적합성을 보장하지 않는다.
