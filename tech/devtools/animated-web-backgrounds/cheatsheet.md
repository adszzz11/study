# Cheatsheet: 확인 범위 빠르게 점검하기

## 현재 알 수 있는 것

- 탐색 접점: threeui browse 화면과 디자인 예시·에셋 카드.
- 적용 주제: 애니메이션 배경 언급. 구체적인 효과·구현 방식은 미확인.
- 연계 도구: Codex·Claude Code에 붙여넣기 안내. 입력 형식은 미확인.
- 기술 판단: framework·rendering engine·dependency·성능·접근성 지원 확정 불가.

## 빠른 판단표

| 질문 | 현재 답 | 다음 행동 |
|---|---|---|
| 무엇을 복사하는가? | 미확인 | payload 원문 확보 |
| 무엇으로 렌더링하는가? | 미확인 | 코드·공식 안내 확인 |
| 바로 설치할 수 있는가? | 절차 근거 없음 | 전달 형식과 환경 확인 |
| 라이선스·가격은? | 미확인 | 최신 공식 조건 확보 |
| 두 코딩 도구 결과는 같은가? | 확인되지 않음 | 같은 입력으로 실행 비교 |
| 성능·접근성이 보장되는가? | 근거 없음 | prototype에서 검증 |

## 실행 전후 체크

- [ ] 관찰 사실과 요구사항을 분리한다.
- [ ] 복사 내용·출처·사용 조건을 확인한다.
- [ ] 실행 환경·dependency·수정 내용을 기록한다.
- [ ] 가독성·클릭·keyboard focus를 비교한다.
- [ ] viewport·reduced motion·성능·browser 동작을 검토한다.
- [ ] 미실행과 미확인을 성공 결과와 구분한다.

## 피해야 할 추정

이름만으로 Three.js·WebGL·Canvas·CSS animation을 지정하지 않는다. 모든 예시를 배경으로 분류하거나, 개발 시간 단축·사용성 개선·production 적합성을 단정하지 않는다.
