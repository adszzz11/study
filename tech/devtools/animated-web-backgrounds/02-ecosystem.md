# Ecosystem: 역할과 검증 범위 비교

## 비교 기준

직접적인 경쟁 서비스가 자료에 제시되지 않았다. 아래 표는 제품 순위가 아니라 흐름 안의 역할을 비교한다.

| 대상 | 자료에서의 역할 | 배경과의 연결 | 비교의 한계 |
|---|---|---|---|
| threeui | 디자인 예시·에셋 탐색 접점 | 소개 중 배경 효과 언급 | 제공 형식·구현 기술 미확인 |
| Codex | 붙여넣기 활용 대상으로 언급 | 후속 구현에 활용하려는 흐름으로 해석 가능 | 실제 입력·생성 결과 미확인 |
| Claude Code | Codex와 함께 언급된 코딩 도구 | 동일 안내 맥락 | 도구별 절차·품질 차이 미확인 |
| 다른 서비스·직접 구현 | 자료에 제시되지 않음 | 비교 근거 없음 | 경쟁력·비용·성능 순위 판단 불가 |

threeui와 두 코딩 도구는 각각 탐색 접점과 후속 코딩 도구로 등장하므로 직접적인 경쟁 제품으로 취급하지 않는다.

## 후속 비교 설계

실제 입력을 확보한 뒤 동일한 요구사항, 시작 코드, dependency 제약을 기록한다. 도구별 버전·실행 환경·수정 횟수·실행 성공 여부를 남긴다. 단일 실행 결과를 일반적인 품질 우열로 확대하지 않는다. 비용·라이선스 비교는 별도의 최신 공식 자료가 필요하다.
