# References: 출처와 근거의 한계

## 자료 목록

| 자료 | 확인 범위 | 한계 |
|---|---|---|
| https://threeui.com/browse | dossier가 지목한 디자인 탐색 화면 | 현재 사이트의 기능·제공 형식은 직접 검증하지 않음 |
| 사용자 제공 dossier | 영상의 디자인 예시, 약 00:11 배경 언급, 붙여넣기 안내 요약 | 원본 영상 URL·복사 내용·실행 결과 없음 |

## 출처 읽기 원칙

- 화면의 존재, 안내 문구, 실제 실행 결과를 각각 별도의 증거로 기록한다.
- 웹페이지 URL이 있다고 해서 원본 영상 관찰이나 현재 지원 기능 전체가 검증된 것은 아니다.
- source code나 prompt가 확보되면 원문, 확보 날짜, 출처, 사용 조건을 함께 기록한다.
- 공식 문서가 확보되기 전에는 설치 명령, framework 지원, 가격·라이선스를 채워 넣지 않는다.

## 추가로 필요한 자료

- 원본 영상과 정확한 장면 위치.
- 실제 복사 payload 및 그 형식.
- dependency·실행 방법·라이선스에 관한 공식 안내.
- 실행 환경과 화면·성능·접근성 검증 기록.
