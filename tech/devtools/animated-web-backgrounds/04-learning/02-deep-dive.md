# 심화: 통합과 실행 검증 설계

## 전제

실제 복사 내용·구현물·실행 안내를 확보한 다음 수행하는 학습 제안이다. 현재 자료는 아래 기능의 지원 여부나 테스트 통과를 보여주지 않는다.

## 전달 계약과 통합 경로

| 확보한 형식 | 다음 확인 | 진행 조건 |
|---|---|---|
| source code | 파일 구조·dependency·실행 환경·사용 조건 | 실행 절차를 재현할 근거 확보 |
| prompt | 요구사항·출력 형식·대상 환경 | 생성 결과를 검토하고 통합 방법 확인 |
| 설정 정보 | 대상 도구·필수 설정·버전 | 설정이 적용되는 환경 확인 |
| URL | 링크 대상·복사 대상의 실체 | 참조 자료인지 구현물인지 구분 |
| 설치 명령 | 출처·명령 동작·필수 환경 | 내용을 검토하고 실행 범위 결정 |

## 평가 항목과 결과 분리

| 검토 항목 | 실습 방법 제안 | 현재 결과 |
|---|---|---|
| 가독성 | 제목·본문을 정적 배경과 비교 | 미실행 |
| 상호작용 | 클릭·keyboard focus·입력 방해 확인 | 미실행 |
| viewport 변화 | 좁은 화면·넓은 화면·resize 확인 | 미실행 |
| reduced motion | OS 설정 변화에 따른 동작 확인 | 미실행 |
| 성능 | 동일 환경에서 효과 on/off의 rendering·CPU 기록 | 미실행 |
| browser compatibility | 대상 browser와 버전을 정해 재현 | 미실행 |

수치 기준은 대상 제품과 실행 환경에 맞게 실습 전에 정한다. 지원이 확인되지 않은 항목을 성공으로 표시하지 않는다. reduced motion 미대응이 확인되면 정적 대체나 움직임 제어를 요구사항으로 검토한다.

## AI 코딩 도구 비교 기록

동일한 입력 원문, 요구사항, 시작 파일을 두 도구에 제공한다. 버전·모델·환경과 실행별 차이를 기록하고, 실행 가능성·수정량·요구사항 충족 여부를 평가한다. 동일 입력도 같은 결과를 보장하지 않는다.

```text
도구 / 버전 / 모델:
입력 원문과 출처:
실행 환경 / dependency:
실행 성공 여부 / 오류:
수동 수정 내역:
요구사항별 결과 / 증거:
남은 미확인 항목:
```
