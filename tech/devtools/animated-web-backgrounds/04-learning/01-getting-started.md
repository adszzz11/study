# 시작하기: 관찰 명세 만들기

## 목표와 준비

현재 자료로 만들 수 있는 것은 검증 범위를 표시한 명세와 평가 계획이다. 아래 절차는 **후속 학습 제안**이며 threeui에서 검증된 구현법이 아니다. 준비물은 dossier와 관찰 기록이며, 실행 단계에는 실제 구현 자료가 필요하다.

## 1. 사실과 요구사항 분리

| 항목 | 현재 근거 | 후속 요구사항 예시 |
|---|---|---|
| 움직임 | 배경 효과 언급만 있음 | 원하는 속도·방향·반복 주기 정의 |
| 콘텐츠와 겹침 | 실제 동작 미확인 | 제목·본문 가독성 유지 |
| 입력 반응 | 실제 동작 미확인 | 버튼 클릭과 focus 이동 유지 |
| 움직임 제어 | 지원 여부 미확인 | reduced motion 정책 결정 |

## 2. 전달 형식 확인

실제 복사 내용이 확보되면 source code, prompt, 설정 정보, URL, 설치 명령 등으로 분류한다. 설치 명령처럼 보여도 출처와 내용을 읽고 필요한 환경을 확인한다. 형식이 확인되기 전에는 설치·실행 절차를 확정하지 않는다.

```text
관찰 사실: dossier에 애니메이션 배경 언급이 기록되어 있음
미확인: 실제 복사 내용, 렌더링 방식, 실행 환경
요구사항: 본문 가독성과 버튼 입력 유지
다음 증거: 복사 payload 원문과 공식 실행 안내
```

## 3. 최소 화면 계획

구현물을 확보한 뒤 제목·본문·버튼이 있는 단일 화면에 적용한다. 정적 배경 상태를 기준으로 기록하고 움직임이 켜진 상태와 비교한다. 아직 구현물이 없으면 실행 결과는 `미실행`으로 둔다.

## 완료 기준

- [ ] 관찰 사실과 원하는 동작을 분리했다.
- [ ] 미확인 전달 형식을 명시했다.
- [ ] 실행에 필요한 추가 자료와 평가 항목을 적었다.
