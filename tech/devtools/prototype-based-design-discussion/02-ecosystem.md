# Ecosystem: 검토 방식 비교

## 비교 범위

자료에 경쟁 제품 목록이 없으므로 제품 순위 대신 검토 방식을 비교한다. 대안이 실제 영상에서 사용됐다는 뜻은 아니다.

| 접근 | 논의의 중심 | 기대 역할 | 한계·주의점 |
|---|---|---|---|
| 프로토타입 기반 논의 | 구체적인 화면과 강조 영역 | 대상과 변경 위치 공유 | 동작 범위가 없으면 interaction 검토 제한 |
| 텍스트 중심 논의 | 설명과 수정 요청 | 의도와 이유 기록 | 화면 위치와 해석을 별도로 맞춰야 함 |
| 속성 비교 중심 검토 | 색상 코드·텍스트 스타일·변수 | 시스템 대응 관계 검토 | 전체 인상과 맥락을 충분히 설명하지 못함 |
| 적용 전후 시각 비교 | 변경 전후 화면 | 시각적 영향 확인 | 값 연결과 누락은 별도 검토 필요 |
| 명령 기반 적용 흐름 | 명령 문자열과 Figma URL | 채팅으로 적용 지시 | 실행 환경·지원 범위·재현 방법 미상 |

## 조합해서 사용하기

- 위치를 먼저 정하고 텍스트로 변경 이유를 남긴다.
- 속성표로 참조 대응을 검토한 뒤 같은 상태의 화면을 비교한다.
- 값의 일치만으로 화면 품질을, 시각적 변화만으로 시스템 적용 정확성을 확정하지 않는다.

## 도구와 사례의 역할

Figma는 URL로 참조되는 디자인 도구이고, MeetBook은 예약 캘린더 사례의 이름이다. 공식 관계나 연동 구조는 확인되지 않았다. 특정 framework, backend, API 또는 성능 수치는 자료에 없다.
