## 추가 확보할 근거

- [ ] 원본 영상 URL, 게시 주체와 게시일
- [ ] Figma URL과 그 역할: 대상 프로토타입 / 디자인 시스템 참조
- [ ] 명령 제공 제품, 지원 입력 형식과 실행 환경
- [ ] 변경 범위, 파일 기록 위치, 권한과 사람의 승인 단계
- [ ] token binding·component replacement를 확인할 실제 속성 기록
- [ ] 정확도·시간·사용성 주장을 검증할 측정 조건과 결과

## 사실과 제안 구분

- **자료상 관찰:** 특정 영역 강조, 명령 입력, 비교표, 전후 탭.
- **해석:** 프로토타입이 의견과 위치를 연결하는 공통 기준으로 기능한다.
- **학습 제안:** 동일 상태 비교, 검토표, 요구사항 프로젝트.
- **미확인:** 내부 구현, 실제 동작, 자동화 범위, 효과 수치.
