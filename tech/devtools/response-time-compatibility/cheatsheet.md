# Cheatsheet

## 실행 전

- [ ] 빌드·시나리오·기대 결과를 고정한다.
- [ ] 측정 시작·종료, 수단, 단위를 적는다.
- [ ] 기기·OS·브라우저 버전과 환경 조합을 적는다.
- [ ] 지원 범위·합격 기준의 존재 여부를 확인한다.

## 실행 중·이후

- [ ] 기능 성공 여부와 응답 시간을 따로 기록한다.
- [ ] 실패·미완료를 정상 완료 시간으로 기록하지 않는다.
- [ ] 재현 조건과 실행 조건 차이를 남긴다.
- [ ] 변경 전후는 동일 조건을 우선 맞춘다.
- [ ] 미검증 환경과 판정 유보 항목을 명시한다.

## 빠른 해석표

| 관찰 | 가능한 보고 | 피해야 할 확대 해석 |
|---|---|---|
| 한 환경에서 빠르게 동작 | 해당 조건의 시간 관찰값 | 모든 환경에서 빠름 |
| 일부 조합에서 기능 성공 | 확인한 조합의 기능 결과 | 전체 호환성 확보 |
| 변경 후 시간 차이 | 조건을 포함한 변화 기록 | backend가 원인이라고 확정 |
| 기준 없음 | 측정값 보고·판정 유보 | 임의 합격 |
| 화면 표시·기능 동작 | 해당 기능의 결과 | 접근성·보안까지 검증 완료 |

## 기록 한 줄 양식

```text
빌드 | 시나리오 | 환경·버전 | 시작→종료·수단·단위 | 기능 결과 | 시간 | 기준·판정 | 재현 조건
```

도구명·지원 환경·합격 수치는 제공 자료에 없다. 임의의 수치를 공식 기준처럼 적용하지 않는다.
