## 근거와 제안의 구분

- **자료에서 확인**: performance testing의 응답 속도 측정, 기기·브라우저 호환성 확인, 관련 QA 유형의 소개.
- **학습 제안**: 동일 시나리오 비교, 측정 구간 정의, 환경별 결과표, 변경 전후 비교, 출시 검토 보고서.
- **확인 불가**: 실제 응답 시간·테스트 결과·지원 목록·합격선·측정 도구·구현 아키텍처.

특정 서비스가 빠르거나 호환성이 우수하다는 결론을 내릴 근거는 없다. 예시 기록표의 빈칸은 관찰값을 넣는 자리이며 실제 결과가 아니다.

## 추가 자료 확보 시 확인할 항목

- 원본 영상 URL과 게시자·게시일을 확인한다.
- 00:35와 00:40의 실제 내용을 확인한 뒤 항목별 타임스탬프를 연결한다.
- 서비스의 지원 정책과 acceptance 기준을 확보한다.
- 측정 도구를 선택하면 공식 문서에서 측정값의 의미와 한계를 확인한다.

임의의 영상 주소나 도구 문서를 원본 출처로 대체하지 않는다.
