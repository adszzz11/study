# Ecosystem · 도구와 접근 비교

## 역할 비교

수집 자료에 경쟁 서비스는 등장하지 않는다. 기능·가격 순위 대신 도구별 역할과 판단 기준을 비교한다.

| 도구·접근 | 자료에서의 역할 | 판단 기준 | 비교 한계 |
|---|---|---|---|
| threeui | 웹 디자인 예시·에셋 탐색 출발점 | 원하는 표현을 찾는가 | 제공 형식·license·호환성 미확인 |
| Codex | 붙여넣기 활용 대상으로 언급된 AI 코딩 도구 | 입력을 프로젝트 맥락에 맞게 처리하는가 | 실제 입력·실행 결과 미제공 |
| Claude Code | Codex와 함께 언급된 AI 코딩 도구 | 동일 입력에서 어떤 결과를 내는가 | 성능·품질 우열 판단 불가 |
| 예시를 참고한 직접 구현 | 고려할 수 있는 대안적 접근 | 시각적 의도를 요구사항으로 옮기는가 | 영상에서 실행된 방식은 아님 |

threeui와 두 AI 코딩 도구는 동일 역할의 경쟁자가 아니다. 탐색과 구현 활용이라는 서로 다른 단계에 등장한다. 연결 절차가 구체적이지 않아 end-to-end workflow의 완성도는 평가할 수 없다.

## 선택 기준

- reference가 필요하면 시각적 특징부터 기록한다.
- 구현물을 원하면 산출물 형식·실행 조건·사용 조건부터 확인한다.
- 도구 비교가 필요하면 동일 입력과 프로젝트 조건을 고정한다.
- 직접 구현은 가능한 대안이지만, reference의 사용 조건도 별도로 검토한다.

## 공정한 비교 기록

| 고정할 조건 | 기록할 결과 |
|---|---|
| 입력 자료·요구사항·완료 기준 | 외형 충족과 동작 충족을 별도 평가 |
| framework·버전·초기 파일·실행 환경 | build·실행 성공, console error |
| 모델·도구 버전과 수정 기회 | dependencies 변화, 수동 수정 내역 |

이 표는 실험 설계 제안이며, 실제 비교 결과는 아니다.
