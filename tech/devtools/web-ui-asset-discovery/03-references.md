# References · 근거와 추가 확인

## 제공된 자료

| 자료 | 용도 | 근거 범위 |
|---|---|---|
| https://threeui.com/browse | 디자인 예시 탐색의 출발점 | dossier의 영상 요약에서 언급된 browse 화면 |
| 사용자 제공 dossier | 영상 내용과 정보 공백 정리 | 원본 영상 URL·직접 실행 결과는 제공되지 않음 |

## 읽을 때 구분할 내용

- **관찰 내용**: 버튼·책 형태 카드, 키보드·꽃·타일 구체 예시, 애니메이션 배경 언급.
- **활용 안내**: Codex·Claude Code에 붙여넣는 방식이 소개됨.
- **미확인**: 복사 대상, 통합 절차, license, framework, dependencies, 성능.
- **학습 제안**: 이 노트의 검토표·프롬프트·프로젝트는 실습 설계이며 제품 기능의 증거가 아님.

## 추가 조사 체크리스트

- [ ] 후보 상세 화면과 실제 복사 내용의 형식을 기록한다.
- [ ] 사용 조건·license의 원문 URL, 확인일, 적용 범위를 기록한다.
- [ ] 실행 조건·dependencies·지원 framework를 확인한다.
- [ ] 동작을 직접 확인하고 정지 화면만으로 한 추정을 수정한다.
- [ ] 실행 로그와 결과를 남겨 자료에서 확인한 사실과 분리한다.

새로운 사실을 추가할 때에는 해당 근거 URL과 확인일을 함께 기록한다. 제공되지 않은 공식 문서·license URL은 추정해서 추가하지 않는다.
