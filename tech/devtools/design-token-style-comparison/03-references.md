# References: 근거와 확인 과제

## 제공 자료

| 자료 | 확보 상태 | 사용할 수 있는 근거 |
|---|---|---|
| 사용자 제공 dossier | 텍스트 제공 | 영상 요약, 관찰 사실, 해석과 실습 제안 |
| 원본 영상 | URL 미제공 | 직접 재검증할 수 없음 |
| Figma 디자인 참조 | URL 등장 사실만 제공 | 대상 파일과 역할을 열어 확인할 수 없음 |
| 비교 표와 전후 화면 | 요약만 제공 | 실제 값이나 변경 결과의 독립 검증 불가 |

## 사실과 제안 구분

- **관찰 사실:** 비교 표, 명령과 Figma URL 입력, 전후 디자인 탭이 제시된다.
- **해석:** 디자인 시스템에 맞추어 속성을 변경하고 결과를 검토하려는 흐름으로 읽힌다.
- **실습 제안:** 값과 참조를 분리해 기록하고, 기준이 없으면 비교 불가로 남긴다.
- **주장할 수 없는 결과:** 자동 적용 정확도, 시간 절감, 컴포넌트 교체, 코드 생성 성공.

## 후속 확인 목록

- [ ] 원본 영상 URL과 관찰 장면의 위치 확보
- [ ] Figma 실제 URL, 접근 가능 여부, 참조 대상의 역할 확인
- [ ] 명령의 제공 환경·입력 형식·권한·적용 범위 확인
- [ ] 실제 비교 값, 기준 자료의 버전, 판정 규칙 확보
- [ ] 변경 결과와 자동 적용·수동 수정 범위 확인

URL이 없는 상태는 출처가 확보된 상태와 구분한다. 임의의 Figma 주소나 도구 문서를 원본 출처처럼 보충하지 않는다.
