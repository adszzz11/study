# 심화 학습: 값·참조·변경 수준

## 값과 참조를 별도로 보기

같은 색상 값이 보이더라도 같은 변수에 연결되었다고 단정할 수 없다. 반대로 변수 이름만으로 적용된 값을 확정해서도 안 된다. 이는 검토를 위한 일반적인 분석 제안이며 영상에서 두 조건을 검사했다는 뜻은 아니다.

| 질문 | 확인할 정보 | 정보가 없을 때 |
|---|---|---|
| 값이 같은가? | 적용 전·기준·적용 후의 실제 색상 코드 | 값 비교 불가 |
| 참조가 같은가? | 각 대상의 변수 연결 정보 | 참조 비교 불가 |
| 텍스트가 같은 기준인가? | 스타일 이름과 비교 범위에 포함한 실제 속성 | 이름만으로 전체 일치 판정 금지 |

## 텍스트 스타일의 비교 범위 정하기

실습에서는 이름만 비교할지, font family·size·weight·line height 등의 실제 속성까지 비교할지 먼저 정한다. 이 속성 목록은 실습 제안이며 자료에 등장한 상세 필드가 아니다. 이름 일치와 속성 일치를 각각 기록하면 판정의 범위를 명확히 전달할 수 있다.

## 디자인·컴포넌트·토큰 연결 기록

| 변경 ID | 디자인: 화면 위치·변화 | 컴포넌트 정보 | 토큰 또는 변수 정보 | 근거 |
|---|---|---|---|---|
| C-01 | 선택한 영역의 관찰 변화 | 확인된 이름 또는 미확인 | 확인된 참조 또는 미확인 | 화면·속성 기록의 위치 |

세 열을 채우기 위해 없는 관계를 추정하지 않는다. 컴포넌트 이름이 보이는 것과 실제 인스턴스 교체가 일어난 것은 별도 주장이다. 변수와 토큰의 대응도 기준 자료로 확인해야 한다.

## 전후 검토의 교차 확인

1. 전후 화면의 선택 상태·표시 범위 등 비교 조건을 맞춘다.
2. 표의 변경 ID가 화면에서 같은 위치를 가리키는지 확인한다.
3. 시각적 변화가 있어도 내부 참조 정보가 없으면 참조 검증은 미완료로 둔다.
4. 자동 적용과 수동 수정을 구분해 결과에 기록한다.

## 효과 측정의 한계

작업 시간이나 정확도 향상을 평가하려면 비교 조건, 측정 대상, 시간 기록, 오류 판정 기준이 별도로 필요하다. 제공 자료에는 이러한 측정이 없으므로 효과를 수치나 성공 사례로 주장하지 않는다.
