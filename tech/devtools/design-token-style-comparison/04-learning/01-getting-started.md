# 시작하기: 한 화면 비교 기록

## 목표와 준비물

한 화면의 특정 영역에 대해 현재 상태·적용 기준·적용 후 상태를 분리한 표를 만든다. 아래는 실습 제안이며 영상의 실제 수행 절차가 아니다.

- 검토할 프로토타입 한 화면과 영역 식별 정보
- 확보할 수 있다면 디자인 시스템 기준 자료와 버전
- 동일 조건의 전후 화면 및 관찰값을 적을 문서

기준이 없어도 관찰 기록은 가능하지만 일치·불일치 판정은 할 수 없다.

## 진행 순서

1. 예약 캘린더와 같은 화면 하나와 우선 검토 영역을 지정한다.
2. 적용 전 화면과 색상 코드·텍스트 스타일·변수 정보를 기록한다.
3. 기준 자료를 별도 열에 적는다. 없는 정보는 `미확인`으로 남긴다.
4. 실제 환경에서 지원되는 방식으로 적용하거나 수동 수정한다. 수행 주체와 수정 범위를 기록한다.
5. 같은 화면 상태에서 적용 후 관찰값을 기록한다.
6. 기준과 비교하여 `일치 / 불일치 / 비교 불가`를 판정하고 근거를 적는다.

## 기록 양식

| 화면 영역 | 비교 항목 | 적용 전 | 적용 기준 | 적용 후 | 판정·근거 |
|---|---|---|---|---|---|
| 선택 영역 | 색상 코드 | 관찰값 | 확인된 기준 또는 미확인 | 관찰값 | 일치 / 불일치 / 비교 불가 |
| 선택 영역 | 텍스트 스타일 | 이름·확인 가능한 속성 | 확인된 기준 또는 미확인 | 이름·속성 | 근거 기록 |
| 선택 영역 | 디자인 변수 | 확인된 값·참조 | 확인된 기준 또는 미확인 | 확인된 값·참조 | 값과 참조를 분리 판정 |

## 명령을 접했을 때

```text
/apply-ds-to-prototype
```

위 문자열은 자료에서 관찰된 입력이다. 설치 또는 실행 가이드가 아니며, 지원 환경·권한·입력 규칙을 먼저 확인해야 한다. 실제 Figma URL은 제공되지 않았다.

## 완료 기준

- [ ] 화면 위치와 비교 항목을 구체적으로 적었다.
- [ ] 현재 상태와 적용 기준을 분리했다.
- [ ] 기준이 없는 항목은 비교 불가로 남겼다.
- [ ] 전후 화면과 표의 대상·조건이 일치한다.
