# Cheatsheet: 디자인 토큰과 스타일 비교

## 빠른 검토 순서

```text
범위 고정 → 현재 상태 기록 → 기준 확인 → 값·참조 분리
→ 적용 방식 기록 → 전후 대조 → 근거와 미확인 항목 정리
```

## 핵심 질문

| 대상 | 확인할 질문 |
|---|---|
| 색상 코드 | 실제 값이 바뀌었는가? 어느 화면 영역인가? |
| 텍스트 스타일 | 이름만 비교했는가, 실제 속성도 비교했는가? |
| 디자인 변수 | 값과 연결 관계 중 무엇을 확인했는가? |
| 컴포넌트 | 구성 단위의 변화가 확인되는가? 교체 근거가 있는가? |
| 전후 화면 | 같은 조건에서 표의 변경과 같은 대상을 보는가? |

## 판정 규칙 — 실습 제안

- **일치:** 확인된 기준과 비교 대상이 정한 범위에서 같다.
- **불일치:** 확인된 기준과 다른 항목 및 근거를 제시할 수 있다.
- **비교 불가:** 기준, 관찰값 또는 연결 정보가 없어 판단할 수 없다.
- 값 일치와 참조 일치는 별도로 기록한다.

## 반복 체크리스트

- [ ] 화면과 영역을 고정했다.
- [ ] 적용 전·기준·적용 후를 분리했다.
- [ ] 변수와 토큰의 미확인 관계를 추정하지 않았다.
- [ ] 자동 적용과 수동 수정을 구분했다.
- [ ] 전후 화면과 표가 같은 변경을 설명한다.
- [ ] 정확도·시간 절감 등 측정되지 않은 효과를 주장하지 않았다.
