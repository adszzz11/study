# Spatial UI의 시각적 구조와 의료 대시보드 적용 분석

> **한 줄 정의**: Spatial UI는 이 자료에서 해부학적 심장 이미지와 건강 지표를 하나의 화면에 배치한 의료 대시보드의 디자인 스타일명이다.

## Overview

영상 요약은 Skeuomorphism, Minimalism, Liquid Glass, Spatial UI의 시각적 예시를 제시한다. 00:07의 Spatial UI 사례는 붉은 해부학적 심장과 건강 지표를 배치한 어두운 의료 대시보드다. 이 노트는 공식 기술 규격이나 제품 안내가 아닌 **화면 구성 분석을 위한 tool-study**다.

- **관찰 사실:** 심장 이미지, 건강 지표, 어두운 화면, 영상의 스타일 명명.
- **해석:** 대상 표현과 상태 표현의 배치가 두 정보의 연결을 유도할 수 있다.
- **검증 가설:** 배치가 탐색 시간이나 이해 오류를 개선하는지는 실험이 필요하다.
- **미확인:** framework, renderer, backend, data source, AR·VR·headset, 실제 3D와 interaction.

## When To Use

- 관찰 대상 이미지와 상태 지표의 의미 연결을 검토할 때.
- 같은 콘텐츠로 서로 다른 정보 배치를 비교할 때.
- 의료 대시보드의 visual hierarchy와 가독성을 학습용 prototype으로 평가할 때.

## When Not To Use

- 이 자료를 공식 Spatial UI 정의나 SDK 선택 근거로 사용할 때.
- AR·VR, 실시간 sensor data 또는 임상 시스템 통합을 확인해야 할 때.
- 검증 없이 의료 판단의 정확성이나 사용성 향상을 주장할 때.
