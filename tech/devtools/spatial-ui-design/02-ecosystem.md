# Ecosystem: 네 가지 스타일 예시 비교

## 비교 범위

기업·제품·SDK의 경쟁 정보는 없다. 아래는 같은 영상 요약의 네 화면에 한정한 비교다. 콘텐츠와 용도가 서로 달라 스타일 자체의 우열이나 최신성을 판단할 수 없다.

| 스타일 | 자료의 예시 | 시각적 초점 | 판단 불가 |
|---|---|---|---|
| Skeuomorphism | 노브·슬라이더가 있는 흰색 오디오 제어 화면 | 물리적 도구를 연상시키는 control | 실제 조작감·학습 난이도 |
| Minimalism | 옅은 색의 기술 문서 웹페이지 | 문서 중심의 정보 제시 | 정보 밀도·탐색 성능 |
| Liquid Glass | 반투명 패널의 보라색·파란색 음악 앱 목업 | 투명도·패널 표현 | 가독성·rendering 비용 |
| Spatial UI | 붉은 심장과 건강 지표의 어두운 의료 대시보드 | 대상과 상태 정보의 함께 배치 | 공간 interaction·분석 정확도 |

## 비교에서 얻는 질문

- 각 화면은 무엇을 시각적 중심으로 삼는가?
- 콘텐츠 종류의 차이와 스타일의 효과를 구분할 수 있는가?
- 같은 데이터를 사용하면 배치의 효과가 유지되는가?

관찰된 차이를 모두 스타일 효과로 돌리지 않는다. 실제 대안 검토에는 동일 콘텐츠를 사용하는 배치 비교가 필요하다.
