# Spatial UI Cheatsheet

## 빠른 구분

| 구분 | 기억할 내용 |
|---|---|
| 정의 범위 | 해당 영상 요약의 의료 대시보드 스타일명 |
| 확인 | 붉은 해부학적 심장 + 건강 지표 + 어두운 화면 |
| 해석 | 대상 표현 + 상태 표현 + 배치 관계 |
| 검증 필요 | 이해 속도, 탐색 오류, 중요 지표 발견 |
| 미확인 | framework, renderer, backend, data source, 3D, AR·VR, interaction |

## 설계 점검

- [ ] 대상과 지표의 의미 관계가 명확한가?
- [ ] 시각적 강조와 정보 중요도가 맞는가?
- [ ] 어두운 배경에서 텍스트와 상태를 읽을 수 있는가?
- [ ] 비교 화면은 콘텐츠를 고정하고 배치만 바꿨는가?
- [ ] 추가 데이터는 synthetic으로 표시했는가?
- [ ] 공간 표현이나 interaction이 개선할 과업을 정했는가?

## 기술스택 요약

- 확인된 구성은 붉은 해부학적 심장, 건강 지표, 어두운 의료 대시보드다.
- framework, renderer, backend, data source는 자료에 명시되지 않았다.
- AR·VR·headset·실시간 3D 지원 여부도 확인할 수 없다.
- 대상과 지표의 배치 prototype에서 시작해 가독성과 탐색 성능을 검증한다.
