# Projects: 의료 대시보드 적용 실습

## 1. 의료 대시보드 구성 재해석

**목표:** 심장 이미지와 건강 지표를 함께 보여주는 학습용 prototype을 만든다.

- 어두운 배경·붉은 심장·건강 지표라는 관찰된 구성에서 시작한다.
- 추가 수치는 synthetic data로 표시한다. 예: `학습용 synthetic data — 임상 사용 목적 아님`.
- 대상 식별, 지표 탐색, 상태 비교 과업을 정의한다.
- 산출물: 정적 화면, 관찰·해석 목록, 과업 수행 기록.
- 검증: 이미지 다음에 관련 수치를 찾는가? 중요한 지표가 묻히는가?

## 2. 동일 데이터의 배치 비교

**목표:** 대상 주변 배치와 별도 지표 패널의 차이를 검토한다.

- 데이터·색상·텍스트 크기를 유지하고 배치만 변경한다.
- 지표 탐색 시간과 잘못 연결해 읽은 사례를 기록한다.
- 산출물: A/B 화면, 비교 조건표, 시간·오류 관찰표.
- 검증: 스타일명에 대한 선호와 실제 과업 수행 결과를 구분한다.

## 3. 정적 prototype에서 interaction 실험으로 확장

**목표:** interaction을 추가할 이유를 판단한다.

- 정적 화면을 먼저 평가한 뒤 선택 시 관련 지표 강조를 추가한다.
- 기능별로 탐색 단계와 오류의 변화를 기록한다.
- 3D 회전이나 몰입형 환경은 필요성이 확인될 때 별도 실험한다.
- 산출물: 정적 기준 화면, 기능 한 개를 추가한 화면, 비교 기록.
- 검증: 기능 추가가 해결한 과업과 새로 생긴 어려움을 설명할 수 있는가?

## 완료 기준

- [ ] 모든 추가 수치가 synthetic임을 표시했다.
- [ ] 관찰 사실과 직접 만든 기능을 구분했다.
- [ ] 가설을 지지하지 않는 결과도 기록했다.
- [ ] 결과를 의료 판단 정확성이나 임상 유효성으로 확대하지 않았다.
