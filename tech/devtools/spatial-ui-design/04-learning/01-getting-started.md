# 시작하기: 화면 요소와 관계 기록

## 목표와 준비

관찰 사실과 해석을 구분한 정적 wireframe을 만든다. 종이 또는 익숙한 2D 디자인 도구를 사용하면 된다. 특정 SDK는 요구하지 않는다. 원본이 없으므로 정확한 화면 복제라고 부르지 않는다.

## 실습 순서

1. 심장 이미지, 건강 지표, 어두운 배경을 요소 목록으로 적는다.
2. 지표의 역할을 적되 원본에 없는 이름·수치·단위를 사실로 추가하지 않는다.
3. 대상과 지표를 가까이 둔 A안과 별도 목록에 둔 B안을 만든다.
4. 두 안의 데이터·색상·텍스트 크기를 고정하고 배치만 바꾼다.
5. 대상 식별, 지표 탐색, 상태 비교 과업으로 의미 연결을 확인한다.

## 기록 템플릿

```text
요소: 건강 지표
관찰: 심장 이미지와 같은 화면에 배치됨
미확인: 이름, 수치, 단위, 갱신 방식
해석: 심장 상태를 설명하는 정보일 수 있음
실험: 특정 지표를 찾고 대상과의 관계를 설명하게 하기
```

## 완료 조건

- [ ] 관찰·해석·가설이 구분되어 있다.
- [ ] 추가 데이터에는 synthetic data 표시가 있다.
- [ ] 두 안에서 콘텐츠는 같고 배치만 다르다.
- [ ] 가까이 놓은 것과 의미가 명확한 것을 구분해 기록했다.
