# 심화: visual hierarchy와 과업 기반 검증

## 핵심 개념

- **Visual hierarchy:** 붉은 심장의 시각적 강조와 업무상 중요한 지표의 우선순위가 일치하는지 살핀다.
- **의미 연결:** 근접 배치만으로 관계가 명확해졌다고 가정하지 않는다.
- **가독성:** 어두운 배경에서 지표·단위·상태를 읽을 수 있는지 평가한다.
- **공간 표현의 필요성:** 깊이·원근·회전은 개선할 과업이 있을 때 실험한다.

## 배치 비교 실험 제안

아래는 후속 학습 실험이며 영상의 평가 결과가 아니다.

| 항목 | 설계 |
|---|---|
| 가설 | 대상 주변 배치가 별도 패널보다 관련 지표 탐색을 돕는다 |
| 독립변수 | 지표 배치 A/B |
| 고정 조건 | 데이터·이미지·색상·텍스트 크기·과업 |
| 과업 | 지정한 지표 찾기, 대상과 관계 설명, 두 상태 비교 |
| 관찰값 | 과업 완료 시간, 오연결 사례, 누락, 사용자 설명 |
| 순서 효과 | 참여자별 A/B 제시 순서를 교차한다 |

시간이 짧아져도 오류가 늘면 개선으로 단정하지 않는다. 소규모 학습 실험을 임상 효용의 근거로 일반화하지 않는다.

## 시각적 강조 점검

1. 가장 먼저 본 요소를 기록하게 한다.
2. prototype에 넣은 중요 지표 또는 synthetic 경고를 찾게 한다.
3. 심장 이미지에 주의가 집중되어 지표를 놓치는지 관찰한다.
4. 대비·크기·여백을 바꾼다면 배치 실험과 구분한 별도 반복으로 기록한다.

## Interaction 확장

정적 화면을 기준으로 선택 시 관련 지표 강조를 하나씩 추가한다. 탐색 단계와 오류가 줄어드는지 확인한다. 회전·확대·실제 3D·몰입형 환경은 이 자료에서 확인된 기능이 아니며 별도 가설로 다룬다.
