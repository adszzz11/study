# Ecosystem — UI 스타일 비교

제품·라이브러리·프레임워크 생태계는 제공 자료에 없다. 아래는 영상에 등장한 예시의 비교다.

| 스타일 | 제공된 예시 | 표현의 초점 | 미확인 사항 |
|---|---|---|---|
| Skeuomorphism | 노브·슬라이더가 있는 흰색 오디오 화면 | 물리적 장치 형태 | 실제 입력·피드백 |
| Minimalism | 옅은 색 기술 문서 웹페이지 | 문서 중심 표현 | 정보 구조·기능 상세 |
| Liquid Glass | 보라·파랑 음악 앱 목업의 반투명 패널 | 반투명 패널과 색 | 가독성·성능·구현 |
| Spatial UI | 붉은 해부학적 심장과 건강 지표가 있는 어두운 의료 대시보드 | 대상과 지표 배치 | 실제 3D 공간·공간 입력 |

## 비교할 때 유지할 조건

네 예시는 콘텐츠와 목적도 다르므로 직관성·효율의 우열을 결론 내릴 수 없다. 같은 레이블·범위·기능·작업을 가진 패널 두 개를 만들고 표현만 바꾼다. 목표 값 도달 시간, 오입력, 조작 질문을 기록하고 결과를 해당 실험 조건으로 한정한다.
