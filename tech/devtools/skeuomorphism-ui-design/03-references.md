# References — 근거의 범위

## 원자료

| 항목 | 범위 |
|---|---|
| 자료 | 사용자 제공 dossier에 포함된 단일 영상 요약 |
| 시점 | 00:00 장면 설명 |
| 원본 URL | 미제공 — 추정하거나 대체 URL을 만들지 않음 |
| 관찰 | 흰색 오디오 화면의 노브·슬라이더 및 다른 세 스타일 예시 |
| 제외 | 실제 동작·성능·구현·역사·보급·사용성 우열 |

## 읽는 순서

1. dossier에서 직접 관찰된 형태를 먼저 기록한다.
2. MDN에서 기본 range 입력의 범위·step·레이블 연결을 살펴본다.
3. APG에서 커스텀 slider의 이름·값·키보드 상호작용을 검토한다.
4. 문서의 권장 동작과 자신이 구현한 동작을 대조한다. 문서 링크만으로 접근성 충족을 선언하지 않는다.

보충 문서는 아래 실습을 위한 별도 참고 자료다. 원영상의 출처나 기능을 입증하지 않는다.
