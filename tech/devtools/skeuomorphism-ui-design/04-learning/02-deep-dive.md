# 심화 학습 — 조작 규칙과 검증

## 입력 규칙 명시

노브는 회전 입력인지, 수직·수평 드래그인지 외형만으로 확정되지 않는다. 한 가지 규칙을 선택하고 안내·감도·경계 처리를 정의한다. 포인터가 영역 밖으로 이동하거나 조작이 취소될 때도 값과 표시가 일치하는지 확인한다.

## 접근성과 정밀도

- 기본 range 입력을 우선 검토하고 레이블·현재 값·focus 표시를 확인한다.
- 커스텀 slider라면 APG의 접근 가능한 이름, 최솟값·최댓값·현재 값과 키보드 규칙을 함께 검토한다. ARIA 속성만 추가해서 동작이 생기지는 않는다.
- 방향키로 step 변경, Home/End로 경계 이동을 실습 규칙으로 삼고 실제 구현을 점검한다.
- 숫자 직접 입력으로 정밀 조절을 보완한다. 빈 값·범위 초과 입력의 처리 규칙도 정한다.
- 흰색 화면에서 경계·포커스·선택 상태가 구분되는지 확인한다. 색과 입체감만으로 상태를 전달하지 않는다.

## 같은 기능으로 비교

| 통제 조건 | 기록할 결과 |
|---|---|
| 같은 레이블·범위·step·초기값 | 목표 값 도달 시간 |
| 같은 목표 값과 기기 | 오입력 및 복구 횟수 |
| 같은 기능·숫자 입력 제공 | 조작 방향 질문 및 막힌 지점 |

노브 중심 패널과 단순 입력 패널을 만들고 순서 효과를 줄이도록 제시 순서를 바꾼다. 소규모 관찰은 가설을 개선하는 근거로 사용하며 스타일 전체의 우수성으로 일반화하지 않는다.

## 실제 기능 연결

가상 값 검증 후 실제 오디오를 연결한다면 UI의 요청 값과 처리 결과를 분리해 기록한다. 적용 실패·지연 때 표시가 잘못된 확신을 주지 않는지 확인한다. 이 단계는 확장 제안이며 영상의 기능 재현을 뜻하지 않는다.
