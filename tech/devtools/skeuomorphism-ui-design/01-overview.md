# Overview — 형태·동작·값의 연결

## What

Skeuomorphism은 이 자료에서 물리적 노브·슬라이더를 닮은 제어 요소로 나타난다. 자료의 정의 범위는 이 사례로 제한한다. 특정 프레임워크나 제품명이 아니다.

## Why

노브와 슬라이더는 값 조절 장치라는 시각적 단서를 제공한다. 그러나 장치임을 알아보는 것과 실제로 값을 바꾸는 방법을 아는 것은 별개다. 따라서 사실적인 장식보다 조절 대상·입력 규칙·현재 값의 연결을 먼저 검토한다.

## 관찰 가능한 특징

| 요소 | 확인된 내용 | 검토 질문 |
|---|---|---|
| 화면 | 오디오 제어 화면 | 무엇을 조절하는가? |
| 제어 | 노브, 슬라이더 | 조작 방향을 알 수 있는가? |
| 색조 | 흰색 | 경계와 상태를 구분할 수 있는가? |
| 맥락 | 네 UI 스타일의 서로 다른 예시 | 콘텐츠 차이를 스타일 효과로 오인하지 않는가? |

그림자·질감·재질·입체 표현의 구체적 방식은 기술되지 않았다. 실제 드래그나 회전 지원도 미확인이다.

## 실습용 설계 분해

| 층 | 역할 | 검증 |
|---|---|---|
| 시각적 표현 | 형태·상태 표시 | 레이블과 현재 값이 보이는가? |
| Interaction | 입력을 값 변화로 변환 | 회전·수직·수평 중 어떤 규칙인가? |
| 상태·기능 | 값 저장 및 제어 대상 연결 | 표시 값과 적용 값이 일치하는가? |

이는 영상 속 아키텍처가 아니다. 정밀도에는 숫자 표시·직접 입력을, 접근성에는 레이블·키보드 조작을 보완하는 설계로 실험할 수 있다.
