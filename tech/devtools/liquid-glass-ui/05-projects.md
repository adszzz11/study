# Projects — 실전 적용

## 1. Liquid Glass 음악 앱 시안

보라색·파란색과 반투명 패널을 사용해 음악 앱 화면을 제작한다.

- **산출물:** 동일한 Layout의 불투명·반투명 시안.
- **고정:** 콘텐츠, 글자 크기, 버튼 위치.
- **검증:** 곡 정보 식별, 재생 조작 요소 발견, 선택 상태 구분.
- **완료 기준:** 비교 화면과 함께 읽기 어렵거나 구분이 모호해지는 조건을 기록한다.

## 2. Surface Playground

배경과 패널 속성을 조절하는 작은 실험 도구를 만든다.

- **조절:** 배경 색채·밝기, 패널 Alpha, 텍스트 색.
- **선택 실험:** Blur를 독립 옵션으로 추가한다. 원본의 구현이라고 표시하지 않는다.
- **산출물:** 조건별 화면과 관찰 기록.
- **완료 기준:** 적용 가능한 조건과 조정이 필요한 조건을 설명한다.

## 3. 네 가지 스타일의 통제된 비교

한 음악 앱 화면을 네 가지 스타일에서 착안한 시안으로 재구성한다.

- **고정:** 콘텐츠, 기능, 화면 크기, 수행 과제.
- **변경:** 색채, 표면, 조작 요소의 시각 표현.
- **검증:** 곡 정보 탐색과 재생 조작 과정의 차이.
- **완료 기준:** 동일 과제의 비교 결과와 한계를 기록한다. 제작한 시안의 결과를 스타일 전체의 우열로 일반화하지 않는다.

## 제출 체크리스트

- [ ] 각 화면의 고정 변수와 변경 변수를 명시했다.
- [ ] 실제 관찰 결과와 구현 가설을 분리했다.
- [ ] 불리한 배경 조건과 모호한 상태를 함께 남겼다.
- [ ] 확인하지 않은 Framework·API·성능을 주장하지 않았다.
