# References — 근거와 한계

## 자료 목록

| 자료 | 제공 상태 | 활용 범위 |
|---|---|---|
| 사용자 제공 dossier | 본문 제공, URL 없음 | 정의·시각 단서·비교·실습 제안의 근거 |
| 원본 영상 | URL·파일 없음 | 직접 재생·프레임 검증 불가 |

## 근거 수준 기록법

- **Observation**: dossier에 반투명 패널이 명시되어 있다.
- **Interpretation**: 배경과 콘텐츠를 시각적으로 연결하는 표면으로 읽을 수 있다.
- **Hypothesis**: Blur로 구현할 수 있을지 실험한다. 원본의 구현이라고 주장하지 않는다.

## 추가 자료 확보 시 확인할 것

1. 원본 URL, 제작자, 게시일과 해당 장면 위치를 기록한다.
2. 정지 화면의 시각 단서와 영상으로만 확인 가능한 동작을 나눈다.
3. 공식 코드나 제품 문서가 있을 때만 Framework·API를 연결한다.
4. 평가 결과에는 배경·콘텐츠·과제·측정 조건을 함께 남긴다.

현재는 외부 URL을 추정해 출처로 붙이지 않는다.
