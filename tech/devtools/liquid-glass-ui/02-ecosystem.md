# Ecosystem — 영상 속 스타일 비교

## 비교 범위

제품·라이브러리·Framework 생태계와 시장 경쟁 정보는 없다. 따라서 함께 등장한 스타일의 **영상 속 예시**만 비교한다.

| 스타일 | 예시 | 직접 확인되는 시각 단서 | 비교 축 |
|---|---|---|---|
| Skeuomorphism | 흰색 오디오 제어 화면 | 노브와 슬라이더 | 조작 장치 형태와 Surface 표현 |
| Minimalism | 옅은 색의 기술 문서 웹페이지 | 문서 중심 화면, 옅은 색 | 문서 배치와 색채·패널 표현 |
| Liquid Glass | 보라색·파란색 음악 앱 목업 | 반투명 패널 | 배경과 패널의 시각적 관계 |
| Spatial UI | 어두운 의료 대시보드 | 붉은 해부학적 심장, 건강 지표 | 중심 대상·지표 배치와 색채 |

## 비교의 한계

- 스타일과 콘텐츠가 동시에 달라진다. 음악 앱과 기술 문서의 차이를 스타일의 효과만으로 설명할 수 없다.
- 심장 이미지가 등장한다는 설명은 실제 3D Interaction이나 공간 입력을 지원한다는 증거가 아니다.
- 우열이나 시장 점유율을 판단할 자료가 없다.

## 통제된 비교 설계

곡명, 아티스트명, 재생 버튼, 화면 크기, 수행 과제를 고정하고 색채·표면·조작 요소의 시각 표현만 변경한다. 결과는 제작한 시안에 한정해 기록한다.
