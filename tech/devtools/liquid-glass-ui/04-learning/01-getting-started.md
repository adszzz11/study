# 시작하기 — Transparency 실험

## 목표와 준비

동일한 음악 앱 Layout에서 패널의 투명도만 바꿔 배경 노출과 콘텐츠 식별성을 관찰한다. 아래 절차는 제안 실습이며 원본의 제작 방법이 아니다. 디자인 도구나 HTML/CSS 중 편한 환경을 선택한다.

## 절차

1. 곡명·아티스트명·재생 버튼을 포함한 한 화면을 만든다.
2. 보라색·파란색 배경과 불투명 패널을 기준 시안으로 저장한다.
3. 콘텐츠·글자 크기·버튼 위치를 고정하고 패널 Alpha만 변경한다.
4. 같은 배경에서 불투명·반투명 시안을 나란히 비교한다.
5. 곡 정보 읽기, 재생 버튼 찾기, 선택 상태 구분 결과를 기록한다.

## CSS 실험 예시

```css
/* 실습용 가설이며 원본 코드가 아니다. */
.panel {
  --panel-alpha: 0.75;
  background-color: rgb(28 22 65 / var(--panel-alpha));
  color: #fff;
}
```

패널 전체의 `opacity`를 낮추면 자식 텍스트와 아이콘도 함께 투명해질 수 있다. 배경색의 Alpha를 조정하면 이 변수를 분리하기 쉽다. 위 예시는 Blur를 적용하지 않는다. 색상과 Alpha 값은 실습용이며 검증된 권장값이 아니다.

## 기록 양식

| 조건 | Alpha | 곡 정보 식별 | 재생 버튼 발견 | 상태 구분 | 해석 |
|---|---|---|---|---|---|
| 기준 | 1.0 | 미측정 | 미측정 | 미측정 | 실험 후 기록 |
| 반투명 A | 0.75 | 미측정 | 미측정 | 미측정 | 실험 후 기록 |
| 반투명 B | 0.5 | 미측정 | 미측정 | 미측정 | 실험 후 기록 |
