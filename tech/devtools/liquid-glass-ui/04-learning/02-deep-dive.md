# Deep Dive — 변수 분리와 견고함

## Color와 Surface 분리

| 시안 | Color | Surface | 질문 |
|---|---|---|---|
| A | 보라색·파란색 | 불투명 | 색채만으로 어떤 인상이 유지되는가? |
| B | 보라색·파란색 | 반투명 | Surface 변화가 무엇을 바꾸는가? |
| C | 다른 색채 | 불투명 | 다른 색채의 기준은 어떤가? |
| D | C와 동일 | 반투명 | 다른 색채에서도 Surface의 효과가 유지되는가? |

콘텐츠, 글자 크기, 버튼 위치를 고정한다. 색채와 Surface가 함께 바뀐 두 화면만 비교해 원인을 단정하지 않는다.

## 배경 변화 실험

밝은 배경, 어두운 배경, 복잡한 배경에서 같은 패널을 확인한다. 곡 정보 식별·재생 버튼 발견·선택 상태 구분을 같은 과제로 수행한다. 특정 배경에서만 성립하는 가독성인지 기록한다.

## Blur 독립 실험

1. 동일한 Alpha와 배경에서 Blur 없음/있음 시안을 만든다.
2. 비교 기록에 Blur 여부와 설정값을 별도 열로 남긴다.
3. Blur의 효과와 Transparency의 효과를 구분해 서술한다.

Blur는 선택적 구현 가설이다. 원본 적용 여부는 확인되지 않았으며 Refraction과도 같은 개념이 아니다.

## 검증 범위 확장

- 여러 패널을 추가해 정보 위계와 시각적 밀도 변화를 확인한다.
- 선택·비활성·재생 상태를 명시적으로 설계하고 식별 여부를 확인한다.
- 접근성·성능을 평가한다면 실제 대비, 입력 방식, 기기·브라우저·측정 조건을 기록한다. 시각적 인상만으로 통과를 선언하지 않는다.
