# 시작하기 — 화면 세 개를 같은 기준으로 비교하기

## 목표와 준비

시각적 선호를 정보 전달과 사용자 행동으로 설명한다. 다음 절차는 dossier를 바탕으로 만든 실습 제안이며 영상의 공식 교육 과정이 아니다.

- 비교할 화면 레퍼런스 세 개를 준비한다. 자료에는 URL이 없어 이 노트에서 바로 열 수 있는 갤러리는 제공하지 않는다.
- 하나의 제품 화면과 핵심 행동을 정한다. 예: 상품 목록에서 조건에 맞는 상품을 찾아 상세 보기.
- 실제 user flow는 정지 화면만으로 확인할 수 없음을 기록한다.

## 1. 같은 항목으로 관찰

| 기준 | 화면 A | 화면 B | 화면 C |
|---|---|---|---|
| 정보 위계: 가장 먼저 보이는 정보 | 작성 | 작성 | 작성 |
| 여백: 요소의 묶음과 구분 | 작성 | 작성 | 작성 |
| 타이포그래피: 제목·본문 구별 | 작성 | 작성 | 작성 |
| 색상: 강조와 상태 표현 | 작성 | 작성 | 작성 |
| 핵심 행동: 위치와 시각적 강조 | 작성 | 작성 | 작성 |

“깔끔하다” 대신 “제목과 본문 크기 차이가 커서 제목을 먼저 읽게 된다”처럼 관찰 근거를 적는다. 사용자 행동에 미치는 효과는 가설로 구분한다.

## 2. 적용 요소 하나 선택

```text
대상 화면과 핵심 행동:
참고한 레퍼런스:
관찰한 배치·표현:
선택할 요소와 이유:
제외할 요소와 이유:
실제 콘텐츠에 맞게 바꿀 부분:
확인이 필요한 사용자 행동 가설:
```

## 3. 구현 요청 준비

전체 화면을 모방하라는 요청 대신 적용 위치·콘텐츠·배치 기준을 적는다. 컴포넌트 효과는 별도 판단한다. `Copy prompt`가 있다면 본문을 먼저 읽고 실제 포함된 정보만 기록한다.

## 완료 체크

- [ ] 세 화면을 같은 항목으로 비교했다.
- [ ] 선택과 제외 이유를 정보 전달·사용자 행동에 연결했다.
- [ ] 관찰 사실과 사용성 가설을 구분했다.
- [ ] 적용 범위와 수정할 부분을 명시했다.
