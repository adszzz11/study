# References — 출처 범위와 확인 과제

## 제공된 자료

유일한 근거는 사용자 제공 dossier다. 원본 영상, 갤러리, 모바일 화면 페이지, React Bits 페이지, 3D 큐브 그리드 페이지의 URL은 제공되지 않았다. 서비스 주소를 추정해 기재하지 않는다.

| 자료의 언급 | 확인된 범위 | 추가로 필요한 근거 |
|---|---|---|
| 갤러리·모바일 화면 | 화면 목록의 존재 | 정확한 서비스명·원본 URL·사용 맥락 |
| React Bits `Paper Crumple` | 미리보기 | 해당 페이지·설치 문서·라이선스 |
| 3D 큐브 그리드 | 설명·AI 대상 메뉴 | 페이지 URL·라이브러리 소속·의존성 |
| `Copy prompt` | 도구별 메뉴 항목 | 실제 prompt 본문·수동 전달 및 실행 결과 |

## 사실과 제안 구분

- **관찰 사실:** 여러 화면과 효과 미리보기, 컴포넌트 설명, AI 도구 대상 메뉴가 등장한다.
- **해석:** 화면에서 컴포넌트로 좁혀 AI 요청으로 이어지는 접점으로 볼 수 있다.
- **실습 제안:** 동일 기준 비교, 효과 유무 실험, brief 보완, 결과 대조, 판단 기록 재사용.
- **검증되지 않은 주장:** 레퍼런스 열람에 따른 판단력 향상, AI별 품질 우열, 자동 설치, 성능 보장.

## 향후 출처 확보 시 기록할 항목

```text
자료 이름 / 정확한 URL / 확인 날짜:
직접 확인한 기능 또는 문구:
버전·지원 환경·의존성:
라이선스와 사용 조건:
여전히 확인하지 못한 항목:
```

현재는 빈칸을 추정으로 채우지 않는다. 설치·배포 판단은 실제 문서와 적용 환경을 확인한 뒤 진행한다.
