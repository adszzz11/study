# Cheatsheet — 탐색에서 적용까지

## 작업 순서

`목적 정의 → 화면 비교 → 효과 역할 검토 → 실제 prompt 읽기 → brief 보완 → AI 결과 대조 → 판단 기록`

## 핵심 질문

| 단계 | 질문 |
|---|---|
| 화면 | 어떤 정보를 먼저 보게 하는가? |
| 비교 | 위계·여백·타이포그래피·색상을 같은 기준으로 봤는가? |
| 효과 | 이 효과는 화면 안에서 어떤 역할을 맡는가? |
| 제거 비교 | 효과가 없어도 목적이 전달되는가? |
| AI 전달 | 실제 prompt에는 무엇이 포함되어 있는가? |
| 결과 | 원본과 닮았는가? 제품 목적에 맞는가? |

## 적용 전 체크

- [ ] 선택·제외 이유를 사용자 행동과 연결했다.
- [ ] 화면 구성과 개별 효과를 따로 평가했다.
- [ ] 적용 위치·범위·원하는 동작을 명시했다.
- [ ] 실제 환경의 가독성·입력 방해·성능을 확인했다.
- [ ] 설치법·API·의존성·지원 환경·라이선스는 실제 문서로 확인했다.
- [ ] 레퍼런스·선택 이유·적용 위치·수정 사항을 기록했다.

## 단정하지 말 것

- 썸네일 목록만으로 실제 navigation이나 user flow를 알 수 없다.
- 3D 큐브 그리드의 React Bits 소속은 확인되지 않았다.
- `Copy prompt`는 자동 설치·동일 결과·디자인 품질의 보증이 아니다.
- Claude Code·Codex·ChatGPT의 품질 우열은 이 자료로 비교할 수 없다.
- 레퍼런스를 많이 보는 것의 판단력 개선 효과는 검증되지 않았다.

## 짧은 판단 기록

```text
목적 / 참고 요소 / 선택 이유 / 적용 위치:
AI 결과에서 유지할 부분:
수정·제거할 부분과 근거:
미확인 사항과 다음 확인 작업:
```

이 체크리스트는 실습 제안이다. 확인 범위는 [[tech/devtools/ui-design-reference-exploration/03-references|References]], 전체 순서는 [[tech/devtools/ui-design-reference-exploration/README|학습 지도]]에서 확인한다.
