# Projects

## 1. B2B Admin 재설계

table filtering, bulk action, role/permission, audit-log 사례를 수집한다. 목표는 특정 화면을 닮게 만드는 것이 아니라 정보 밀도, state, recovery action의 결정을 개선하는 것이다.

**산출물:** 비교 matrix, role별 state map, original admin brief, accessibility checklist.

## 2. Activation 개선

SaaS onboarding, email verification, team invite flow를 비교한다. 단계 수, progress indicator, skip policy를 가설로 정리하고 activation metric과 함께 실험한다.

**질문:** 어느 단계에서 사용자가 멈추는가? skip을 제공했을 때 가치 전달이 약해지는가? 재개 경로는 명확한가?

## 3. Pricing / Upgrade 전환

pricing page, paywall, upgrade modal 사례를 조사해 value framing과 plan comparison 가설을 만든다. 가격·혜택·제한을 실제 제품 정책으로 검증하며, reference의 copy나 branding은 가져오지 않는다.

## 4. Design QA agent workflow

PR 또는 화면 명세마다 다음 산출물을 요구한다.

```text
1. 유사 flow 5개
2. 적용 가능한 pattern 3개와 근거
3. 우리 제품 제약으로 제외한 pattern
4. accessibility / originality checklist
```

이 workflow는 agent의 답을 승인하는 장치가 아니다. product·design reviewer가 pattern 선택과 저작권 경계를 검토할 수 있게 만드는 자료다.

## 5. 개인 / team reference library

agent 대화에서 유효한 사례를 collection에 저장한다. 주제별로 모으고, 각 저장 항목에는 용도와 제외 조건을 남긴다. 예: “bulk action의 selection feedback 참고; destructive action copy는 재사용하지 않음”.
