## 재확인 체크리스트

- endpoint, auth 방식, client별 `config.toml`/CLI 형식은 **로그인한 MCP 페이지**에서 복사한다.
- Pro 포함 범위, price, quota, library count는 결제 또는 운영 도입 직전에 다시 확인한다.
- client의 MCP 지원 상태와 local configuration path는 해당 client의 공식 문서에서도 확인한다.
