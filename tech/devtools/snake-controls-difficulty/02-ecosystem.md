# Ecosystem: 설계 대안 비교

## 비교 범위

자료에는 경쟁 제품이나 다른 Snake 구현이 소개되지 않는다. 아래 대안은 분석용 제안이며 영상의 구현 사실이 아니다.

| 항목 | 확인된 방식 | 검토 가능한 대안 | 판단 기준 |
|---|---|---|---|
| 조작 | 방향키 | 다른 키 매핑, 화면 버튼 | 대상 기기와 입력 편의성 |
| 성장 | 먹이 섭취 후 성장 | 성장량을 파라미터로 정의 | 진행 속도와 설명의 명확성 |
| 난이도 | 속도 증가 조건 | 고정 속도, 단계별 증가, 연속 증가 | 변화의 예측 가능성 |
| Trigger | 구체 내용 없음 | 먹이 개수, 점수, 경과 시간 | 성과와 난이도의 연결 |
| 검사 | Build·Check 반복 | 규칙별 Acceptance criteria | 일관된 판정 가능 여부 |

## 선택의 영향

- 고정 속도는 비교 실험의 기준이지만 최종 속도 증가 요구를 단독으로 충족하지 않는다.
- 단계별 증가는 임계값 도달 시 변화가 뚜렷하다. 임계값 중복 처리를 검사해야 한다.
- 연속 증가는 점진적인 변화를 만들 수 있다. 증가율과 최소 이동 간격을 정해야 한다.
- 먹이 개수 기반 Trigger는 섭취와 난이도를 연결한다. 시간 기반 Trigger는 먹이를 먹지 않아도 난이도가 상승할 수 있다. 둘 모두 선택 가능한 설계다.

## 비교 실습

조작과 성장 규칙을 고정하고 속도 정책만 바꾼다. 이동 간격과 체감 변화 시점을 함께 기록한다.
