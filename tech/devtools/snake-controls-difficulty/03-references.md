## 사실과 제안 구분

- **확인된 요구**: 방향키 조작, 먹이 섭취 후 성장, 속도 증가 조건.
- **미확인**: 성장과 속도 증가의 직접 관계, 충돌 정책, Engine, Framework.
- **학습용 제안**: 반대 방향 차단, 입력 큐, 단계식·연속식 속도 공식, 테스트 수치.
- **전용 금지**: 웹사이트 유사도 90%와 최대 6라운드는 Snake 난이도나 합격 기준의 근거가 아니다.

## 출처 보완 시 기록할 항목

원문 URL, 자료 제목, 발행자, 열람일, 관련 구간, 실제 요청 전문, 관찰 가능한 구현 동작을 기록한다. 확인 전에는 추정치를 사실로 바꾸지 않는다.
