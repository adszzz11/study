# Ecosystem: 표현과 검증 설계 비교

## 비교 범위

자료에 경쟁 제품이나 구체적인 monitoring 도구가 없어 제품별 기능·성능 비교는 할 수 없다. 아래 대안은 영상의 기능이 아닌 분석상 제안이다.

| 관점 | 관찰된 표현 | 설계 대안 | 판단상 차이 |
|---|---|---|---|
| 시스템 구성 | 중앙 JEV와 주변 Agent | 역할·작업 ID·의존성 그래프 | 위치와 업무 관계 구분 |
| 활동 표시 | 수치와 막대 증가 | 상태 이력·최근 갱신 시각 | 변화의 시점과 근거 확인 |
| 완료 판단 | 진행 막대 | 분모·완료 조건 명시 | 업무 완료와 연결 |
| 성과 판단 | 회사 운영 가능성 홍보 | 산출물·검증 결과 연결 | 주장과 확인 결과 분리 |
| 문제 파악 | 오류 표시 확인 불가 | 실패·재시도·대기 별도 표시 | 막힌 이유 추적 |

## 선택 기준

- 그래프는 관계의 의미를 설명할 때 사용한다. 노드 수를 실제 실행 주체 수로 간주하지 않는다.
- 패널은 정의가 고정된 집계 질문에 사용한다. 비용 증가와 성과 증가를 같은 색으로 처리하지 않는다.
- 막대는 전체 범위와 완료 조건을 설명할 수 있을 때 사용한다. 범위를 모르면 처리 건수와 상태를 표시한다.
- 시각적 풍부함보다 의미와 근거의 명확성을 우선한다.

제공 자료만으로 운영 도구인지 시연용 화면인지 확정할 수 없다.
