# References: 근거 범위와 추가 조사

## 제공 자료

| 항목 | 확보 상태 | 사용할 수 있는 범위 |
|---|---|---|
| 영상 00:00·00:05 요약 dossier | 제공됨 | 화면 요소와 두 시점의 변화 분석 |
| 원본 영상 URL·제목·제작자 | 미제공 | 원문 재확인 불가 |
| 지표 정의·실행 로그·산출물 | 미제공 | 구현·성능 평가 불가 |
| 제품 문서·저장소·벤치마크 | 미제공 | 제품별 비교 불가 |

영상 원본을 직접 검토한 기록이 아니라 제공된 요약을 바탕으로 작성했다. 원본 URL을 추정하거나 관련 없는 제품 문서를 근거로 대체하지 않는다.

## 추가 확보할 자료

- 원본 URL과 장면 맥락: 시연·녹화·실행 화면 여부.
- Metric 명세: 이름·단위·집계 범위·계산식·갱신 시각.
- Progress 명세: 전체 대상, 완료 조건, 실패·취소·재시도 처리.
- 실행 근거: task ID, attempt ID, 상태 이력, Agent 역할과 산출물 검증.
- 홍보 주장 검증: 실제 운영 업무 범위, 사람 개입, 실패 사례, 평가 기준.

## 인용 원칙

“화면에서 값이 증가한다”와 “업무 성과가 증가한다”는 별개다. 이후 자료를 추가할 때 URL·확인일·근거 장면을 남기고, 기존 관찰과 새로 검증된 사실을 구분한다.
