## 근거의 경계

- 이 study는 제공된 dossier 기반이며 현재 저장소를 재검증한 결과가 아니다.
- 사용자가 제공한 시작하기 내용은 “수동 설치 조건은 macOS 또”에서 끊겼다. 지원 OS의 전체 범위, runtime 버전, 설치 명령을 추정하지 않았다.
- Benchmark는 프로젝트 측 주장이다. 독립적 사람 평가, 통계적 유의성, 실제 장애 감소 효과는 확인할 수 없다.
- Show HN 게시물의 별도 URL·댓글은 제공되지 않았으므로 근거로 사용하지 않았다.
- 실습 제안은 학습용 설계이며 실행 결과가 아니다.
