# References: 근거와 미확인 정보

## 제공 자료

| 항목 | 확인 상태 |
|---|---|
| 자료 형태 | QA 테스트 12종 소개 영상의 수집 요약을 정리한 사용자 제공 dossier |
| 원본 제목·게시자·게시일 | 미제공 |
| 원본 URL·타임스탬프 | 미제공 |
| 직접 확인 가능한 범위 | 제공 dossier의 서술 |
| 외부 원본 대조 | 수행 불가: 식별 정보 없음 |

원본 영상이나 전체 발언을 직접 검증한 자료로 인용하지 않는다. 출처 URL 요구는 현재 자료만으로 충족할 수 없으므로 미제공 상태를 명시한다.

## 주장 구분표

| 구분 | 내용 | 기록 원칙 |
|---|---|---|
| 요약에 명시 | Alpha 내부 참여자, Beta 실제 사용자 | 제공 요약에 근거한다고 표기 |
| 분석 | 참여자 축과 검증 목적 축 분리 | 영상의 아키텍처나 규칙으로 표현하지 않음 |
| 제안 | 별도 기록 필드·경계 사례 토론·프로젝트 | 실습·운영 제안으로 표시 |
| 미확인 | 순서·환경·모집·인원·완료 기준·집단 중복 | 통상 관행으로 빈칸을 채우지 않음 |

## 원본 확보 후 확인할 질문

- Alpha/Beta의 참여 조건과 중복 여부를 실제로 정의하는가?
- 수행 순서, 공개 범위, 환경, 완료 기준을 언급하는가?
- acceptance testing과의 관계를 어떤 문장으로 설명하는가?
- 각 주장을 뒷받침하는 원본 URL과 타임스탬프는 무엇인가?

원본을 확보하면 확인된 문장과 위치를 기록하고, 현재 제안과 구분해 갱신한다.
