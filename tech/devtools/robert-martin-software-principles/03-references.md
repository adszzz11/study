# References: 근거와 검증 계획

## 현재 자료 상태

제공된 자료는 사용자 dossier 한 건이며 원문 URL, 페이지, 직접 인용이 없다. 아래 자료명은 후속 확인을 위한 후보이며 이 노트 작성 중 열람한 출처가 아니다.

| 후보 | 확인할 내용 | 상태 |
|---|---|---|
| Robert C. Martin, Clean Code | 이름·함수·책임에 대한 원래 맥락 | 원문·서지 확인 필요 |
| Robert C. Martin, Clean Architecture | Dependency Rule과 경계 사례 | 원문·서지 확인 필요 |
| Robert C. Martin, The Clean Coder | 전문성과 품질 책임의 맥락 | 원문·서지 확인 필요 |
| SOLID 원칙별 원전 | 개별 기원, Martin의 기여, 명칭 형성 | 확인 필요 |
| TDD 관련 원전·실증 연구 | 실천 방식과 효과의 조건 | 확인 필요 |

## 후속 조사 체크리스트

- [ ] 저자·공식 출판사 등 신뢰 가능한 원문 URL을 확보한다.
- [ ] 인용에는 판본·페이지 또는 정확한 원문 위치를 기록한다.
- [ ] SOLID 각각의 기원과 대중화 과정을 구분한다.
- [ ] 생산성·결함 감소 주장은 연구 조건과 한계를 함께 확인한다.
- [ ] 사례 관찰을 일반적인 인과 효과로 확대하지 않는다.

현재는 직접 인용과 수치 효과를 제시하지 않는다. 실습의 변경 파일 수·코드량도 프로젝트 내 관찰값으로만 취급한다.
