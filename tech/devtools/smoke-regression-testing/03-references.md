# References: 근거와 확인 한계

## 제공 자료

| 항목 | 확인 가능한 내용 |
|---|---|
| 자료 형태 | 사용자 제공 영상 요약 dossier |
| 시점 정보 | 00:10, 00:15 |
| 핵심 정의 | Smoke: 새 빌드 핵심 기능의 빠른 확인 / Regression: 변경 후 기존 기능 재점검 |
| 원본 URL·제목·게시자 | 미제공 |

시점별 원문과 정의의 정확한 대응은 확인할 수 없다. 원본을 직접 열람한 것으로 인용하지 않는다.

## 사실과 설계 제안 구분

- **자료의 설명:** 두 테스트의 목적, 빠른 확인과 기존 기능 재점검이라는 특성, 다른 QA 관점의 요약.
- **설계 제안:** 로그인 예시, 체크리스트, 실행 흐름, 결과 양식, 프로젝트와 완료 기준.
- **미확정:** 필수 실행 순서, 자동화 여부, 실행 주기, 통과 기준, 특정 구현 도구, Sanity / Load의 상세 정의.

## 원본 확보 후 확인할 항목

- [ ] URL·영상 제목·게시자를 기록한다.
- [ ] 00:10과 00:15의 실제 설명을 대조한다.
- [ ] 요약과 원문이 다른 부분을 수정한다.
- [ ] 추가 정의가 없다면 미확정 상태를 유지한다.

## Sources

- 사용자 제공 dossier: 영상 요약 및 시점 정보(00:10, 00:15). 원본 URL은 제공되지 않아 기재할 수 없다.
- 원본 영상의 제목·게시자·각 시점의 원문은 확인되지 않았다. 출처 URL을 추정하거나 다른 자료로 대체하지 않았다.
