# Ecosystem: 역할과 비교 범위

## 자료 속 역할

| 대상 | 자료 속 역할 | 비교 가능한 범위 | 판단할 수 없는 항목 |
|---|---|---|---|
| threeui | 디자인 예시와 에셋 카드 소개 | 참고 자료를 접하는 지점 | 코드 제공·export·라이선스·framework 호환성 |
| Codex | 붙여넣기 대상으로 언급 | 전달 대상 중 하나 | 입력 지원·구현 정확도·자동화 수준·비용 |
| Claude Code | 붙여넣기 대상으로 언급 | 전달 대상 중 하나 | 입력 지원·구현 정확도·자동화 수준·비용 |
| 그 밖의 대안 | 등장하지 않음 | 비교 근거 없음 | 제품 추천·우열 평가 |

Codex와 Claude Code는 같은 활용 문맥에서 제시되었다. 이것만으로 기능적 동등성이나 대체 가능성이 입증되지는 않는다. threeui와 개발 도구 역시 같은 역할의 경쟁 제품으로 비교할 근거가 없다.

## 비교 실험의 최소 조건

- 동일한 입력 원문·시각 자료·요구사항을 사용한다.
- 같은 프로젝트 기준 상태와 평가 항목을 사용한다.
- 도구·모델·설정·실행일과 환경 차이를 기록한다.
- 요구 충족 여부와 수정 부담을 관찰값으로 남긴다.
- 한 번의 실습을 도구 전체의 성능으로 일반화하지 않는다.
