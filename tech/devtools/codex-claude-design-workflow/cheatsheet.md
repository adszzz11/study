# Cheatsheet

## 기술스택 요약

- 디자인 참고 경로: threeui.com/browse에서 웹 디자인 예시와 에셋 카드가 소개됨.
- 개발 도구: Codex와 Claude Code가 붙여넣기 활용 대상으로 언급됨.
- 시각 요소: 키보드·책·꽃·타일 구체 예시와 애니메이션 배경이 등장함.
- 미확인: 복사 내용, framework, dependencies, 구현 절차와 결과.
- 적용 판단: 디자인 탐색과 도구 입력의 연결 방향은 보이지만 구현 가능성과 도구 간 우열은 검증되지 않음.

## 실행 전 체크

- [ ] 관찰 사실과 해석을 구분했는가?
- [ ] 복사 원문·형식·출처와 이용 조건을 확보했는가?
- [ ] 참고 입력과 구현 요청을 분리했는가?
- [ ] 프로젝트 환경과 실행 방법을 기록했는가?
- [ ] 정지 화면과 실제 동작의 완료 기준을 정했는가?
- [ ] 수동 수정 전후와 재시작 절차를 남길 수 있는가?

## 판단 경계

| 근거 | 허용되는 기록 | 확정하면 안 되는 주장 |
|---|---|---|
| 책 형태 카드 노출 | 책 형태의 카드가 보임 | source code·component 제공 |
| 타일 구체 예시 | 구체 모양의 시각 요소 | 3D rendering·특정 library 사용 |
| threeui라는 이름 | 서비스 이름 | Three.js 기반 stack |
| 두 개발 도구 언급 | 같은 전달 문맥 | 동등한 기능·비용·성능 |
| 애니메이션 배경 언급 | 동적 표현이 소개됨 | 구현 방식과 실행 성공 |

## 최소 기록 양식

```text
관찰 / 해석 / 미확인:
입력 원문·형식·출처:
구현 요청·완료 기준:
환경·도구·설정:
실행 결과·시각/동작 확인:
수동 수정·재시작 방법:
```

입력이 없으면 명세 작성까지 진행하고 재현은 미실행으로 표시한다. 모든 실습 양식은 학습용 제안이며 영상 속 실제 prompt가 아니다.
