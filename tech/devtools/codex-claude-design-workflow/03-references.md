# References: 출처와 근거 관리

## 확보된 자료

| 자료 | 현재 근거 | 사용 범위 |
|---|---|---|
| https://threeui.com/browse | dossier에 URL과 화면 관찰이 기재됨 | 디자인 탐색 경로 식별 |
| 사용자 제공 dossier | 영상 내용을 요약한 텍스트 | 관찰 사실과 미확인 사항 정리 |

사이트의 현재 기능을 직접 확인한 기록은 없다. 영상 원본 URL과 Codex·Claude Code 문서 URL도 수집 자료에 포함되지 않았다. 존재하지 않는 영상 링크나 추정한 문서 주소를 출처로 추가하지 않는다.

## 후속 확보 목록

- [ ] 영상 원본 URL, 확인 시점과 해당 장면의 timestamp
- [ ] 구현하려는 예시의 원본 시각 자료와 상세 페이지
- [ ] 실제 복사 원문, 형식, 복사 위치
- [ ] 참고 자료의 이용 조건·라이선스
- [ ] 사용하는 도구 버전의 공식 입력·실행 안내
- [ ] 프로젝트 환경, 실행 결과와 수정 기록

이 목록은 조사 계획이다. 해당 기능이나 자료가 제공된다는 보장은 아니다.

## 근거 기록 양식

```text
자료 URL:
확인 일시:
해당 장면 또는 위치:
직접 관찰한 내용:
해석:
아직 확인하지 못한 내용:
원문 또는 시각 자료 보관 위치:
```
