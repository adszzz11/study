# 시작하기: 관찰에서 전달 명세까지

## 목표와 준비물

목표는 디자인 요소 하나의 명세를 만드는 것이다. 아래는 영상 속 절차나 prompt의 재현이 아닌 **학습용 제안**이다. 현재 dossier만으로 관찰·미확인 사항을 정리할 수 있지만 정확한 외형 재현에는 원본 시각 자료가 필요하다.

## 1. 관찰과 추론 분리

| 관찰 기록 예시 | 별도로 확인할 사항 |
|---|---|
| 버튼이 보임 | hover·click 동작, 크기·색상 |
| 책 형태 카드가 보임 | 이미지인지 component인지, 복사 가능 여부 |
| 애니메이션 배경이 언급됨 | 움직임, 구현 방식, 실행 조건 |

이름이나 모양만으로 framework를 지정하지 않는다.

## 2. 실제 입력 확보

복사할 수 있는 내용이 실제로 있는지 확인한다. 확보되면 원문과 형식을 그대로 보관하고 출처와 이용 조건을 기록한다. 확보하지 못하면 `입력 미확보`로 남기며 붙여넣기 실행을 재현했다고 쓰지 않는다.

## 3. 입력과 요청 분리

다음은 학습용 요청 양식이며 영상 속 실제 prompt가 아니다.

```text
[참고 입력]
출처와 실제 확보한 원문/시각 자료:
입력 형식:

[구현 요청]
대상 요소 하나:
필수 형태와 배치:
필수 상호작용:
기존 프로젝트와 실행 방법:
완료 확인 기준:

[미확인 사항]
추가 확인이 필요한 부분:
구현자가 선택해도 되는 부분:
```

## 4. 완료 확인

- [ ] 관찰 사실과 추론을 구분했다.
- [ ] 확보된 입력과 미확보 입력을 표시했다.
- [ ] 요구사항과 임의 결정 영역을 명시했다.
- [ ] 정지 화면과 실제 동작의 확인 기준을 분리했다.
