# Cheatsheet

## 빠른 질문

| 축 | 확인 질문 | 남길 기록 |
|---|---|---|
| Usability | 무엇을 해야 하는지, 결과와 다음 단계를 이해하는가? | 혼란·망설임이 발생한 단계 |
| Accessibility: 스크린 리더 | 정보 파악과 기능 이용이 가능한가? | 환경·재현 단계·결과 |
| Accessibility: 큰 글자 | 정보 확인과 흐름 진행이 가능한가? | 설정·중단 지점·결과 |
| Security: 권한 우회 | 허용되지 않은 접근이 차단되는가? | 기대 권한·실제 접근 결과 |
| Security: 정보 유출 | 보호 대상 정보가 노출되는가? | 보호 대상·실제 노출 결과 |

## 점검 흐름

```text
기능과 목표 선택 → 기본 동작 → 다섯 항목별 기대/관찰 → 결함 기록 → 재점검
```

이 순서는 자료를 바탕으로 한 실습 제안이다.

## 혼동 방지

- 기능 작동 ≠ 사용성·접근성·보안 통과.
- 스크린 리더 통과 ≠ 큰 글자 통과.
- 권한 점검 완료 ≠ 정보 유출 점검 완료.
- 관찰 결과 ≠ 구현 원인 확정.
- 자료의 접근 지원 두 항목 ≠ 접근성 전체 범위.
- 점검 미수행 = 미확인. 통과로 기록하지 않는다.

## 최소 기록

`기능 / 빌드·환경 / 관점·조건 / 기대 / 단계 / 관찰 / 추정 / 판정 / 재점검`

정식 절차·표준·자동화 도구·정량 기준은 제공 자료에서 확인되지 않는다.
