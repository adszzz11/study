# References와 근거의 경계

## 제공 자료

| 자료 | 확인 가능한 내용 | 확인할 수 없는 내용 |
|---|---|---|
| 사용자 제공 dossier의 QA 영상 요약 | 세 테스트의 점검 대상, 다른 QA 테스트의 간략한 설명 | 원본 URL, 정확한 인용 위치, 정식 절차·표준·도구·버전·정량 기준 |

## 서술 원칙

- **자료에서 확인:** Usability는 혼란 없는 흐름, Accessibility는 스크린 리더·큰 글자, Security는 권한 우회·정보 유출을 다룬다.
- **학습용 해석:** 같은 기능을 세 관점으로 반복 점검하고 기대 결과·관찰·재점검을 분리한다.
- **미확인:** 특정 도구가 영상에서 권장되었다거나 두 접근 지원 조건이 접근성의 전부라는 주장은 할 수 없다.

## 원본 확보 후 보완할 항목

- [ ] 원본 URL·제목·발행일과 인용 구간 확인
- [ ] 요약의 표현과 원본 설명 대조
- [ ] 추가 표준이나 도구를 소개한다면 별도 출처를 명시

원본 미제공 상태에서 임의의 URL을 출처로 채우지 않는다.
