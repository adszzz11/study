# References: 근거와 확인 한계

## 원자료 상태

제공된 dossier는 영상 관찰을 정리한 자료다. 원영상 URL, 게시자, 게시일, 타임스탬프가 없어 원자료를 직접 확인하거나 특정 장면을 인용할 수 없다. 원자료 URL과 실제 Figma 참조 URL도 서로 다른 정보이며 둘 다 제공되지 않았다.

| 주장 | 근거 수준 | 노트에서의 취급 |
|---|---|---|
| MeetBook 예약 캘린더와 강조 영역 등장 | dossier의 관찰 기록 | 사례 맥락 |
| 명령과 Figma URL 입력 | dossier의 관찰 기록 | 입력 흐름만 설명 |
| 속성 비교표·전후 탭 등장 | dossier의 관찰 기록 | 검토 수단으로 설명 |
| API·plugin·MCP 사용 | 근거 없음 | 추정하지 않음 |
| 전체 자동 적용·코드 변경·배포 | 근거 없음 | 완료 사실로 서술하지 않음 |
| 반복 실행의 일관성 | 미검증 | 후속 실습 과제로 제안 |

## 추가로 확보할 자료

- 원영상 URL과 해당 장면의 타임스탬프.
- 명령 구현 제품의 공식 문서, 지원 버전 및 실행 환경.
- 실제 Figma 참조 범위와 접근 권한 설명.
- 변경 항목 기록, 비교표의 기준, 미적용 항목 및 복원 절차.

공식 Figma 사이트 자체는 이 사례의 custom workflow 존재나 정확성을 증명하지 않는다. 근거가 추가되면 관찰·해석·실습 제안을 구분해 갱신한다.
