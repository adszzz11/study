# Ecosystem: 검토 방식 비교

## 비교 범위

수집 자료에는 경쟁 제품이나 외부 대안이 없다. 다음 표는 제품의 우열이 아니라 **검토 관점의 역할**을 비교한다.

| 방식 | 보는 대상 | 역할 | 미확인 |
|---|---|---|---|
| 프로토타입 중심 논의 | 예약 캘린더·강조 영역 | 논의할 화면 맥락 제공 | 의견 기록·승인 방식 |
| 속성 비교표 | 색상·텍스트 스타일·변수 | 차이를 항목별로 구체화 | 비교 기준·자동 생성·누락 탐지 |
| 디자인·컴포넌트·토큰 관점 | 화면과 구성 기준 | 서로 다른 검토 관점 제공 | 매핑·변경 전파 |
| 전후 디자인 탭 | 적용 전후 화면 | 변화가 화면에 드러나는지 확인 | 이력·복원·승인 기능 |

## 함께 사용하는 방법

1. 화면으로 논의 대상을 정한다.
2. 비교표로 차이를 구체화한다.
3. 컴포넌트·토큰 연결 여부를 질문한다.
4. 전후 화면에서 속성 변화와 시각적 결과를 대응시킨다.

각 방식은 상호 보완적이다. 실제 도구에서 이들이 자동 연결된다는 근거는 없다. 제품 선택을 하려면 지원 환경, 참조 접근 범위, 변경 가능 항목, 복원 방식 등을 추가 조사해야 한다.
