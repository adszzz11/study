# Cheatsheet: 빠른 점검

## 흐름

```text
대상 화면·영역 기록
  → Figma 참조 URL·범위 확인
  → 지원 환경에서 명령 입력
  → 색상·텍스트 스타일·변수 비교
  → 전후 화면과 대응
  → 불일치·미확인 항목 기록
```

## 입력과 확인 한계

| 항목 | 요약 |
|---|---|
| 입력 | Figma 디자인 URL + `/apply-ds-to-prototype` |
| 사례 대상 | MeetBook 예약 캘린더 프로토타입 |
| 비교 | 색상 코드, 텍스트 스타일, 디자인 변수 |
| 검토 | 디자인·컴포넌트·토큰 항목, 전후 탭 |
| 미확인 | 실행 도구, 연동 방식, 모델, 코드 변경, 자동 적용 범위 |

명령은 영상 관찰에 나온 이름이다. 공식 Figma 기능이나 범용 실행 명령으로 취급하지 않는다.

## 검토 체크리스트

- [ ] 논의 영역과 변경 영역을 구분했는가?
- [ ] 링크가 가리키는 디자인과 읽을 수 있는 범위를 확인했는가?
- [ ] 색상·텍스트·변수를 각각 비교했는가?
- [ ] 값의 일치와 컴포넌트·토큰 연결을 구분했는가?
- [ ] 전후 화면에서 비교 결과를 확인했는가?
- [ ] 변경되지 않은 항목과 미확인 항목을 남겼는가?

## 피해야 할 추론

| 관찰 | 바로 단정할 수 없는 내용 |
|---|---|
| Figma URL 입력 | API·plugin·MCP 사용 |
| 비교표 표시 | 모든 차이 자동 수정 |
| 화면 변경 | 전체 컴포넌트·토큰 일관성 |
| 전후 탭 존재 | 이력·복원·승인 기능 |
| 명령 이름 | Figma 공식 명령 |
