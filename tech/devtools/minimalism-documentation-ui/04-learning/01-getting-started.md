# 시작하기 — 관찰과 Visual hierarchy

## 목표와 준비

짧은 기술 문서 하나를 준비한다. 제목, 2~3개 절, 본문, 보조 설명, 링크를 포함하면 된다. 도구는 자유롭게 선택하며 원본 구현을 재현했다고 주장하지 않는다. 아래 과정은 dossier에서 도출한 학습 제안이다.

## 1. 관찰과 추론 분리

| 기록 | 분류 |
|---|---|
| “자료는 옅은 색의 기술 문서라고 설명한다.” | 관찰 요약 |
| “본문에 집중할 수 있을 것 같다.” | 해석 |
| “특정 절을 더 빨리 찾을 수 있다.” | 측정할 가설 |

## 2. 의미 구조 먼저 정하기

- 문서의 H1과 절 제목의 관계를 정한다.
- 본문과 보조 설명의 역할을 명시한다.
- 링크의 목적을 문맥이나 링크 텍스트로 이해할 수 있게 한다.

## 3. 위계를 화면에 표현하기

- 제목·본문·보조 설명을 typography와 spacing으로 구분한다.
- 색을 줄여도 제목과 절의 경계를 찾을 수 있는지 살핀다.
- 링크의 식별 단서를 유지하고 keyboard focus를 표시한다.
- 옅은 색은 선택 가능한 표현이며 필수 요건이 아니다.

## 4. 작은 과제로 확인하기

1. 지정한 절을 찾는다.
2. 핵심 설명을 찾는다.
3. 링크를 식별하고 키보드로 이동한다.

```text
변경 요소:
유지한 의미 관계:
기대 효과(가설):
과제 / 관찰 결과:
사라진 단서 / 다음 수정:
```
