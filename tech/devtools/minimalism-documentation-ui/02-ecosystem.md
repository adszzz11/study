# Ecosystem — 시각적 대안 비교

## 비교 범위

자료는 제품 생태계나 시장 경쟁 관계를 설명하지 않는다. 아래는 영상에 함께 등장했다고 dossier가 설명한 스타일의 비교다.

| 스타일 | 예시 | 표현 단서 | 판단 한계 |
|---|---|---|---|
| Skeuomorphism | 흰색 오디오 제어 화면 | 노브, 슬라이더 | 실제 조작감·사용성 미확인 |
| Minimalism | 옅은 색의 기술 문서 웹페이지 | 옅은 색, 문서 중심 화면 | navigation·typography 구체 설명 없음 |
| Liquid Glass | 보라색·파란색 음악 앱 목업 | 반투명 패널 | 가독성·rendering cost 판단 불가 |
| Spatial UI | 어두운 의료 대시보드 | 붉은 해부학적 심장, 건강 지표 | 실제 3D interaction·공간 추적 미확인 |

## 비교의 한계

스타일과 콘텐츠·사용 과업이 동시에 달라진다. 기술 문서와 음악 앱 사이의 차이를 스타일만의 효과로 분리할 수 없다. 따라서 이 자료는 시각적 차이를 이해하는 출발점이며 Minimalism의 우수성이나 업무 적합성을 입증하지 않는다.

## 공정한 비교 설계

- 동일 문서, 기능, 정보 순서, viewport를 유지한다.
- 배경·구분선 등 비교할 표현 요소를 명시하고 변경 목록을 남긴다.
- 같은 정보 찾기 과제를 수행해 시간, 오류, 혼동 지점을 기록한다.
- 미적 선호와 과제 수행 결과를 별도로 수집한다.
- 참여자가 두 화면을 모두 보면 순서 효과를 줄이도록 제시 순서를 바꾼다.
