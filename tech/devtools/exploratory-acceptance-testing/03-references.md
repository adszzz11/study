# References: 근거와 추가 확인

## 원자료 상태

제공 dossier는 영상에서 설명한 테스트 유형을 정리한 자료다. 원본 URL·제목·게시일이 없어 직접 열람·인용 위치 확인은 할 수 없다. URL을 추정하거나 추가 자료를 원본 영상인 것처럼 표시하지 않는다.

## 주장과 근거 구분

| 구분 | 노트에 반영한 내용 | 해석 범위 |
|---|---|---|
| 자료의 설명 | 탐색은 발견, 인수는 기준에 따른 출시 준비 확인 | 제공된 요약에 한정 |
| 정의에서 도출한 해석 | 발견한 문제와 관련 기준 연결 | 공식 프로세스가 아님 |
| 학습용 제안 | 기록표, 두 활동 실습, 프로젝트 | 표준 절차·필수 산출물이 아님 |
| 미제공 | 도구, 자동화, 비용·시간, 효과 수치, 승인자 | 추정하지 않음 |

## 추가 조사 질문

- 원본 영상 URL과 각 정의가 등장하는 시점은 무엇인가?
- 실제 팀의 고객·기획 기준과 승인 책임은 어디에 기록되어 있는가?
- ISTQB Glossary에서 exploratory testing, acceptance testing을 검색했을 때 제공 요약과 어떤 표현 차이가 있는가?

추가 용어집은 개념 확장용이다. 제공 자료의 단순화된 정의를 보편적인 상세 정의 전체로 취급하지 않는다.
