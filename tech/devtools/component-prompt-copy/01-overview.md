# Overview — What / Why / 특징

## What

컴포넌트 상세 페이지의 ‘Copy prompt’ 메뉴에서 AI 도구를 선택해 사용할 요청문을 복사하도록 제공하는 UI다. 자료에는 메뉴가 보이지만, 클릭 이후 Clipboard에 무엇이 들어가는지는 제시되지 않았다.

## Why

영상은 AI를 잘 활용하지만 미적 판단이 부족한 신입 디자이너에 관한 질문에서 출발한다. 앱·인터페이스 썸네일 갤러리와 모바일 화면 레퍼런스, React Bits의 ‘Paper Crumple’, 3D 큐브 그리드 페이지가 이어진다.

이 맥락에서 기능의 가치는 선택한 시각적 대상을 다시 문장으로 설명하는 부담을 줄일 가능성이다. 설명 시간 감소와 구현 정확도 향상은 아직 검증되지 않았다. **선택의 적절성**과 **구현의 편의**는 구분해야 한다.

## 관찰된 특징

| 항목 | 확인 내용 | 확인되지 않은 부분 |
|---|---|---|
| 위치 | 3D 큐브 그리드 컴포넌트 페이지 | 다른 페이지의 제공 여부·사이트 소속 |
| UI | Copy prompt 메뉴 | 클릭 결과·복사 성공 여부 |
| 대상 | Claude Code, Codex, ChatGPT 등 | 전체 목록·지원 버전·호환성 |
| 맥락 | 컴포넌트 설명과 함께 제공 | 설명·코드·링크·이미지 포함 여부 |
| 인접 사례 | React Bits Paper Crumple 미리보기 | 큐브 페이지와 동일 제품인지 여부 |

## 개념적 흐름

```text
컴포넌트 탐색 → 상세 확인 → AI 도구 선택 → Copy prompt → 선택한 도구에서 활용
```

관찰된 UI를 설명하기 위한 개념 모델이며 내부 구현 아키텍처가 아니다.

- **컴포넌트 맥락:** 일반 질문보다 특정 시각적 대상을 출발점으로 한다.
- **도구 선택:** 메뉴의 도구명이 다르더라도 payload가 다르다고 단정할 수 없다.
- **작업 전달:** 복사 메뉴만으로 API 호출·도구 실행·파일 수정까지 수행한다고 해석할 수 없다.

## 평가의 핵심

payload가 외형·동작·설치 조건·검증 기준을 얼마나 구체적으로 담는지 확인해야 한다. framework와 backend, Clipboard API 사용 여부를 포함한 기술스택은 자료만으로 알 수 없다.
