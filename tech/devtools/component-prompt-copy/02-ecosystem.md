# Ecosystem — 레퍼런스와 전달 방식 비교

## 역할별 비교

제품 성능 순위가 아니라 dossier에 등장한 자원과 작업 방식의 역할을 비교한다.

| 자원·방식 | 주된 역할 | AI 작업과 연결 | 자료상 판단 |
|---|---|---|---|
| 앱·인터페이스 썸네일 갤러리 | 여러 화면 탐색 | 원하는 방향 선택의 출발점 | 등장 확인 |
| 모바일 앱 화면 레퍼런스 | 구성과 표현 참고 | 요청의 시각적 맥락으로 활용 가능 | 페이지 등장 확인 |
| React Bits Paper Crumple | 특정 시각 효과 확인 | 효과 설명의 참고 대상 | 미리보기 확인 |
| 큐브 그리드 Copy prompt | 컴포넌트 관련 요청 복사 | AI 도구 대상 전달 UI | 메뉴·도구명 확인 |
| 직접 요청문 작성 | 요구사항 직접 표현 | 사용자가 설명 범위 결정 | 비교용 방식, 영상 속 기능은 아님 |

## 서로 다른 문제

레퍼런스 갤러리는 “무엇을 참고할 것인가”, 프롬프트 복사는 “선택한 대상을 어떻게 전달할 것인가”에 가깝다. 두 단계가 연결돼도 최종 디자인 적합성이 보장되지는 않는다.

Claude Code, Codex, ChatGPT는 **메뉴의 대상 도구**다. 이 관찰로 세 도구의 실행 방식, 구현 능력, 결과 품질, 호환성을 비교할 수 없다. React Bits에서 같은 복사 기능을 제공한다고 추론해서도 안 된다.

## 비교 시 기록할 항목

- 원본 특징을 설명하는 데 필요한 수작업의 양.
- 도구별 payload의 공통 부분과 차이.
- 프로젝트 제약을 보완해야 하는 정도.
- 재현 정확도와 화면 목적에 맞는 정도를 각각 평가.
