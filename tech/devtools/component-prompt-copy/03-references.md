# References — 근거와 확인 대기 항목

## 현재 확보된 자료

사용자 제공 dossier만을 근거로 작성했다. 원본 영상, 갤러리, 컴포넌트 페이지의 URL과 실제 복사 텍스트는 없다. 따라서 독립적으로 원문을 재현·검증한 조사로 간주하지 않는다.

| 대상 | 확보된 정보 | 추가로 필요한 자료 |
|---|---|---|
| 영상 | 질문의 배경과 등장 화면 요약 | 원본 URL·게시 시점·해당 시점 |
| 큐브 그리드 | Copy prompt 메뉴·일부 도구명 | 정확한 페이지 URL·메뉴 전체·실제 payload |
| React Bits | Paper Crumple 미리보기 | 해당 페이지 URL·큐브 페이지와의 관계 |
| 구현 실험 | 제안만 존재 | 실행 환경·원본 요청·결과·수정 기록 |

## 출처 확보 후 확인 순서

1. 원본 영상과 화면의 시점을 기록한다.
2. 큐브 그리드 페이지의 정확한 URL과 사이트 소속을 확인한다.
3. 각 도구의 payload를 원문 그대로 확보하고 수집일을 남긴다.
4. 페이지가 바뀌었을 가능성을 고려해 영상 관찰과 현재 동작을 분리한다.
5. 확인한 사실만 노트에 반영하고, 미확인 항목은 유지한다.

```text
자료명:
원본 URL: 미확보
관찰 시점 / 수집일:
확인된 사실:
미확인 항목:
```
