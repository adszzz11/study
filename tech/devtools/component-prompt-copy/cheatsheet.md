# Cheatsheet — 빠른 참조

## 기억할 구분

| 구분 | 현재 판단 |
|---|---|
| 관찰 | 큐브 그리드 페이지의 Copy prompt 메뉴와 일부 도구명 |
| 가능성 | 시각적 대상을 다시 설명하는 부담 감소 |
| 미검증 | 시간 절감·구현 정확도 향상·도구별 최적화 |
| 미확인 | payload·Clipboard 동작·framework·backend·API 연동 |
| 별도 판단 | 컴포넌트 선택·화면 목적·시각적 조화 |

## 적용 순서

```text
미리보기 확인 → payload 읽기 → 도구별 비교 → 프로젝트 조건 보완
→ AI에서 활용 → 외형·동작 검증 → 디자인 적합성 검토
```

개념적 작업 순서이며 사이트의 내부 구현이나 실제 실행 결과를 나타내지 않는다.

## 복사 전후 체크리스트

- [ ] 페이지 URL과 수집일을 확보했는가?
- [ ] 복사 성공과 원본 텍스트를 직접 확인했는가?
- [ ] 설명·코드·링크·설치·검증 기준 포함 여부를 구분했는가?
- [ ] 선택 도구별 내용이 실제로 다른지 비교했는가?
- [ ] 원본 관찰과 프로젝트 요구사항을 분리했는가?
- [ ] 요청 준비 시간과 후속 수정 작업량을 함께 기록했는가?
- [ ] 재현과 디자인 적합성을 별도로 평가했는가?

## 피해야 할 해석

- 메뉴가 있다는 이유만으로 도구 자동 실행이나 파일 수정을 추정하지 않는다.
- 인접한 React Bits 미리보기를 큐브 페이지의 소속 증거로 쓰지 않는다.
- 미실행 항목을 성공·실패·0회로 기록하지 않는다.
- 도구명 목록을 성능 순위나 호환성 보장으로 해석하지 않는다.
