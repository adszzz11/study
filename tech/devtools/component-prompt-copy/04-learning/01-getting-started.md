# 시작하기 — 복사 내용부터 확인하기

## 실습 전제

아래는 **실습 제안**이다. 실제 사이트에 접속하거나 프롬프트를 복사해 얻은 결과가 아니다. 페이지 URL을 확보하지 못하면 관찰 기록과 비교 양식까지만 준비하고 실행 결과는 비워 둔다. 특정 package 설치나 CLI 명령을 추정하지 않는다.

## 첫 실습 순서

1. 접근 가능한 컴포넌트 페이지를 확보하고 URL·수집일·선택 이유를 기록한다.
2. 미리보기의 형태, 배치, 움직임을 자신의 표현으로 기록한다.
3. Copy prompt에서 제공되는 도구를 선택하고, 복사 결과를 텍스트로 먼저 읽는다.
4. 설명·코드·링크·설치 지침이 포함되는지 구분한다. 메뉴 클릭과 복사 성공을 따로 기록한다.
5. 프로젝트의 framework, 크기, 입력 방식, 반응형 조건과 payload의 조건을 대조한다.
6. 목표 도구에 전달할 때 원본 payload와 사용자가 추가한 지시를 구분해 보존한다.

## 관찰과 요구사항 분리

| 구분 | 기록 예시 — 원본 사실이 아닌 양식 예시 |
|---|---|
| 관찰 | 큐브의 배열, 회전 방향, 움직임의 시작 조건 |
| 프로젝트 요구 | 모바일 화면, 터치 입력, 필요한 크기 |
| 미확인 | 애니메이션 구현 방식, 의존성, 복사 텍스트의 내용 |

```text
컴포넌트 / URL:
선택 도구 / 수집일:
원본 payload:
포함 정보: 설명 [ ] 코드 [ ] 링크 [ ] 설치 [ ] 검증 기준 [ ]
유지할 외형·동작:
프로젝트 조건:
추가 지시:
실행 여부 / 결과:
```

## 완료 기준

- [ ] 원본 payload와 추가 요구사항을 분리했다.
- [ ] 실제로 확인한 내용과 미확인 항목을 표시했다.
- [ ] 시각적 재현과 디자인 적합성을 별도로 검토할 준비가 됐다.
