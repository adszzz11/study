# Projects: 시각적 피드백 적용

아래 프로젝트는 dossier에서 확장한 실습 제안이다. 영상에 해당 도구가 실제로 존재했다는 뜻은 아니다.

## 1. 모션그래픽 재현 피드백 로그

- 목표: 녹화를 수정 요청으로 바꾸는 과정을 재현 가능하게 만든다.
- 산출물: 기준·구현·수정 후 녹화, 차이 목록, 수정 요청, 최종 판정.
- 기록: 대상 요소, 문제 구간, 기대 동작, 수정 내용, 재검토 결과.
- 진행: 한 동작 선택 → 조건 기록 → 차이 한 종류 수정 → 재녹화.
- 완료 기준: 사전에 정한 주요 차이가 해결되었는지 사람이 확인하고 판정 이유를 남긴다.

## 2. 화면 비교 검토 보조 도구

- 목표: 제3자가 같은 문제 구간을 찾아낼 수 있게 한다.
- 핵심 기능: 나란히 재생, 일시정지, 구간 반복, 시점별 메모.
- 설계 과제: 서로 다른 영상의 공통 시작 이벤트와 시간 오프셋을 정의한다.
- 산출물: 비교 화면 설계, 두 녹화의 시점 대응표, 문제 메모.
- 완료 기준: 제3자가 기록된 구간과 설명만으로 같은 문제를 찾는다.

## 3. 검증 단계를 포함한 자동 수정 실험

- 목표: 자동 수정의 범위를 단계별로 평가한다.
- 진행: 차이 설명 → 수정 제안 → 변경 적용 → 재검토.
- 산출물: 각 단계의 입력·출력·수행 주체·성공 여부, 변경 내역, 재녹화.
- 완료 기준: 적용 성공과 품질 통과를 따로 기록하고, 실패·판단 보류 사례도 남긴다.
- 주의: 진행률을 프레임 일치율이나 테스트 통과율로 해석하지 않는다.
