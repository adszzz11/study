# References

## 원자료 상태

제공된 dossier에는 원본 URL이 없다. 영상, 갤러리, Paper Crumple 상세 페이지, 큐브 그리드 상세 페이지의 주소를 추정해 기재하지 않는다.

| 자료 | 현재 확인 수준 | 추후 확보할 내용 |
|---|---|---|
| 디자인 참고 영상 | 질문의 배경과 등장 화면 요약 | 원본 URL, 게시일, 해당 타임스탬프 |
| 화면 갤러리·모바일 레퍼런스 | 화면 모음이 등장 | 서비스명, 화면 출처, URL |
| React Bits — Paper Crumple | 미리보기 등장 | 상세 URL, 코드, API, 사용 조건 |
| 3D 큐브 그리드 페이지 | 설명과 Copy prompt 대상 메뉴 | 소속, 상세 URL, prompt 원문 |

## 보충 학습 자료

- React Learn: https://react.dev/learn — 컴포넌트와 UI 구성의 기초 학습.
- React 접근성 HTML 속성 참고: https://react.dev/reference/react-dom/components/common — DOM 공통 속성 참고. 개별 효과가 접근성을 충족한다는 증거는 아니다.

## 출처 기록 원칙

1. 직접 확인한 페이지의 URL과 확인 날짜를 적는다.
2. 화면에서 본 사실과 구현에 관한 가설을 분리한다.
3. 공식 문서·소스·라이선스를 확인하기 전에는 설치 명령이나 지원 버전을 확정하지 않는다.
4. prompt 원문을 확보하면 도구별 내용과 수정 요구를 실제 텍스트로 비교한다.
