# 참고 수단과 활용 접점 비교

## 비교 범위

수집 자료에 경쟁 라이브러리 정보가 없어 제품 순위를 만들지 않는다. 화면 갤러리, 개별 컴포넌트, AI 도구는 역할이 서로 다르다.

| 대상 | 확인된 내용 | 활용 관점 | 미확인 사항 |
|---|---|---|---|
| 앱·인터페이스 썸네일 갤러리 | 여러 화면의 썸네일 | 전체 시각 방향 탐색 | 사이트명, 분류, 코드 제공 |
| 모바일 앱 화면 레퍼런스 | 모바일 화면 나열 | 정보 배치·화면 구성 관찰 | 전환, 실제 상호작용, 출처 |
| React Bits — Paper Crumple | 효과 미리보기 | 개별 효과 후보 검토 | API, 의존성, 구현 방식, 사용 조건 |
| 3D 큐브 그리드 페이지 | 설명과 Copy prompt 메뉴 | 효과 탐색과 AI 활용 연결 | 소속, 렌더링 기술, prompt 본문 |
| Claude Code·Codex·ChatGPT | Copy prompt 대상으로 표시 | 복사한 지시문 활용 | 결과 품질, 지원 범위, 자동화 수준 |

## 선택 기준

- 화면 구성이 고민이면 화면 레퍼런스에서 정보 위계와 여백을 관찰한다.
- 개별 표현이 필요하면 컴포넌트 미리보기에서 목적에 맞는 후보를 찾는다.
- 구현을 요청하려면 prompt 본문, 코드 확보 경로, 사용 조건과 수정 범위를 먼저 확인한다.

이 기준은 제안하는 활용 방법이다. 도구별 우열이나 공식 지원 범위를 의미하지 않는다.
