# 시작하기: 관찰에서 적용 목적까지

## 학습 목표

전체 화면의 맥락과 개별 효과의 인상을 구분하고, 적용 목적을 설명한다. 아래 절차는 제안한 연습이며 서비스의 실제 기능 목록이 아니다.

## 1. 관찰 대상을 분리한다

| 대상 | 기록할 것 | 피할 판단 |
|---|---|---|
| 전체 화면 | 정보 위계, 배치, 여백, 핵심 행동 | 화면 이미지만으로 실제 사용성 확정 |
| 효과 미리보기 | 보이는 형태, 시선이 향하는 위치 | 이름만으로 동작·구현 기술 추정 |

## 2. 효과의 역할을 한 문장으로 쓴다

장식, 핵심 영역 강조, 상호작용 피드백 중 필요한 역할을 정한다. 예를 들어 “소개 화면의 핵심 메시지 주변에 시선을 모으기 위한 후보로 검토한다”처럼 목적을 적는다. 이는 적용 가설이며 효과의 검증된 기능이 아니다.

```text
후보: Paper Crumple / 3D 큐브 그리드
관찰한 사실:
적용하려는 화면과 위치:
효과의 목적:
기대하는 변화:
미확인 사항:
적용을 포기할 조건:
```

## 3. 사실과 가설을 구분한다

- 사실: 큐브가 그리드 형태인 표현을 설명하는 페이지가 등장한다.
- 가설: 특정 3D 엔진으로 구현했을 것이다.
- 처리: 엔진은 미확인으로 기록하고 원본 문서에서 확인한다.

## 4. 구현 전 조건을 확인한다

- [ ] 실제 코드 확보 경로와 사용 조건 확인
- [ ] React 버전·의존성·API·프로젝트 호환성 확인
- [ ] Copy prompt 원문과 요청하는 설치·수정 범위 확인
- [ ] 동일 콘텐츠로 비교할 기본 화면 준비

자료에는 설치 방법과 API가 없으므로 실행 가능한 서비스별 코드는 제시하지 않는다.
