# Cheatsheet

## 빠른 구분

| 개념 | 기억할 점 |
|---|---|
| 화면 레퍼런스 | 정보 위계·배치·맥락 관찰 |
| 효과 미리보기 | 개별 표현의 후보 탐색 |
| Copy prompt | AI 도구로 지시문을 전달하는 접점 |
| 구현 완료 | 코드와 실제 결과를 별도로 검증해야 함 |

## 사실 / 미확인

- **확인**: React Bits의 Paper Crumple 미리보기가 등장한다.
- **확인**: 3D 큐브 그리드 페이지에 Claude Code·Codex·ChatGPT 대상 Copy prompt 메뉴가 있다.
- **미확인**: 큐브 그리드 페이지의 소속, prompt 본문·도구별 차이, 자동화 수준.
- **미확인**: React 버전, API, 렌더링 엔진, 의존성, 라이선스, 성능.

## 적용 체크리스트

- [ ] 효과의 목적을 한 문장으로 설명했다.
- [ ] 관찰과 구현 가설을 분리했다.
- [ ] 원본 페이지·코드·사용 조건을 확보했다.
- [ ] API·의존성·프로젝트 호환성을 확인했다.
- [ ] prompt의 설치 요청·수정 범위를 검토했다.
- [ ] 동일 콘텐츠·레이아웃으로 효과 유무를 비교했다.
- [ ] 가독성·주의 분산·입력 방해를 확인했다.
- [ ] 성능·접근성을 실제 환경에서 검증했다.

```text
목적 → 화면 맥락 → 후보 관찰 → 미확인 사항 조사
     → prompt 검토 → 구현 → 동일 조건 비교 → 도입 판단
```

위 흐름은 학습용 제안이다. 영상에서 제시한 공식 절차나 컴포넌트 내부 아키텍처가 아니다.
