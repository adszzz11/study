# 실전 프로젝트

## 1. 시각 효과 선정 노트

Paper Crumple과 3D 큐브 그리드를 후보로 검토한다.

- **산출물**: 후보별 적용 목적, 예상 위치, 기대 효과, 미확인 사항.
- **진행**: 화면 목적 정의 → 후보 관찰 → 적용 가설 작성.
- **평가 기준**: 외형 선호와 화면에 필요한 기능을 구분했는가?
- **제약**: 동작·설정·구현 기술을 추정해 사실로 기록하지 않는다.

| 후보 | 목적·위치 | 기대 효과 | 현재 미확인 |
|---|---|---|---|
| Paper Crumple | 직접 작성 | 직접 작성 | 동작, API, 의존성, 사용 조건 |
| 3D 큐브 그리드 | 직접 작성 | 직접 작성 | 소속, 엔진, API, 사용 조건 |

## 2. 효과 적용 전후 비교 화면

한 화면의 기본 버전과 효과 버전을 같은 콘텐츠·레이아웃으로 준비한다.

- **실행 전**: 코드 확보 경로, 라이선스 등 사용 조건, 의존성, 프로젝트 호환성을 확인한다. 현재 자료로 충족된 조건은 아니다.
- **산출물**: 비교 화면과 관찰 기록, 환경·변경 범위.
- **평가 기준**: 핵심 정보가 더 잘 드러나는가? 읽기와 조작에 방해가 생기는가?
- **완료 조건**: 성능·접근성을 포함한 검증 결과와 유지·축소·제거 결정을 근거와 함께 남긴다.

## 3. AI prompt 전달 과정 검토

실제 큐브 그리드 페이지와 prompt 본문을 확보한 후 진행한다.

- **진행**: 원문 보존 → 추가 요구사항 기록 → 구현 요청 → 변경 내용과 결과 검토.
- **산출물**: 원본 prompt, 추가 요구사항, 결과 차이와 수정 범위 기록.
- **평가 기준**: 요청한 표현이 재현되는가? 변경이 허용 범위 안에 있는가?
- **제약**: dossier만으로 Claude Code·Codex·ChatGPT의 적합성 순위를 정하지 않는다.
