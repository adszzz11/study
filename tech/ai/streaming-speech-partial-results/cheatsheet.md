# Cheatsheet

## 핵심 구분

| 용어 | 기억할 점 |
|---|---|
| Partial result | 발화 중 먼저 보이는 결과. 확정 여부는 별도 확인 |
| Final result | 종료·잔여 처리 후 결과. 완료 상태의 관찰 기준 필요 |
| 최초 출력 지연 | 첫 텍스트를 보기까지의 시간 |
| 결과 안정성 | 표시된 문구의 수정 빈도와 범위 |
| 최종 정확성 | 기준 발화와 최종 전사의 일치 정도 |

## 관찰 체크리스트

- [ ] Mac·버전·모델·입력·설정을 기록한다.
- [ ] 같은 녹음과 기준 전사로 모델을 비교한다.
- [ ] 첫 출력·후속 반영·종료 후 지연을 나눠 본다.
- [ ] 뒤쪽 추가와 기존 문구 수정을 구분한다.
- [ ] 중간 멈춤·단어 경계·전문용어·무음·언어 감지를 살핀다.
- [ ] 설정은 가능할 때 하나씩 변경한다.

## 오해 방지

- 빠른 첫 출력 ≠ 빠른 전체 완료.
- 먼저 표시된 문구 ≠ 확정된 문구.
- Mac 내부 음성 처리 설명 ≠ 전체 통신·저장 정책 확인.
- 최대 18배·15배 주장: 비교 기준·입력·모델·측정 과정 미제공.
- 설치 명령·저장소·API·지원 기종·확정 정책: 별도 확인 필요.
