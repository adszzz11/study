# Deep Dive: 속도·안정성·정확성 분리 평가

## 평가 설계

같은 녹음 파일을 모델별로 처리하고 입력·설정·환경을 고정한다. 반복 실행 횟수와 측정 기준을 미리 정한다. 파일 입력이 실제 시간에 맞춰 처리되는지는 알려지지 않았으므로 마이크 실험과 분리해 보고한다.

| 관찰값 | 기록 방법 | 주의점 |
|---|---|---|
| 최초 출력 지연 | 첫 표시 시각 − 발화 시작 시각 | 파일은 발화 시작과 처리 시작을 구분 |
| 후속 출력 지연 | 음성의 특정 구절과 해당 구절 표시 시점 비교 | 대응 구절과 시각 기준 명시 |
| 출력 수정 | 이전 문구를 바꾼 이벤트와 범위 기록 | 단순 뒤쪽 추가는 수정과 구분 |
| 종료 후 지연 | 최종 완료 시각 − 녹음 종료 시각 | 완료 신호가 없으면 관찰값임을 표시 |
| 최종 정확성 | 기준 전사와 최종 전사의 오류 비교 | 한국어 띄어쓰기·구두점 처리 기준 고정 |

## 실험 순서

1. **안정성:** 문장 중간 멈춤과 후속 설명 추가를 비교한다. 이전 출력의 어느 부분이 바뀌는지 남긴다.
2. **경계:** 연속 발화와 단어 사이를 끊은 발화를 비교한다. 관찰된 차이만 기록하고 내부 알고리즘을 추론해 단정하지 않는다.
3. **모델:** tiny~large 중 실제 선택 가능한 모델을 같은 파일로 비교한다. 자료만으로 성능 우열을 정하지 않는다.
4. **용어 사전:** 형식과 사용법을 확인한 뒤 전문용어의 적용 전후를 비교한다. 최종 오류와 부분 결과의 수정도 함께 본다.
5. **무음·언어:** 무음 전후 출력과 자동 언어 감지 결과를 관찰한다. 무음이 확정 신호라고 가정하지 않는다.

설정을 변경할 수 있다면 한 번에 하나씩 바꾼다. 후보 비교·단어 경계 유지가 사용자 설정으로 노출되는지는 자료에 없다.

빈칸은 실측 후 채운다. 수치를 만들어 넣지 않는다. 필요한 경우 자원 사용량도 별도로 관찰하되 모델별 메모리 요구량을 미리 단정하지 않는다.

## 해석

첫 표시가 빨라도 수정이 잦으면 읽기 부담이 클 수 있다. 최종 정확성이 높아도 표시가 늦으면 발화 중 확인의 효용이 작다. 최대 18배·15배는 비교 기준이 없어 이 실험으로 재현했다고 주장할 수 없다.
