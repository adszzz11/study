# 시작하기: 부분 결과와 최종 결과 구분

## 준비와 한계

설치 명령, 저장소 주소, API 사용법은 제공되지 않았다. 따라서 이 노트는 **실행 가능한 환경을 별도로 확보한 뒤 수행하는 관찰 절차**다. 공식 배포처와 지원 환경을 먼저 확인하고, 존재를 확인하지 못한 명령이나 설정을 가정하지 않는다.

- 짧은 한국어 문장과 실제 발화를 옮긴 기준 전사를 준비한다.
- 마이크 실습의 입력 환경, Mac 기종, 사용 모델과 설정을 기록한다.
- 가능하면 출력 변화를 시간과 함께 기록한다. 화면 기록을 사용할 경우 자신의 테스트 음성을 사용한다.

## 첫 실습

1. “오늘 회의는 오후 세 시에 시작합니다”처럼 짧은 문장을 발화한다.
2. 발화 시작과 첫 텍스트 표시 시각을 기록한다.
3. 녹음 중 보이는 문구를 적고, 녹음 종료 뒤 전사와 비교한다.
4. 중간에 잠시 멈춘 발화와 뒤에 설명을 덧붙인 발화를 각각 시도한다.
5. 앞서 표시된 단어가 바뀌는지, 어느 범위까지 수정되는지 확인한다.
6. 화면에 확정 표시가 없다면 임의로 확정 시점을 정하지 않고 “확정 상태 미확인”으로 남긴다.

## 기록 양식

```text
실행 ID / 날짜:
Mac / 앱 버전 / 모델 / 입력 방식 / 설정:
발화 시작 시각:
최초 텍스트 시각:
녹음 종료 시각:
최종 결과 관찰 시각:
녹음 중 표시 문구 → 종료 후 문구:
수정된 범위 / 최종 전사 오류:
확정 상태 표시 유무 / 관찰 한계:
```

앱이 최종 완료 상태를 제공하지 않으면 최종 시각은 관찰 기준을 명시하고, 공식 완료 시각처럼 보고하지 않는다. 파일 처리 종료와 마이크 녹음 종료도 구분한다.

## 완료 체크

- [ ] 최초 표시와 확정을 구분했다.
- [ ] 중간 출력과 종료 후 결과의 차이를 기록했다.
- [ ] 기능 소개와 직접 확인한 동작을 나눠 적었다.
