# References

## 근거 자료

| 자료 | 확보 상태 | 사용 범위 |
|---|---|---|
| 사용자 제공 dossier | 본문 제공됨 | 개념·기능 소개·실습과 적용 아이디어 |
| dossier가 요약한 영상 | 원본 URL·제목·게시일 미제공 | 영상 요약에 귀속한 제품 소개와 속도 주장 |
| 공식 저장소·설치 문서·API 문서 | 주소 미제공 | 설치·연동 절차를 작성할 수 없음 |

무료·오픈소스·Mac 전용이라는 소개는 자료에 귀속한다. 실제 라이선스와 지원 기종을 확인한 것으로 취급하지 않는다.

## 후속 확인 목록

- [ ] 원본 영상 URL과 게시일 확보.
- [ ] 공식 프로젝트 저장소와 라이선스 확인.
- [ ] 설치 방법, 지원 macOS·기종·모델 요건 확인.
- [ ] 부분 결과의 확정 기준, 수정 정책, 출력 형식·API 확인.
- [ ] 최대 18배·15배 주장의 비교 대상·입력·모델·측정 과정 확인.
- [ ] 네트워크 동작과 저장·로그 정책 확인.

이 목록은 미확인 사항이다. 검색으로 추정한 동명 프로젝트를 공식 출처로 대체하지 않는다.

## 근거를 읽는 원칙

1. 자료에서 소개한 기능과 직접 관찰한 동작을 분리한다.
2. 평가 제안은 제품이 제공하는 기능이나 측정 결과로 쓰지 않는다.
3. 상대 속도 주장은 기준이 확보된 뒤 재현 가능성을 판단한다.
