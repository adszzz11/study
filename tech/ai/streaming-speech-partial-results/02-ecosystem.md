# Ecosystem: 처리 방식과 입력 경로 비교

## 비교 범위

제공 자료에는 다른 제품이나 구현체가 없다. 특정 경쟁 제품의 기능·성능을 덧붙이지 않고, 소개된 처리 방식·입력 경로·모델 선택을 비교한다. 각 행은 상호 배타적인 제품 목록이 아니다.

| 방식·구성 | 결과 확인 시점 | 자료에서 드러나는 가치 | 검증할 점 |
|---|---|---|---|
| 녹음 종료 후 일괄 변환 | 녹음 종료 후 | 실시간 방식의 대비 대상 | 처리 시간과 정확도 수치 미제공 |
| Lightning-SimulWhisper 부분 결과 | 녹음 중 확실한 부분부터 | 발화 도중 전사 확인 | 확정 기준과 수정 동작 |
| 마이크 입력 | 발화가 들어오는 동안 | 실시간 받아쓰기 | 소음·거리·입력 환경 영향 |
| 녹음 파일 입력 | 파일 처리 중 | 동일 음성 반복 비교 | 실제 시간에 맞춘 처리 여부 |
| tiny~large 모델 선택 | 선택 모델 처리 중 | 모델 크기를 바꿔 평가 | 정확도·지연·자원 사용량 |

## 선택 기준

- 실시간 확인이 목적이면 최초 출력과 후속 출력 지연을 살핀다.
- 읽기 편한 전사가 목적이면 기존 출력의 수정 범위를 함께 기록한다.
- 모델 비교는 같은 입력과 환경에서 수행한다. 큰 모델이 항상 더 적합하다고 가정하지 않는다.
- 파일 입력의 처리 시간을 마이크의 실시간 지연과 바로 비교하지 않는다. 파일 입력의 처리 방식부터 확인한다.

## 로컬 처리의 해석

Mac 내부 처리라는 설명은 음성을 서버로 전송하지 않는 사용 흐름을 뜻한다. 모든 네트워크 통신 부재, 모델 다운로드 동작, 저장·로그 정책까지 입증하지는 않는다. 도입 조건에 해당 항목이 포함된다면 별도 확인이 필요하다.
