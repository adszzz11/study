# Toplr — What / Why / 특징

[[tech/ai/toplr-ai/README|학습 진입점]]

## What / Why

Toplr는 숏폼 기획에서 흩어진 레퍼런스 수집, 성과 비교, 영상 분석, 대본 작성을 연결하는 사용자용 SaaS다. “어떤 영상이 잘됐는가 → 어떤 구조를 참고할 것인가 → 내 주제에 어떻게 적용할 것인가”를 이어가는 것이 목적이다.

계정 내부의 **Relative performance**를 함께 보면 대형 계정의 높은 조회수만 따라가는 편향을 줄이는 데 도움이 될 수 있다. 다만 공급자의 시간·비용 절감 수치는 마케팅 주장으로 구분한다. 제공 dossier에는 독립적 검증 자료가 없으며, 이번 작성에서도 직접 성능을 측정하지 않았다.

## 핵심 기능

| 단계 | 공개 설명상의 기능 | 검토할 점 |
|---|---|---|
| 탐색 | 크리에이터 구독 기반 대시보드, 계정 규모·게시 기간·조회수·참여율·평균 대비 성과 필터 | 계정 규모와 게시 후 경과 시간이 비슷한가? |
| 분석 | 음성 스크립트, 원본 캡션, Hook·본문·CTA, 컷·화면 전환 흐름 | 실제 대사·장면과 일치하는가? |
| 작성 | 레퍼런스 구조와 소재를 연결한 대본 생성·수정 | 사실, 말투, 촬영 가능성을 사람이 검토했는가? |
| 관리 | 프로젝트·아카이브에 레퍼런스와 결과 정리 | 원본 URL과 수정 이유가 남아 있는가? |

탐색·분석 세부 기능은 제공 dossier의 공식 가이드 요약에 근거한다. 해당 가이드 두 페이지는 이번 재열람에서 오류가 발생했다.

Chrome Extension은 Instagram에서 지표 정렬, 여러 릴스 선택, 프로젝트 저장, AI 분석 요청과 다운로드를 지원한다고 안내한다. 웹에서 소개하는 세 플랫폼 전체를 확장프로그램도 동일하게 지원한다고 해석하지 않는다.

## 논리적 처리 흐름

아래는 공개 기능과 처리방침을 연결한 **개념도**다. 실제 배포 구성이나 내부 호출 순서를 검증한 결과가 아니다.

```text
공개 소셜 콘텐츠 / URL / Instagram Extension
                      ↓
       수집·저장 → 성과 비교 → 레퍼런스 선택
                      ↓
          AI 구조 분석 → 대본 생성·수정
                      ↓
             프로젝트·아카이브 관리
```

| 계층 | 처리방침에 명시된 서비스 | 역할 |
|---|---|---|
| AI 분석 | Google Gemini API 등 | 레퍼런스 요약·구조 분석 |
| AI 작성 | Anthropic Claude API | 대본 생성·보완 |
| 인증·데이터 | Supabase | 회원 인증·세션·서비스 데이터 저장 |
| 웹 운영 | Vercel | 배포·요청 처리·운영 로그 |
| 파일·보안 | Cloudflare R2 / Turnstile | 파일 저장·전송·봇 탐지 |
| 결제·제품 분석 | Payple / PostHog 등 | 정기결제·사용 이벤트·품질 분석 |

이는 개인정보처리방침상의 설명이며 코드나 실행 로그로 확인한 기술 스택이 아니다. 제공 dossier에 따르면 확장프로그램은 서버에서 폐기 가능한 전용 세션 토큰을 저장하고 웹 Supabase 세션 토큰과 비밀번호는 저장하지 않는다고 설명한다. 이 세션 상세는 이번 페이지 열람에서 별도로 재확인하지 못했다. 수집 방식은 공식 API·공개 웹 수집을 포괄하지만 수집업체와 플랫폼별 구현은 공개하지 않는다.

**미확인 구현**: Frontend framework, Backend 언어, Queue, Vector DB, RAG, 모델 버전, 영상 프레임 샘플링, ASR 방식. 제공 조사에서 공식 공개 GitHub 저장소와 개발자용 API 문서도 확인하지 못했다. 부재가 입증된 것은 아니다.

## 가격과 제품 상태

2026-09-09 공개 페이지 확인 기준이며 실제 결제 가능 여부를 시험하지 않았다.

| 플랜 | 월 가격 | 월 credits | 상태 |
|---|---:|---:|---|
| Free | 0원 | 15 | 홈페이지에 표시 |
| Starter | 19,000원 | 150 | VAT 별도 |
| Pro | 29,000원 | 300 | VAT 별도 |
| Team | 미확정 | 구매 조건 미확정 | 준비 중 표시 |

- 영상 분석: 3–8 credits, 대본 초안 생성: 3–5 credits.
- 홈페이지는 Free의 전체 기능 7일 체험을 안내한다. 월 무료 credits와 기능별 이용 제한은 구분해서 확인한다.
- dossier에 따르면 약관은 Pro를 29,000–59,000원 범위로 기재하고 결제 활성화 조건을 남겨 두었다. 해당 약관의 가격 범위와 활성화 조건은 이번 재열람에서 별도로 재확인하지 못했다. 홈페이지 가격표만으로 실제 구매 구성을 확정하지 않는다.
- dossier의 확장프로그램 기록: 공식 스토어 0.1.5·2026-08-22, 외부 아카이브 0.1.9·2026-08-30. 수집 시점 차이 가능성이 있어 최신 버전으로 단정하지 않는다.

## 공개 기록과 분석 한계

제공 조사에서는 제품에 직접 연결되는 2025년 활동·출시 자료를 확인하지 못했다. 공식 기록에는 2026-07-24 시행 약관과 07-25·07-31 리포트가 있지만 이를 최초 출시일로 단정할 수 없다.

Outlier 임계값·점수 산식·비교 기간·결측치 처리는 공개 리포트 요약에 제시되지 않았다. AI 설명을 검증된 인과관계로 받아들이지 말고, [[tech/ai/toplr-ai/04-learning/02-deep-dive|Grounding 실습]]으로 근거를 대조한다.
