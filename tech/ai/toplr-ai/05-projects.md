# Toplr — 실전 프로젝트

[[tech/ai/toplr-ai/README|학습 진입점]]

## 적용 제안

아래는 확인된 고객 사례가 아닌 **실전 적용 제안**이다. 제공 dossier의 마지막 ‘대본 품질 평가’ 문장이 중간에 끊겨 있어 해당 항목의 세부 절차와 평가 기준은 학습용으로 보완했다.

| 프로젝트 | 실행 방법 | 산출물 | 평가 기준 |
|---|---|---|---|
| 브랜드 Hook 실험 | 같은 주제를 질문형·결과 선공개형·오해 교정형으로 제작 | 대본 3개와 영상 3개 | 게시 후 동일 기간의 시청 유지·전환 |
| 경쟁 콘텐츠 분석 | 동종 크리에이터의 Outlier와 평범한 영상 함께 분석 | 주간 패턴 보고서 | 분석시간·실제 채택 아이디어 수 |
| 대본 품질 평가 | 같은 소재를 수작업과 Toplr 보조 방식으로 작성 | 익명화한 초안·수정본·평가표 | 사실 오류·수정시간·촬영 가능성·말투 |

## 프로젝트 1: 브랜드 Hook 실험

1. 하나의 주제와 전달할 핵심 사실을 고정한다.
2. Hook만 다른 초안 3개를 만들고 본문·CTA·목표 길이를 최대한 맞춘다.
3. 촬영·수정 후 게시한다. 게시 시점과 관찰 기간을 기록한다.
4. 플랫폼에서 제공하는 시청 유지 지표와 미리 정의한 전환 지표를 비교한다.

관찰 기간은 예를 들어 게시 후 7일로 동일하게 정한다. 게시 시점·유입·알고리즘 노출의 차이가 남으므로 통제 실험이나 인과 증명으로 보고하지 않는다. 실제 게시와 측정은 학습자가 수행하는 별도 단계다.

## 프로젝트 2: 경쟁 콘텐츠 분석

- 같은 분야의 크리에이터 2–3명을 정하고 비교 기간·규모·게시 경과 시간을 기록한다.
- 각 계정에서 Outlier 후보와 평범한 영상을 함께 선택한다.
- Hook·전개·CTA·컷 전환을 표로 정리하고 각 주장에 원본 시간대를 붙인다.
- 공통 패턴 중 자신의 브랜드에 적용할 것과 제외할 것을 이유와 함께 고른다.

**완료 기준**: 원본 URL이 있는 주간 보고서, 관찰과 추론의 구분, 분석에 쓴 시간, 실제 채택한 아이디어 수. 후보의 총조회수만으로 보고서의 가치를 평가하지 않는다.

## 프로젝트 3: 대본 품질 평가

1. 같은 주제·길이·대상 시청자·참고자료를 사용한다.
2. 수작업과 Toplr 보조 방식 각각의 초안 작성시간, 검토시간, 수정시간을 기록한다.
3. 여러 소재를 쓴다면 제작 순서를 번갈아 배치해 먼저 작성한 경험의 영향을 줄인다.
4. 가능하면 제작 방식을 가리고 다른 검토자가 평가한다.
5. 실제 credits와 최종 채택 여부를 함께 보고한다.

```text
소재 / 제작 방식 / 초안 시간 / 검토·수정 시간
검증 가능한 주장 수 / 사실 오류 수
촬영 가능 여부와 이유 / 말투 수정 항목
사용 credits / 최종 채택 여부 / 남은 한계
```

한두 번의 실험으로 공급자의 시간 절감 주장을 입증하지 않는다. 결과는 자신의 주제·작업 조건에 한정한다.
