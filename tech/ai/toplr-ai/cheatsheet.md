# Toplr — Cheatsheet

[[tech/ai/toplr-ai/README|학습 진입점]]

## 빠른 작업 순서

```text
주제·시청자 정의 → 크리에이터 2–3명 선택
→ 조회수순 / 성과순 비교 → 영상 1개 분석
→ 원본과 대조 → 구조 선택 → 자신의 대본 생성·수정
→ URL·분석 메모·최종본을 프로젝트에 정리
```

## 용어와 판단 기준

| 용어 | 의미 | 주의점 |
|---|---|---|
| Outlier | 계정의 평소 성과보다 두드러진 영상 | Toplr의 임계값·산식 미공개 |
| Relative performance | 계정의 기준 성과 대비 변화 | 기간·표본·게시 경과 시간 확인 |
| Engagement rate | 분모 대비 상호작용 비율 | 조회수/팔로워 등 분모 확인 |
| Hook | 초반에 관심을 끄는 요소 | 실제 대사·장면에 대응 |
| CTA | 시청자에게 요청하는 행동 | 목표 행동을 구체적으로 작성 |
| Grounding | 설명을 원본 증거에 연결 | 관찰과 인과 추론 구분 |
| Structure transfer | 콘텐츠 구조를 새 소재에 적용 | 고유 표현·경험담 복제 방지 |

## 가격·credits 빠른 참조

**2026-09-09 홈페이지 표시**: Free 15 credits/월, Starter 19,000원·150 credits/월, Pro 29,000원·300 credits/월. 유료 가격 VAT 별도, Team 준비 중.

- 분석 3–8 + 초안 3–5 = **6–13 credits**. 수집·재생성·추가 작업 제외.
- Free의 월 credits와 전체 기능 7일 체험 제한은 별개다.
- dossier에는 약관과 홈페이지의 Pro 가격 표기 차이가 기록되어 있다. 약관의 해당 표기는 이번 재확인되지 않았으며 실제 결제 구성은 별도 확인한다.
- 확장프로그램의 기록상 버전 불일치가 있어 최신 버전은 단정하지 않는다.

## 실행 전후 체크

- [ ] 지원 플랫폼·현재 플랜·예상 소모량을 확인했다.
- [ ] 원본 URL·게시일·관찰일·비교 기간을 기록했다.
- [ ] 분석 내용마다 실제 대사·장면·시간대를 확인했다.
- [ ] AI의 성공 요인 설명을 가설로 취급했다.
- [ ] 대본의 사실·말투·촬영 가능성을 검토했다.
- [ ] 사용 credits와 최종 수정시간을 남겼다.

## 복사용 기록 양식

```text

```
