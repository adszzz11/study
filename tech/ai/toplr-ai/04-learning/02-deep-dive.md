# Toplr — Deep dive

[[tech/ai/toplr-ai/README|학습 진입점]]

## 실습의 성격

아래는 제공 dossier의 개념을 익히기 위한 **학습자 실험 제안**이다. Toplr 내부 산식의 재현이나 제품 성능 검증 결과가 아니다.

## 1. Relative performance와 Outlier

가상의 계정 A는 평소 80만 조회수, 후보 영상은 100만이다. 계정 B는 평소 2만, 후보는 10만이다. 단순 비율은 각각 1.25배와 5배다. 절대 도달 규모는 A가 크지만 평소 대비 변화는 B가 크다.

```text
학습용 단순 비율 = 후보 조회수 / 비교 영상들의 평균 조회수
주의: Toplr의 공개되지 않은 Outlier 점수 산식이 아니다.
```

- 같은 플랫폼·주제에서 계정 규모와 게시 후 경과 시간을 최대한 맞춘다.
- 비교 영상의 기간과 표본 수를 기록하고 평균뿐 아니라 중앙값도 확인한다.
- 평균이 0이거나 표본이 부족하면 비율을 계산하지 않고 판단 보류로 남긴다.
- Outlier와 평범한 영상 모두에서 같은 Hook이 나오는지 확인한다. 성공 영상만 보는 선택 편향을 줄인다.

## 2. Engagement rate

분모가 조회수인지 팔로워인지 확인한다. 다음은 가능한 정의의 **예시**이며 Toplr의 확정 산식이 아니다.

```text
조회수 기준 예시 = (좋아요 + 댓글) / 조회수 × 100
팔로워 기준 예시 = (좋아요 + 댓글) / 팔로워 수 × 100
```

포함되는 상호작용 종류와 수집 시점도 기록한다. 누락된 저장·공유 수를 0으로 취급하지 않는다. 정의를 확인하지 못하면 도구 간 점수를 직접 비교하지 않는다.

## 3. Grounding: 설명을 원본에 연결

| AI 설명 예시 | 확인할 증거 | 판단 |
|---|---|---|
| 시작에 질문이 나온다 | 실제 첫 대사와 시간대 | 관찰로 확인 가능 |
| 빠른 컷 전환이 있다 | 전환 지점과 구간별 횟수 | 관찰로 확인 가능 |
| 질문 때문에 조회수가 늘었다 | 다른 요인을 통제한 비교 필요 | 인과 추론, 영상만으로 확정 불가 |

설명마다 실제 대사·장면·시간대를 붙이고 `관찰 / 추론 / 미확인`으로 표시한다. 원본에 없는 문장이나 장면은 오류로 기록한다.

## 4. Structure transfer

표현을 복사하기보다 **문제 제기 → 증거 → 행동 요청**이라는 구조를 옮긴다. 같은 구조로 서로 다른 소재 두 개를 작성하고, 각 소재의 사실 근거와 시청자 맥락이 유지되는지 확인한다.

예: “정리 습관의 흔한 오해”를 분석한 뒤 “초보 식물 관리의 흔한 오해”로 구조를 옮긴다. 원본의 경험담이나 수치를 자신의 근거처럼 재사용하지 않는다.

## 5. Evaluation

같은 소재에 대해 수작업 초안과 Toplr 보조 초안을 비교한다. 아래 평가지표는 자체 실험 기준이다.

| 지표 | 측정 방법 |
|---|---|
| 사실 정확성 | 검증 가능한 주장 수와 확인된 오류 수 기록 |
| 수정 시간 | 초안부터 촬영 가능한 최종본까지 분 단위 측정 |
| 촬영 가능성 | 필요한 장소·소품·분량을 실제 확보할 수 있는지 검토 |
| 브랜드 말투 | 미리 정한 표현·금지 표현 기준으로 평가 |
| 구조 전이 | 원본 표현 복제 없이 Hook·전개·CTA가 작동하는지 검토 |

평가할 때 제작 방식을 가리고 같은 기준을 적용하면 선호 편향을 줄일 수 있다. 소수 대본의 결과를 전체 제품 성능이나 게시 후 성공률로 일반화하지 않는다.
