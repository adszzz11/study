# Toplr — Getting started

[[tech/ai/toplr-ai/README|학습 진입점]]

## 목표와 준비

**목표**: 영상 1개에 대해 원본 URL → 구조 분석 메모 → 자신의 대본 수정본을 연결한다. 아래는 공식 시작 가이드에 대한 dossier 요약을 토대로 구성한 실습이며 직접 실행한 결과는 아니다.

- 자신의 분야와 대상 시청자, 영상 길이를 정한다.
- 참고할 크리에이터 2–3명을 고른다.
- 가입 후 현재 플랜의 기능 접근·잔여 credits를 확인한다.
- Instagram에서 수집할 경우 공식 Chrome Web Store의 Toplr Extension을 설치하고 서비스 안내에 따라 연결한다.

## 첫 실습

1. 관심 분야와 크리에이터를 선택해 대시보드를 구성한다. 신규 수집 등 추가 비용이 표시되면 예산에 포함한다.
2. **조회수순**과 **성과순** 후보를 비교한다. 높은 절대 조회수와 평소 대비 높은 성과가 같은 영상을 가리키는지 기록한다.
3. 영상 하나를 선택해 원본 URL·게시일·관찰일·표시 지표를 기록한다. 분석 전에 예상 credit 소모량을 확인한다.
4. AI 분석을 실행하고 원본을 직접 보며 대사·Hook·본문·CTA와 컷 전환 설명을 대조한다.
5. 참고할 구조, 자신의 소재, 대상 시청자와 길이를 정해 대본 초안을 만든다.
6. 사실 오류·말투·촬영 가능성을 검토해 수정하고 원본 URL, 분석 메모와 수정본을 같은 프로젝트에 정리한다.

계정·플랜에서 탐색이 제한되면 URL 직접 추가 기능의 이용 가능 여부를 확인한다. 이 노트는 UI 버튼명이나 메뉴 위치를 고정하지 않는다.

## Credit 예산

홈페이지 표시 기준 분석 1회(3–8) + 초안 생성 1회(3–5)는 **6–13 credits**다. 이는 두 작업만의 산술 합계이며 신규 크리에이터 수집·재수집·재생성·추가 조사는 제외한다. Free 월 15 credits로 모든 온보딩과 반복 실험까지 가능하다고 가정하지 않는다.

## 대본 입력 예시 — 학습자 작성

다음은 UI에 넣을 수 있는 소재 설명 예시이며 Toplr 전용 API나 고정 Prompt 문법이 아니다.

```text
주제: 처음 실내 식물을 키우는 사람의 물 주기 실수
대상: 초보 식물 집사
길이: 30초
구조: 흔한 오해 → 확인할 단서 → 오늘 할 행동
말투: 친근하지만 과장 없이
조건: 레퍼런스의 고유 문장을 복사하지 말 것.
      식물 종류별 차이를 무시한 단정은 피할 것.
      추가 확인이 필요한 사실은 따로 표시할 것.
```

## 완료 기록

| 항목 | 기록할 내용 |
|---|---|
| 원본 | URL, 크리에이터, 게시일, 관찰일 |
| 선택 이유 | 절대 조회수 또는 상대 성과, 비교 조건 |
| 구조 | Hook / 본문 / CTA와 해당 시간대 |
| 검토 | AI 오류, 관찰과 추론의 구분 |
| 최종본 | 수정 대본, 바꾼 이유, 촬영 메모 |
| 비용·시간 | 실제 차감 credits, 분석·수정에 걸린 시간 |

- [ ] 원본과 분석을 대조했다.
- [ ] 최종 대본의 사실·말투·촬영 가능성을 검토했다.
- [ ] 표현 복제 대신 구조를 자신의 소재로 옮겼다.
- [ ] URL·메모·수정본을 다시 찾을 수 있다.
