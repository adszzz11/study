# 시작하기: 역할과 모델의 효과 분리

## 준비

특정 제품 설치를 전제하지 않는 수동 실험이다. 사용 가능한 모델과 공개·비민감 자료 한 묶음을 준비한다. 세 모델 모두에 접근할 수 없다면 가능한 범위만 비교하고 누락을 기록한다.

## 1. 동일 모델로 역할 나누기

같은 자료와 모델을 유지하고 연구자 → 작성자 → 검토자를 순서대로 실행한다. 처음에는 사람이 결과를 전달한다.

| 역할 | 목표 | 산출물·완료 조건 |
|---|---|---|
| 연구자 | 사실과 미확인 사항 분리 | 근거 목록, 미확인 항목 |
| 작성자 | 근거에 맞는 초안 작성 | 주장과 근거의 연결 |
| 검토자 | 오류·누락 검토 | 수정 위치, 이유, 잔여 의문 |

```text
역할: 연구자
입력: 동일한 공개 자료
목표: 자료에 근거한 핵심 사실 정리
출력: 사실 / 근거 위치 / 미확인 항목
제약: 자료 밖의 주장을 사실로 추가하지 말 것
```

## 2. 동일 역할로 모델 비교하기

역할·자료·지시문을 고정하고 Claude·GPT·Gemini의 사용 가능한 모델로 반복한다. 정확한 모델 이름·버전, 날짜와 설정을 기록한다. 모델 계열 전체의 우열로 일반화하지 않는다.

## 3. 기록과 비교

| 실행 | 역할 | 모델·버전 | 사실 충실도 | 형식 준수 | 수정량 |
|---|---|---|---|---|---|
| 실험 기록 | 연구자 | 실제 사용값 | 근거 없는 주장 수 | 누락 필드 수 | 수정 항목 수 |

역할을 나눈 결과와 한 역할로 처리한 결과의 누락·중복을 비교한다. 모델 비교에서는 동일 기준을 유지한다. 입력·출력 원문과 검토 결과를 남기면 차이의 원인을 설명하기 쉽다.
