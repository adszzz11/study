# References: 근거와 검증 상태

## 자료 범위

이 노트 묶음은 사용자 제공 dossier만 사용했다. Dossier는 영상 요약을 바탕으로 하며 원본 URL을 포함하지 않는다. 영상 제목과 시점 정보가 있었다는 설명은 있으나 실제 값은 제공되지 않았다.

## 주장별 근거 분류

| 주장 | 상태 | 해석 범위 |
|---|---|---|
| SkillTree에 부서별 agent와 세 모델 계열 등장 | Dossier 내 관찰 | 실제 제품 재현 검증은 아님 |
| 여러 요소를 한 workspace에 모음 | Dossier 내 관찰 | 자동 협업 보장 아님 |
| 도구 분산·맥락 반복 감소 | 분석·가설 | 별도 실험 필요 |
| Routing·공유 memory·권한 관리 구현 | 미확인 | 구현 여부 단정 불가 |
| 학습 절차·프로젝트·점검표 | 제안 | 제품 사용법 아님 |

## 추가 확보할 근거

- 원본 영상 URL, 제목, 게시일, 해당 장면 시점.
- SkillTree의 정확한 제품 식별 정보와 공식 문서 URL.
- Agent별 모델 연결, 인계, 접근 제어, 실행 기록을 보여주는 재현 가능한 사례.
- 가격·배포·개인정보 정책은 확인 날짜와 원문을 함께 기록.

이름만으로 공식 사이트를 추정하지 않는다. 원문을 확보하면 관찰·설명·직접 실행 결과를 구분해 갱신한다.

## Sources

- 제공된 dossier: SkillTree 및 함께 소개된 도구의 영상 요약. 원본 URL은 제공되지 않았다.
- 출처 URL: 미제공. 영상 제목·시점의 구체 값도 현재 dossier에 없어 원문 대조가 불가능하다. URL을 추정하거나 새 출처를 추가하지 않았다.
