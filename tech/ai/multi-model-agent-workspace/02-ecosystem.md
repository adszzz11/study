# Ecosystem: 도구별 비교 축

동영상에서 함께 소개된 도구들이다. 직접 경쟁 관계나 상호 대체 가능성은 확인되지 않았다.

| 도구 | 자료에 제시된 방식·영역 | 비교 관점 | 미확인 |
|---|---|---|---|
| SkillTree | 부서별 agent와 Claude·GPT·Gemini 통합 | 구성의 통합 | Routing·협업·권한·메모리 |
| Hermes | 연구자·작성자·검토자, 모델·메모리 설정 화면 | 역할과 설정 | 부서 구성·공유 범위·자동 인계 |
| Grok Bot | 리서치·영업·마케팅·운영 AI 동료 | 업무 역할 분화 | Multi-model·workspace 구조 |
| Dots | ChatGPT 안에서 사용자 부재 중 이어지는 작업 | 실행 지속성 | 부서 구성·여러 모델 통합 |
| OpenClaw | 백그라운드 서비스와 채팅 요청 처리 | 요청 채널·실행 방식 | 부서 구성·모델 선택 |
| Muse | 예약·쇼핑·양식·알림·장기 목표 | 개인 일상 업무 범위 | 조직 구조·multi-model |

## 비교 방법

단일 순위보다 필요한 조건을 먼저 정한다. 역할 분화, 모델 선택, 인계, 실행 지속성, 요청 채널을 각각 평가한다. Hermes의 설정 화면은 Hermes에 대한 관찰로만 기록한다.

영상에 cloud·open-source 및 가격·개인정보 보호·강점 비교 항목이 등장하지만 세부 값은 제공되지 않았다. 제품별 가격 우위, 배포 방식, 개인정보 보호 수준을 단정할 수 없다. 표의 설명은 현재 제품 사양의 독립 검증 결과가 아니다.
