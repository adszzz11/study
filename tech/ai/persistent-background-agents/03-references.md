# References: 출처와 근거 범위

## 자료 목록

| 자료 | 용도 | 출처 상태 |
|---|---|---|
| 사용자 제공 dossier | 여섯 도구의 관찰 내용과 실습 질문 | 원본 URL·영상 제목·게시자·게시일 미제공 |

외부 조사를 수행하지 않았다. 동명 도구를 혼동할 수 있으므로 제품명을 근거로 공식 URL을 추정하지 않는다. 입력 dossier의 마지막 기술스택 요약은 “Hermes의 설정 화면과 S”에서 잘려 있어, 잘린 문장 이후 내용은 복원하거나 인용하지 않았다.

## 근거 수준

| 수준 | 이 노트의 예 | 해석 |
|---|---|---|
| dossier에 명시된 관찰 | Dots 작업 지속, OpenClaw 서비스·채팅 | 수집 요약에 나타난 설명 |
| 분석상 구분 | Background와 durable execution | 제품 사양이 아닌 비교 기준 |
| 실습·프로젝트 제안 | 상태 기록, 연구→작성→검토 | 제품 지원 여부 별도 확인 |
| 미확인 | 실행 제한, 복구, 가격, 데이터 보관 | 지원·미지원 어느 쪽도 단정 불가 |

## 후속 조사 체크리스트

- [ ] 원본 영상 URL, 제목, 게시자, 게시일과 해당 장면 timestamp 확보.
- [ ] 각 제품의 정확한 식별 정보와 공식 문서 연결.
- [ ] 실행 시간 제한과 화면 이탈·세션 종료의 차이 확인.
- [ ] 저장·복구, 재시도, 가용성, 권한·승인 문서 확인.
- [ ] 가격·라이선스·배포·데이터 보관 조건을 확인 날짜와 함께 기록.

## Sources

- 사용자 제공 dossier: Dots·Muse·Grok Bot·OpenClaw·Hermes·SkillTree 소개 영상의 수집 요약. 원본 영상 제목·게시자·게시일·URL은 제공되지 않았다.
- 출처 URL: **미제공**. 제품명으로 공식 사이트나 특정 제품을 추정하여 연결하지 않았다.
