# 시작하기: 사용자 부재 중 실행 관찰

## 목표와 준비

Background execution, 서비스 대기, 상태 보존을 구분한다. 제품별 설치·가입·명령은 자료에 없으므로 이 문서는 검증 실습안이다. 실제 사용 가능한 도구와 공식 안내를 확보한 뒤 수행한다.

- 민감정보가 없는 짧은 문서 3개를 준비한다.
- 산출물은 쟁점 요약 1개와 문서별 근거 목록으로 제한한다.
- 첫 실습은 결과를 검토할 수 있는 읽기 중심 업무로 정한다.

## 실습 순서

1. 아래 예시 요청을 보내고 시작 시각과 식별 가능한 작업 정보를 기록한다.
2. 화면을 보고 있는 동안 관찰 가능한 상태를 기록한다.
3. 화면을 벗어나되 앱 종료·로그아웃과 혼동하지 않도록 이탈 방법을 적는다.
4. 돌아와 결과, 근거, 상태와 시각을 확인한다.
5. 같은 조건을 반복해 관찰 차이를 기록한다. 실행 환경이 허용하는 경우에만 앱 종료나 세션 종료를 별도 실험한다.

```text
제공한 문서 3개에서 공통 쟁점 3개를 정리해 주세요.
각 쟁점에 문서명과 근거 구절을 붙여 주세요.
근거가 부족한 항목과 미완료 항목은 따로 표시해 주세요.
```

## 관찰 기록

| 항목 | 기록할 내용 |
|---|---|
| 환경 | 도구·버전·날짜·실행 설정 |
| 이탈 | 화면 전환 / 앱 종료 / 세션 종료 중 무엇인가 |
| 진행 | 시작·관찰·완료 시각, 상태 표시 |
| 결과 | 요구한 요약과 근거의 완성 여부 |
| 한계 | 중간 진행 관찰 가능 여부, 오류, 미확인 조건 |

최종 결과가 있다는 사실만으로 화면을 떠난 동안 실제 처리되었는지 확정할 수 없다. 신뢰할 수 있는 진행 기록이나 시각 정보가 없으면 **작업 지속 여부 미확인**으로 남긴다. 한 번의 성공은 장기 안정성이나 자동 복구의 증거가 아니다.
