# Ecosystem: 받아쓰기와 회의 기록 비교

## 비교 범위

수집 자료에는 Sokki와 Damso만 등장한다. 다른 제품·cloud API·Whisper 구현체의 성능 비교는 제공되지 않았다. 아래의 ‘자료에 없음’은 기능 부재를 의미하지 않는다.

| 비교 축 | Sokki | Damso |
|---|---|---|
| 용도 | 개인 받아쓰기 | 회의 기록 |
| Whisper 사용 | README에 명시 | 자료에 없음 |
| 처리 위치 | 기기 내부 | 자료에 없음 |
| 오디오 외부 전송 | Mac 밖으로 나가지 않는다고 명시 | 자료에 없음 |
| 기록 저장 | 로컬 SQLite | 자료에 없음 |
| 사용자 피드백 | 파형·경과 시간·한국어 텍스트 | 회의 기록 화면 |
| 화자 기능 | 자료에 없음 | 화자 분리·누적 화자 프로필 |
| 녹음 시작 제어 | 자료에 없음 | 회의 감지 후 녹음 전 사용자 확인 |

## 선택 관점

- **개인 텍스트 입력:** Sokki 사례를 바탕으로 한국어 오류·수정 부담·결과 확정 시간을 측정한다.
- **회의 기록:** Damso 사례를 바탕으로 녹음 승인 흐름·화자 구간·회차 간 프로필 연결을 평가한다.
- 두 제품은 서로 다른 작업 맥락을 보여준다. 동일 엔진·동일 저장 계층을 공유하거나 직접 대체 가능하다고 단정할 수 없다.
- cloud 방식이나 다른 로컬 엔진을 후보로 추가하려면 실행 위치·전송 범위·저장 정책·동일 조건의 측정 결과를 새로 수집한다.
