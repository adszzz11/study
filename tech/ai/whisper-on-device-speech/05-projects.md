# Projects: 실전 적용

아래 프로젝트는 제품 검증과 workflow 설계를 위한 제안이다. 구현된 연동이나 성능을 보증하지 않는다.

## 1. 한국어 로컬 받아쓰기 평가 노트

- **목적:** 개인 노트 작성에 적합한 발화 길이와 수정 부담 파악.
- **방법:** Sokki에서 기준 문장·출력·수정 내용·확정 지연을 기록하고 조건별로 반복한다.
- **산출물:** 평가표, 대표 오류 사례, 적합한 작업과 부적합한 작업 목록.
- **완료 기준:** 짧은 문장과 긴 문장의 수정 부담을 관찰 근거와 함께 설명한다. Obsidian·ChatGPT Work 입력 연동은 별도 확인한다.

## 2. 로컬 음성 기록 데이터 지도

- **목적:** README 설명과 실제 데이터 경계를 대조.
- **방법:** Whisper 실행·오버레이·SQLite를 출발점으로 오디오·텍스트·메타데이터를 추적한다.
- **산출물:** 데이터 흐름도와 아래 저장 항목 표.
- **완료 기준:** 확인하지 못한 경로를 미확인으로 표시하고, 실행·전송·저장·보호 수준을 분리해 설명한다.

## 3. 사용자 확인을 포함한 회의 기록 workflow

- **목적:** Damso의 녹음 전 확인과 화자 정보 관리를 별도로 평가.
- **방법:** 감지·대기·승인·거절·무응답 시나리오를 관찰하고, 회의 내부 화자 구분과 회차 간 프로필 연결을 기록한다.
- **산출물:** 상태 전이표, 회의별 화자 평가 기록, 미확인 구현 사항 목록.
- **완료 기준:** 확인 전후 녹음 시작 시점을 설명하고 오연결 사례를 남긴다. 처리 위치·사용 모델은 구현 전 확인 사항으로 둔다.
