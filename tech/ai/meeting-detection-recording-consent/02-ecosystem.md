# Ecosystem — 제품과 설계 대안

## 비교

제공 자료에는 Sokki와 Damso만 등장한다. 수동 시작과 감지 후 즉시 녹음은 제품이 아닌 설계 대안이다.

| 제품·설계 대안 | 목적·시작 방식 | 녹음 전 승인 | 처리·저장 근거 | 한계 |
|---|---|---|---|---|
| Sokki | Mac 음성 받아쓰기; 파형·경과 시간·한국어 인식 텍스트 표시 | 설명 없음 | 기기 내 음성 인식·Whisper, 로컬 SQLite, 오디오 외부 미전송 설명 | 회의 감지 여부 불명 |
| Damso | 회의 기록; 회의 감지·화자 분리·누적 화자 프로필 | 녹음 전 사용자 질문 | 위치·저장소 설명 없음 | Sokki의 로컬 속성을 적용할 수 없음 |
| 수동 시작 방식 | 사용자가 직접 실행 | 실행 동작을 시작 의사로 활용 가능 | 구현에 따라 다름 | 참석자 동의 확보를 뜻하지 않음 |
| 감지 후 즉시 녹음 | 감지 결과로 시작 | 별도 질문 없는 구조 | 구현에 따라 다름 | 오탐이 원치 않는 녹음으로 이어질 수 있음 |

## 선택 기준

음성 인식 성능보다 **시작 권한의 위치**를 먼저 비교한다. 로컬 처리 여부와 녹음 전 승인 여부는 독립된 축이다. 로컬 처리만으로 시작 승인 문제가 해결되거나, 승인 UI만으로 데이터 보관 정책이 정해지지는 않는다.

검토 시에는 감지 입력, 승인 범위, 처리 위치, 저장 위치, 삭제 정책을 각각 질문한다. 자료에 설명이 없는 항목은 미지원으로 단정하지 않고 **미확인**으로 남긴다.
