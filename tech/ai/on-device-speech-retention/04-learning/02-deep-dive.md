# 심화 학습: 성능과 보관을 분리해 검증하기

## 모델 크기와 지연

같은 Mac, 같은 샘플, 같은 설정에서 선택 가능한 모델을 비교한다. 모델 준비·초기 실행과 준비 완료 후 실행을 구분하고 반복 횟수를 기록한다. tiny~large의 우열이나 메모리 요구량은 미리 정하지 않는다.

| 기록 항목 | 목적 |
|---|---|
| 첫 출력·최종 완료·출력 수정 | 사용자가 경험하는 지연과 안정성 |
| 처리시간·메모리 사용량 | 모델 크기의 실행 비용 |
| 누락·오인식·삽입 사례 | 속도와 함께 볼 품질 |
| 입력 길이·모델·환경·반복 횟수 | 비교 재현 조건 |

18배·15배 주장에는 baseline이 없어 이 실습을 해당 수치의 재현이라고 부를 수 없다.

## 한국어와 용어 사전

일반 발화와 전문용어 발화를 분리하고, 동일 샘플을 사전 적용 전후로 비교한다. 자동 언어 감지·언어 전환은 별도 샘플로 관찰한다. 한국어 지원 여부와 업무 어휘의 인식 품질은 다른 평가 항목이다.

## 통신과 파일 관찰

통신 관찰과 파일 생성·변경 관찰을 각각 수행한다. 관찰 도구, 대상 프로세스, 시간 범위, 확인 가능한 경로를 기록한다. 모델 다운로드·업데이트 통신과 음성 입력 처리 중 통신을 구분하되, 현재 자료가 각각의 동작을 설명한다고 가정하지 않는다.

| 시점 | 확인 대상 |
|---|---|
| 입력 전 | 기존 파일·로그·사전 상태 |
| 처리 중 | 음성 사본·임시 파일·통신 |
| 출력 후 | 전사 자동 저장·히스토리·내보내기 |
| 앱 종료 후 | 임시 데이터·로그·전사 잔존 |
| 사용자 삭제 후 | 관찰 범위 내 잔존 파일·사본 |

이는 후보 확인 항목이며 실제 파일 생성이나 저장 위치를 단정하는 표가 아니다. 실습 파일은 민감정보가 없는 샘플을 사용하고, 원본을 파괴하는 삭제 실험은 피한다.

## 결론 작성의 경계

- “관찰 기간에 대상 프로세스의 통신을 발견하지 못했다”와 “항상 통신하지 않는다”를 구분한다.
- “관찰 경로에서 파일을 찾지 못했다”만으로 무보관을 선언하지 않는다.
- UI에서 삭제한 것과 잔존 데이터가 제거된 것을 구분한다.
- 관찰하지 못한 경로·권한 제한·다른 실행 조건을 결과에 함께 적는다.
