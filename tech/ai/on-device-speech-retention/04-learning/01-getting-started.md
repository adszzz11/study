# 시작하기: 평가 환경과 첫 기록

## 사전 준비

공식 배포처와 설치 절차는 미제공이다. 이 문서는 설치 완료를 가정한 평가 절차이며, 다운로드 URL이나 실행 명령을 추정하지 않는다. 설치 전 [[tech/ai/on-device-speech-retention/03-references|출처 보완 절차]]로 배포처·버전·요구 환경을 먼저 확인한다.

- 민감정보 없는 한국어 샘플: 일반 문장, 전문용어, 무음 구간을 준비한다.
- 입력 파일의 길이·내용을 고정하고 정답 전사를 작성한다.
- Mac 모델·칩·메모리·macOS·앱 버전·모델·사전 설정을 기록한다.
- 마이크와 파일 입력은 각각 별도 실행으로 기록한다.

## 첫 실습

1. 실행 전 관련 파일 상태와 관찰 시작 시각을 기록한다.
2. 입력 시작, 첫 텍스트 출력, 최종 결과 완료 시각을 각각 기록한다.
3. 먼저 출력된 텍스트가 나중에 바뀌는지 관찰한다.
4. 전사 결과를 정답과 비교하고 오류 사례를 남긴다.
5. 출력 후·앱 종료 후·사용자 삭제 후의 잔존 데이터를 확인한다.

```text
run_id:
환경 / 앱 버전 / 모델 / 사전 설정:
입력 방식 / 샘플 길이:
입력 시작 / 입력 종료 / 첫 출력 / 최종 완료:
출력 수정 사례 / 인식 오류:
파일·통신 관찰 범위:
확인된 사실 / 미확인 영역:
```

첫 출력 지연은 입력 시작부터 첫 출력까지, 입력 종료 후 대기는 입력 종료부터 최종 완료까지로 구분한다. 단일 실행의 결과를 일반적인 제품 성능으로 확대하지 않는다.

## 완료 기준

- [ ] 조건과 시간 기준을 다른 실행에서도 재사용할 수 있다.
- [ ] 점진적 출력과 최종 결과를 구분해 기록했다.
- [ ] 통신 관찰과 저장 관찰을 별도로 남겼다.
- [ ] 미관찰을 부재의 증거로 단정하지 않았다.
