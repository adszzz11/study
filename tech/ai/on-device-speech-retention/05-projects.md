# Projects: 평가에서 정책까지

## 1. 한국어 실시간 받아쓰기 평가 기록

일반 대화·전문용어·무음 구간을 포함한 고정 샘플을 모델별로 실행한다.

- **산출물:** 환경·버전·모델·입력 조건, 첫 출력·최종 완료 시간, 수정 이력, 오류 사례.
- **완료 기준:** 동일 조건 비교표와 재실행 가능한 기록이 있다.
- **판단 목적:** 자신의 환경에서 지연과 품질을 평가한다. 영상의 배수 주장을 재현했다고 단정하지 않는다.

## 2. 로컬 음성 데이터 수명주기 점검

마이크 입력과 파일 입력을 따로 실행하고 음성·전사·로그·사전의 생성 및 잔존 여부를 조사한다.

| 데이터 종류 | 관찰 위치·범위 | 생성 여부 | 종료 후 | 삭제 후 | 미확인 항목 |
|---|---|---|---|---|---|
| 음성·사본 | 미기록 | 미확인 | 미확인 | 미확인 | 기록 필요 |
| 전사·내보내기 | 미기록 | 미확인 | 미확인 | 미확인 | 기록 필요 |
| 임시 데이터·로그 | 미기록 | 미확인 | 미확인 | 미확인 | 기록 필요 |
| 용어 사전 | 미기록 | 미확인 | 미확인 | 미확인 | 기록 필요 |

- **산출물:** 생성 위치, 유지 시점, 삭제 방법, 미확인 영역을 기록한 보관 현황표.
- **완료 기준:** 관찰 사실과 추정을 분리하고 통신 결과를 별도로 첨부한다.
- **판단 목적:** Mac 내부 처리 설명과 실제 보관 동작 사이의 공백을 줄인다.

## 3. 업무용 전사 보관 정책 설계

아래는 채워야 할 정책 양식이며 제품이 지원하는 기능 목록이 아니다.

| 데이터 | 저장 허용 여부 | 보관 기간 | 삭제 책임 | 내보내기 규칙 |
|---|---|---|---|---|
| 입력 음성 | 결정 필요 | 결정 필요 | 지정 필요 | 결정 필요 |
| 전사 결과 | 결정 필요 | 결정 필요 | 지정 필요 | 결정 필요 |
| 용어 사전 | 결정 필요 | 결정 필요 | 지정 필요 | 결정 필요 |

- **산출물:** 데이터별 규칙과 제품 지원 여부의 차이를 적은 정책 초안.
- **완료 기준:** 실제 적용 전에 저장·삭제·내보내기 규칙을 제품이 지원하는지 확인한다.
- **판단 목적:** 처리 위치 설명에 의존하지 않고 업무에 필요한 데이터 수명을 명시한다.
