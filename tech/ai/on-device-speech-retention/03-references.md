# References: 근거와 미확인 정보

## 제공 자료

유일한 근거는 사용자 제공 dossier와 그 안의 영상 요약이다. 원본 영상, 공식 문서, 소스코드, 라이선스 원문 및 측정 보고서의 URL은 없다. 제품이 무료·오픈소스라는 설명도 영상의 소개 수준이다.

## 근거 추적표

| 주장 | 현재 근거 | 추가 확인 자료 |
|---|---|---|
| Mac 내부 처리·녹음 미전송 | 영상 요약 | 공식 설명·코드·범위를 정한 통신 관찰 |
| 점진적 출력·한국어·사전·모델 선택 | 영상 요약 | 기능 문서·동일 조건 실행 기록 |
| 최대 18배·15배 | 조건 없는 영상 주장 | baseline·모델·환경·단위·반복 측정 |
| 로컬 무보관·자동 삭제 | 근거 없음 | 저장 정책·파일 및 삭제 관찰 |
| 완전한 오프라인 동작 | 근거 없음 | 초기 준비와 실행을 분리한 시험 |

## 출처 보완 절차

1. 원본 영상 URL과 게시일을 확보한다.
2. 영상이 가리키는 공식 저장소·문서를 확인한다. 이름이 유사한 프로젝트와 혼동하지 않는다.
3. 버전·commit·라이선스·모델 준비 조건을 기록한다.
4. 문서상의 주장과 직접 관찰한 결과를 구분해 추가한다.

현재는 설치 명령이나 저장 경로를 추정해서 제공하지 않는다.
