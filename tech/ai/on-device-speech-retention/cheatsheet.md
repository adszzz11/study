# Cheatsheet: 처리 위치 ≠ 데이터 수명

## 세 질문

| 축 | 질문 | 현재 답 |
|---|---|---|
| 위치 | 어디서 처리하는가? | 영상은 Mac 내부라고 설명 |
| 시점 | 언제 결과가 나오는가? | 확실한 부분부터 출력한다고 소개 |
| 보관 | 무엇을 얼마나 남기는가? | 정책 미확인 |

## 주장 읽기

- 서버 미전송 ≠ 로컬 무보관.
- 로컬 처리 설명 ≠ 완전한 오프라인 보장.
- 점진적 출력 ≠ 이후 수정이 없는 최종 전사.
- 한국어 지원 ≠ 특정 업무 용어의 정확도 보장.
- 최대 18배·15배는 조건 없는 영상 주장. 합산·곱셈·제품 순위 산정에 사용하지 않는다.

## 실행 전후 체크

- [ ] 공식 배포처·버전·요구 환경 확인
- [ ] 민감정보 없는 고정 샘플·정답 준비
- [ ] Mac·모델·사전·입력 방식 기록
- [ ] 첫 출력·수정 이력·최종 완료 기록
- [ ] 동일 조건에서 모델·사전 전후 비교
- [ ] 통신과 파일 생성·변경을 각각 관찰
- [ ] 입력·처리 중·출력 후·종료 후·삭제 후 확인
- [ ] 음성·전사·임시 데이터·로그·사전별 수명 기록
- [ ] 관찰 사실·추정·미확인 영역 구분

## 결과 문장 양식

```text
[환경·버전·모델]에서 [샘플]을 [관찰 범위·시간] 동안 실행했다.
관찰한 사실: …
확인하지 못한 영역: …
이 결과만으로 무보관·항상 오프라인·제품 전반의 성능을 보장하지 않는다.
```
