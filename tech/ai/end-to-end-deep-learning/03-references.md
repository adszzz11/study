## 후속 확보 순서

1. 원본 영상 URL, 게시자, 게시일과 00:32 장면의 실제 내용을 확인한다.
2. 공식 커리큘럼의 대상 기수·버전과 실습 안내를 확보한다.
3. 논문의 정확한 제목·저자·연도·DOI 또는 공식 원문 URL을 식별한다.
4. 코드 저장소, 데이터 사용 조건, 실행 환경과 평가 절차를 확인한다.
5. 각 주장에 근거 위치와 확인일을 붙인다. 확보 전에는 미확인 상태를 유지한다.

## 근거 기록 양식

```text
주장:
출처 제목 / URL: 미확보
위치: 타임스탬프 / 페이지 / 절
직접 확인 내용:
해석:
남은 불확실성:
확인일:
```

유사한 제목의 논문이나 기관 홈페이지를 원본 출처로 임의 대체하지 않는다. 제공 자료에 URL이 없으므로 출처 URL을 만들어 기재하지 않는다.
