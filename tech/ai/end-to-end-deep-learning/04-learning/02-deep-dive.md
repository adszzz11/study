# 심화: 학습 경계와 재현성 검증

## 전제

이 문서는 제공된 수업 내용이 아닌 후속 검증 제안이다. 공식 코드·데이터·설정이 확보된 범위에서만 진행하며, 특정 Framework나 모델 구조를 전제하지 않는다.

## 핵심 검증 질문

| 주제 | 질문 | 확인할 근거 |
|---|---|---|
| 데이터 흐름 | 입력이 어떤 단계를 거쳐 출력이 되는가? | 코드 경로, 모델 설명 |
| 학습 경계 | 어느 구성 요소가 실제 업데이트되는가? | 학습 설정, Optimizer 대상, 업데이트 기록 |
| 학습 목표 | 어떤 Loss가 어떤 출력에 적용되는가? | Loss 구현, 학습 루프 |
| 평가 | 지표가 실제 과제의 성공을 측정하는가? | 평가 코드, 지표 정의 |
| 재현성 | 같은 조건으로 결과를 재현할 수 있는가? | 버전, seed, 데이터 분할, 실행 로그 |

학습 경계는 이름이나 단일 Loss의 존재만으로 판단하지 않는다. 코드의 연결, 고정된 부분, 업데이트 대상을 함께 확인한다.

## 실험 기록 절차

1. 데이터 이용 조건과 train/validation/test 분할을 기록한다. 전처리에 평가 데이터가 섞이는지 확인한다.
2. 환경 버전, 실행 명령, 학습 설정, seed와 결과 저장 위치를 기록한다.
3. Baseline이 있다면 동일한 데이터·지표·학습 조건에서 비교한다. 차이가 있다면 제한으로 명시한다.
4. 반복 실행이 가능하면 결과 변동을 보고하고, 단일 실행 결과를 일반 성능으로 확대하지 않는다.
5. 실패 사례와 재현 실패도 기록한다. 결과를 논문 채택·취업 성과와 분리한다.

## 결과 표 양식

| 방식·버전 | 데이터 분할 | 학습 조건 | 평가 지표·값 | 반복·변동 | 실패 사례 | 근거 |
|---|---|---|---|---|---|---|
| 미확인 | 미확인 | 미확인 | 미측정 | 미측정 | 미수집 | 미확보 |

소개 논문을 분석할 때는 본문의 방법·실험과 커리큘럼 설명을 각각 읽는다. 영상 내 동시 등장만으로 실습 연관성을 인정하지 않는다.
