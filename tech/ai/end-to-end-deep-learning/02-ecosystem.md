# Ecosystem: 등장 요소와 비교 조건

## 함께 등장하는 요소

아래는 기술적 우열이나 경쟁 제품 비교가 아니라 **자료에서의 역할을 구분한 표**다.

| 요소 | 자료에서의 역할 | End-to-End 딥러닝과의 관계 |
|---|---|---|
| AI 연구 심화 부트캠프 | 교육 프로그램 홍보 | 커리큘럼 항목으로 포함 |
| AIFFEL 웹페이지 | 폐 기능 관련 논문 소개 화면 | 논문과의 기술적 연결 미확인 |
| NeurIPS | 로고와 논문 채택 강조 | 해당 주제와 직접 연결 미확인 |
| MICCAI | 논문 관련 화면의 표기 | 사용 모델·학습 방식 미확인 |
| perturbation signatures 기반 검색 연구 | 마지막 논문 제목의 연구 주제 | End-to-End 적용 여부 미확인 |

## 대안 비교를 위한 조건

자료에는 경쟁 기법이나 대안 architecture가 없다. 비교는 동일한 문제에 대한 구현과 실험 조건을 확보한 후 수행한다.

| 비교 축 | 확보할 근거 |
|---|---|
| 문제와 데이터 | 동일한 입력·출력, 데이터 분할, 전처리 |
| 모델과 학습 범위 | 구성 요소, 고정·학습 여부, 대안 Baseline |
| 학습 조건 | Loss, Optimization, 학습 예산, 설정 |
| 평가 | 동일한 지표·평가 데이터, 반복 실행 결과 |
| 실용성 | 실행 비용, 지연, 오류 사례 등 실제 요구사항 |

학회 이름이나 논문 채택은 위 실험의 대체 지표가 아니다. 현재 상태에서는 특정 접근의 우월성을 결론 내리지 않는다.
