# Overview: 무엇이 확인되었는가

> **한 줄 정의**: 제공 자료에서 확인되는 것은 교육 항목의 존재이며, 기술적 정의와 구현 범위는 미제공이다.

## What

「AI 취업 준비를 위한 논문 실적과 연구 부트캠프 소개」의 커리큘럼 화면에 End-to-End 딥러닝이 등장한다. dossier는 이 장면을 영상 00:32와 연결한다. 원본 영상을 직접 확인한 타임스탬프는 아니다.

## Why

AI 취업 준비와 논문 실적을 다루는 영상에 NeurIPS 로고, 논문 채택 강조 자막, AIFFEL 웹페이지의 폐 기능 관련 논문과 MICCAI 표기가 함께 등장한다. 따라서 연구 역량을 위한 교육 항목이라는 해석은 가능하다. 다만 함께 등장했다는 사실은 기술적 연결의 증거가 아니다.

핵심 공백은 **무엇을 배운다고 소개하는지**와 **어떤 문제를 어떤 모델로 해결하는지** 사이에 있다.

## 특징과 architecture의 확인 범위

| 분석 항목 | 자료에서 확인되는 내용 | 확인할 수 없는 내용 |
|---|---|---|
| 교육상 위치 | 월별 커리큘럼의 항목 | 선수 지식, 기간, 세부 목표 |
| 실습 | 직접 실습 가능하다는 자막 | 데이터, 코드, 환경, 평가 기준 |
| 연구 지원 | 팀별 연구비 언급 자막 | 금액, 조건, 이 항목과의 직접 관계 |
| 모델 구조 | 설명 없음 | 입력·출력, 모듈, 학습 가능 범위 |
| 학습·평가 | 설명 없음 | Loss function, Optimization, Baseline, 성능 |

이름만으로 데이터 흐름이나 학습 경계를 확정하지 않는다. 특정 architecture를 도식화하거나 하나의 Loss로 전체 모델을 학습한다고 단정할 수 없다.

## 해석에서 제외할 주장

- 소개 논문들의 실제 연구 방법이 End-to-End라는 주장
- 교육이 논문 채택이나 취업 성과를 보장한다는 주장
- NeurIPS 또는 MICCAI가 부트캠프를 인증·운영한다는 주장

마지막 논문 제목은 세포 수준의 perturbation signatures를 활용한 표적·화합물 검색 연구를 가리킨다. 정확한 제목·저자·식별자, 사용 방법, 교육 실습 여부, 결과는 확인되지 않았다.
