## 읽는 순서와 검증 질문

1. Inspo AI MCP page에서 지원 client, account requirement, privacy policy가 현재도 명시되는지 확인한다.
2. 연결 화면에서 server URL, OAuth 또는 API key, requested scope, data retention을 기록한다.
3. MCP Client의 tool inventory에서 tool 이름, 입력 schema, write/data-access 여부를 확인한다.
4. 대안 문서와 비교하되, 서로 다른 제품인 Inspo AI와 Nutlope Inspo를 혼동하지 않는다.

> [!note] Evidence boundary
> 이 노트의 제품-specific 사실은 위 공개 페이지와 dossier에 기반한다. 공개 문서에 없는 endpoint, tool schema, rate limit, source availability는 추측으로 보완하지 않는다.
