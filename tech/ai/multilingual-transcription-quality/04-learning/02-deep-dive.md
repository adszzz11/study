# 심화 학습: 정확도·지연·기능별 효과

## 정확도 지표

정답과 최종 전사를 동일 규칙으로 정규화한 뒤 비교한다.

```text
CER = (문자 치환 S + 삭제 D + 삽입 I) / 정답 문자 수 N
WER = (단어 치환 S + 삭제 D + 삽입 I) / 정답 단어 수 N
```

N이 0인 입력은 별도 처리한다. 한국어 WER은 공백 분할 방식의 영향을 받으므로 어절 기준인지 명시한다. CER도 공백 포함 여부와 문자 단위(예: Unicode 완성형 음절)를 고정한다. 숫자, 문장부호, 영문 대소문자 정규화 규칙을 결과와 함께 보관한다. 정규화가 실제 편집 부담을 감출 수 있어 원문 출력도 보존한다.

## 지연과 출력 안정성

| 항목 | 측정 정의 예시 | 주의점 |
|---|---|---|
| 첫 출력 지연 | 입력 시작부터 첫 텍스트까지 | 로딩 포함 여부 고정 |
| 발화 후 출력 지연 | 구간 발화 종료부터 대응 텍스트까지 | 구간 매칭 기준 필요 |
| 전체 처리 시간 | 입력 시작부터 최종 출력까지 | 파일·마이크 결과 구분 |
| 출력 수정 | 관측된 기존 텍스트 변경 횟수 | 출력 기록이 가능한 범위에서만 측정 |
| 편집 시간 | 최종 출력을 정답 수준으로 고치는 시간 | 같은 검수자·기준 유지 |

첫 텍스트가 빠르게 나와도 오류가 많아 검수 시간이 늘 수 있다. 지연과 정확도, 최종 편집 시간을 함께 판단한다.

## 보조 기능 통제 실험

한 번에 한 조건만 바꾸고 동일 입력을 반복한다. 기능을 끌 수 없거나 편집할 수 없다면 효과를 분리할 수 없다고 기록한다.

| 기능 | 대조 조건 | 관찰 항목 |
|---|---|---|
| 용어 사전 | 가능하면 적용 전후 | 정답에 있는 용어의 오인식·누락 |
| 후보 비교 | UI가 허용하는 비교 절차 | 후보 선택 시간, 최종 오류 |
| 무음 건너뛰기 | 가능하면 켜기·끄기 | 무음 전후 발화 누락, 처리 시간 |
| 단어 경계 유지 | 가능하면 설정별 비교 | 경계 오류와 수동 편집 횟수 |
| 언어 감지 | 가능하면 자동·수동 | 언어 선택 오류, 혼합 발화 오류 |

자동 언어 감지 성공과 code-switching 성공은 따로 기록한다. 후보 비교가 수동인지 자동인지 확인하기 전에는 UI 동작을 가정하지 않는다.

## 모델 크기와 재현성

tiny~large 중 실제 제공되는 모델을 같은 파일로 비교한다. 실행 순서를 바꾸고 반복 횟수·각 결과·대표값을 남긴다. 로딩·캐시 상태와 백그라운드 부하를 맞추고, 메모리 등 자원 측정 방법도 기록한다.

최적 모델은 측정한 Mac·음성·허용 지연 조건에서 선택한다. 영상의 최대 18배·15배 주장을 재현하려면 원래 비교 기준이 먼저 필요하다. 이 수치로 전체 처리 속도를 계산하지 않는다.
