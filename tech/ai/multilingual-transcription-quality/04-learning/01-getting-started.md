# 시작하기: 첫 평가 실행

## 목표와 준비

설치 방법은 자료에 없다. 공식 배포처와 설치 문서를 확보한 뒤 진행하며, 추정한 저장소나 설치 명령을 사용하지 않는다. 지원 Mac과 실제 실행 가능한 버전·모델을 확인한다.

공개 실습에는 동의를 받은 음성이나 직접 읽은 비민감 문장을 사용한다. 원본 음성이나 개인 정보가 포함된 전사를 공개 vault에 그대로 올리지 않는다.

## 1. 평가 세트 만들기

| 입력 유형 | 예시 또는 목적 |
|---|---|
| 한국어 일반 문장 | 일상 문장과 띄어쓰기 |
| 전문용어·영어 약어 | “API 응답과 GPU 메모리를 확인합니다.” |
| 숫자 | “회의는 오후 세 시, 예산은 십오만 원입니다.” |
| 한국어·영어 혼합 | 문장 중 언어 전환과 용어 보존 |
| 긴 무음 포함 | 무음 전후 짧은 발화의 누락 |

직접 정답 전사를 작성하고 입력 파일을 고정한다. 숫자를 문자와 숫자 중 무엇으로 비교할지, 공백·문장부호·영문 대소문자를 어떻게 처리할지 먼저 정한다.

## 2. 기준 실행

1. Mac 기종·칩·메모리, OS, 앱 버전, 모델명, 입력 길이를 기록한다.
2. 녹음 파일 하나로 첫 출력 시간·전체 처리 시간·최종 전사를 수집한다.
3. 같은 문장을 마이크로 읽어 실제 받아쓰기 사용성을 살펴본다.
4. 먼저 출력된 문장이 바뀌는지 관찰하고, 확인할 수 없다면 미관측으로 기록한다.
5. 정답 대비 오류와 사람이 수정하는 시간을 기록한다.

모델 다운로드·로딩 시간을 포함했는지 명시하고, 파일 전사와 마이크 측정은 별도 결과로 보관한다.

## 3. 기록 양식

```text
run_id / 날짜:
Mac·메모리 / OS / 앱 버전 / 모델:
입력 ID / 길이 / 마이크 또는 파일:
설정 / 사전 / 사전 로딩 여부:
첫 출력까지 초 / 전체 처리 초:
출력 수정 관측 / 누락·용어 오류:
정답 정규화 규칙 / 최종 전사:
사람의 검수·편집 시간:
```

## 완료 기준

- [ ] 동일 입력과 정답 전사를 준비했다.
- [ ] 첫 출력 시간과 전체 처리 시간을 분리했다.
- [ ] 관측한 결과와 소개된 기능을 구분했다.
- [ ] 설정에서 지원하지 않는 조작은 미지원 또는 미확인으로 기록했다.
