# Projects: 실전 평가

아래는 실행 제안이며 완료된 실험이나 측정 결과가 아니다.

## 1. 한국어 기술 회의 전사 평가

- **질문:** 영어 약어·전문용어가 있는 회의에서 언어 감지, 사전, 후보 비교가 검수 부담을 줄이는가?
- **절차:** 동의받은 평가 음성의 정답을 작성하고 동일 파일로 모델별 실행을 수행한다. 허용되는 설정에서 사전 적용 전후와 후보 검수 시간을 비교한다.
- **산출물:** 정답 전사, 실행 조건, 모델별 CER/WER, 전문용어 오류 목록, 검수 시간.
- **완료 기준:** 혼합 언어 오류와 일반 한국어 오류를 구분하고, 기능 효과를 분리하지 못한 조건을 명시한다.

회의 요약과 화자 분리는 소개된 기능이 아니므로 별도 기능으로 취급한다.

## 2. 로컬 받아쓰기 사용성 검증

- **질문:** 빠른 첫 출력이 실제 문장 완성 시간을 줄이는가?
- **절차:** 같은 문장 목록을 마이크로 읽고 첫 출력 지연, 관측 가능한 수정 횟수, 경계 오류와 수동 편집 시간을 기록한다.
- **산출물:** 문장별 측정표, 오류 사례, 설정별 편집 부담 비교.
- **완료 기준:** 인식 속도와 사용 가능한 문장으로 고치는 시간을 함께 보고한다.

로컬 처리 설명과 별도로 저장·로그·네트워크 동작을 확인하고, 미확인 항목을 남긴다.

## 3. 녹음 파일 모델 선택 가이드

- **질문:** 현재 Mac에서 허용 지연과 정확도를 만족하는 모델은 무엇인가?
- **절차:** 같은 파일을 실제 지원되는 모델 크기로 반복 처리한다. 로딩 포함 여부를 고정하고 정확도·전체 시간·자원 사용을 비교한다.
- **산출물:** 모델별 비교표와 입력 유형별 선택 기준.
- **완료 기준:** 추천의 적용 범위를 측정한 기기·버전·음성·모델로 제한한다.
