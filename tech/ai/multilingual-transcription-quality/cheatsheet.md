# Cheatsheet: 전사 품질 평가

## 빠른 확인

| 항목 | 기억할 점 |
|---|---|
| 엔진 | Lightning-SimulWhisper, 무료·오픈소스 Mac 전용으로 소개 |
| 입력 | 마이크·녹음 파일 |
| 출력 | 확실한 부분부터 실시간 출력, 확정·수정 정책 미확인 |
| 언어 | 한국어·자동 감지 소개, code-switching은 별도 검증 |
| 보조 | 경계 유지·후보 비교·무음 건너뛰기·용어 사전 |
| 모델 | tiny~large 선택, 크기별 추천 근거 없음 |
| 로컬 | Mac 내부·서버 미전송 설명, 저장·로그 정책 미확인 |
| 가속 | M2 Neural Engine 강조, 전체 실행 장치 구성 미확인 |
| 성능 | 최대 18배·15배는 조건 없는 영상 주장, 합산·곱셈 금지 |

## 실행 체크리스트

- [ ] 공식 배포처·버전·설치 문서를 확보한다.
- [ ] Mac·OS·모델·입력·설정·로딩 조건을 기록한다.
- [ ] 정답과 공백·숫자·문장부호 정규화 규칙을 고정한다.
- [ ] 첫 출력·발화 후 지연·전체 시간을 분리한다.
- [ ] CER/WER과 전문용어 오류, 무음 전후 누락을 기록한다.
- [ ] 관측 가능한 출력 수정과 사람이 고치는 시간을 기록한다.
- [ ] 설정이 허용되면 한 조건씩 바꿔 반복한다.
- [ ] 결과의 적용 범위와 미확인 사항을 명시한다.

```text
CER/WER = (치환 + 삭제 + 삽입) / 정답 단위 수
단위: 문자 또는 명시한 단어 분할 기준
판단: 정확도 + 지연 + 자원 사용 + 편집 시간
```

## 피해야 할 결론

- “한국어 지원 → 한국어 정확도 검증 완료”
- “자동 감지 → 혼합 언어 안정 처리 보장”
- “로컬 처리 → 로그·보관·삭제 정책도 확인 완료”
- “큰 모델 → 현재 Mac에서 항상 최적”
- “기능 소개 → 전사 품질 개선 입증”
