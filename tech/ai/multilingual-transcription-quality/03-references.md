# References: 출처와 근거 상태

## 제공된 자료

| 자료 | 형태 | URL | 사용 범위 |
|---|---|---|---|
| Lightning-SimulWhisper 소개 영상 요약 dossier | 사용자 제공 텍스트 | 미제공 | 기능 소개와 영상의 성능 주장 정리 |

원본 영상, 공식 저장소, 설치 가이드, 라이선스 원문, 실험 결과가 없어 교차 검증하지 못했다. 무료·오픈소스·Mac 전용이라는 설명도 제공 자료의 소개 내용으로 취급한다. 이름이 비슷한 프로젝트를 공식 출처로 추정하지 않는다.

## 추가로 확보할 자료

- 원본 영상 URL과 게시 시점: 화면 및 발언의 문맥 확인.
- 공식 저장소·릴리스·라이선스: 배포 주체, 설치 절차, 지원 OS와 하드웨어 확인.
- 언어·모델 문서: 지원 언어 전체, code-switching, 모델별 제한 확인.
- 기능 설명: 경계 유지, 후보 비교, 사전 편집과 반영 방식 확인.
- 데이터 정책: 네트워크 전송, 로그, 저장 위치·보관·삭제 방식 확인.
- 벤치마크 원문: 18배·15배의 기준 장치, 입력, 모델, 측정 구간과 반복 횟수 확인.
