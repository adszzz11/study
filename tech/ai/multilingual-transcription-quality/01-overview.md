# Overview: What / Why / 특징

## What

Lightning-SimulWhisper는 무료·오픈소스 Mac 전용 실시간 받아쓰기 엔진으로 소개된다. 전체 녹음이 끝난 뒤 전사하는 방식과 달리 **확실한 부분부터 먼저 출력**한다. 이는 최종 처리 시간뿐 아니라 유용한 텍스트를 처음 확인하는 시점도 평가해야 한다는 뜻이다.

## Why

다국어 전사는 음성을 문자로 바꾸는 일과 문장을 사용 가능한 형태로 다듬는 일을 함께 포함한다. 언어 감지는 언어 선택을, 단어 경계 유지와 후보 비교는 출력 품질을, 용어 사전은 전문용어 처리를 보조할 수 있다. 기능 소개만으로 한국어 정확도나 편집 시간 감소가 입증되지는 않는다.

## 기능적 구성

```text
마이크 또는 녹음 파일
        ↓
Mac 내부 음성 처리
        ↓
자동 언어 감지 및 음성 인식
        ↓
인식이 확실한 부분부터 텍스트 출력

보조: 단어 경계 유지 / 후보 비교 / 무음 건너뛰기 / 용어 사전
선택: tiny ~ large 모델 크기
```

개념도이며 실제 모듈 순서, 병렬화, 내부 API, 보조 기능 적용 단계는 확인되지 않았다.

## 핵심 특징과 확인 과제

| 특징 | 자료에서 소개된 내용 | 별도 검증할 내용 |
|---|---|---|
| 실시간 출력 | 확실한 부분부터 출력 | 확정 기준, 이후 수정 여부, 지연·정확도 균형 |
| 한국어 | 지원한다고 소개 | CER/WER, 띄어쓰기, 숫자·고유명사 오류 |
| 자동 언어 감지 | 언어 자동 선택 보조 | 전체 언어 목록, 문장 내 code-switching |
| 단어 경계 유지 | 경계 유지 기능 | 보존 대상, 한국어 적용 방식 |
| 후보 비교 | 관련 기능 소개 | 자동 선택인지 사용자 선택인지 |
| 무음 건너뛰기 | 관련 기능 소개 | 검출 방식, 무음 전후 발화 누락 |
| 용어 사전 | 사전 제공 | 사용자 편집 여부, 인식 반영 방식 |
| 모델 선택 | tiny~large 선택 화면 | 크기별 정확도, 메모리, 지연 |

확실한 결과를 출력한다는 설명을 특정 confidence threshold나 decoding 알고리즘의 증거로 해석하지 않는다. 임시·확정 텍스트 구조도 미확인이다.

## 로컬 처리와 가속 주장의 경계

영상은 서버로 녹음을 보내지 않고 Mac 내부에서 처리한다고 설명한다. 파일 저장 위치, 로그, 보관 기간, 삭제 정책은 알려져 있지 않다.

M2 Neural Engine과 함께 소리 분석 최대 18배, 텍스트 변환 최대 15배 빠르다는 수치가 제시된다. 비교 대상·입력 길이·모델·반복 횟수·측정 과정이 없어 검증된 벤치마크로 사용할 수 없다. 두 수치를 곱하거나 합쳐 전체 속도 향상으로 해석할 수 없고, 전체 파이프라인이 Neural Engine에서 실행된다고도 단정할 수 없다.
