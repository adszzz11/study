# Ecosystem: 처리 방식과 선택지 비교

## 비교 범위

제공 자료에는 경쟁 제품이나 외부 서비스가 없다. 제품별 우열·가격·최고 정확도 순위 대신 처리 방식과 평가 조건을 비교한다.

| 비교 축 | 소개된 방식 | 대안 또는 비교 기준 | 판단 가능한 범위 |
|---|---|---|---|
| 결과 시점 | 확실한 부분부터 실시간 출력 | 녹음 종료 후 배치 전사 | 출력 방식 차이, 실제 지연은 측정 필요 |
| 처리 위치 | Mac 내부, 서버 미전송 설명 | 서버 전송 방식 | 외부 제품의 비용·품질 비교 불가 |
| 입력 | 마이크·녹음 파일 | 실시간 사용성·동일 파일 반복 | 두 입력 지원 소개 |
| 언어 | 한국어·자동 감지 | 수동 선택이 가능하면 대조 | 지원 언어 전체·감지 정확도 불명 |
| 모델 | tiny~large 선택 | 동일 입력 모델별 비교 | 성능 순위와 추천 크기 불명 |
| 보조 기능 | 경계·후보·무음·사전 | 설정이 허용되면 적용 전후 비교 | 각 기능의 기여도 미검증 |

## 선택 기준

- 실시간 사용: 첫 출력 시점, 발화 후 지연, 출력 수정, 최종 편집 시간을 기록한다.
- 기존 파일 처리: 동일 파일과 정답 전사로 정확도·전체 처리 시간·자원 사용을 비교한다.
- 민감한 음성: 로컬 처리 설명 외에도 실제 네트워크 동작, 파일·로그 정책을 확인한다.
- 전문용어: 사전 편집과 반영 방식부터 확인하고 용어 오류율을 비교한다.

로컬 실시간 전사와 품질 보조 기능의 결합이라는 방향은 확인할 수 있지만 경쟁 우위는 입증되지 않았다.
