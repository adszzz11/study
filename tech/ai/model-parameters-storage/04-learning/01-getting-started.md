# 시작하기: 관찰과 해석 분리

## 목표

모델을 추측해 설치하기보다, 현재 자료에서 말할 수 있는 범위를 기록한다. 아래 실습은 제안이며 영상의 검증 결과가 아니다.

## 1. 관찰표 작성

| 표기 | 관찰 | 측정 대상 | 다른 수치와의 관계 |
|---|---|---|---|
| 약 54GB | 비교 막대에 등장 | 미확인 | 미확인 |
| 약 3.6GB | 비교 막대에 등장 | 미확인 | 미확인 |
| 5.9GB | 별도 표기 | 미확인 | 미확인 |

같은 화면에 있다는 이유로 변환 전후 관계를 부여하지 않는다.

## 2. 조건부 계산

```python
large = 54
small = 3.6
ratio = large / small  # 15.0: 두 수치가 동일 기준이라는 가정
print(ratio)
```

- 계산 결과: 15배.
- 비교 타당성: 동일 모델·파일 범위·단위 기준 확인 전까지 보류.
- 금지할 해석: “특정 모델을 15배 압축했다.”

## 3. 항목을 분리해 기록

```text
모델 식별자/revision: 미확인
Parameters 수: 미확인
표현 방식/저장 규격: 세 가지 값 사용 설명 / 규격 미확인
배포 파일 범위·크기: 미확인
출처 URL·timestamp: 미제공
```

## 4. 실행 성공의 의미 정의

- [ ] 배포 파일 확보 및 식별.
- [ ] 모델 로딩 성공.
- [ ] 응답 생성 성공.
- [ ] 목표 코딩 작업 성공 기준 충족.

다운로드 성공을 작업 수행 성공으로 기록하지 않는다.

## 완료 기준

각 수치에 관찰·가정·미확인 표시가 있고, 파라미터 수와 파일 크기가 별도 항목이면 다음 단계로 진행한다.
