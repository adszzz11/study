# References: 출처와 검증 상태

## 원자료 상태

유일한 제공 근거는 사용자 dossier다. 영상 URL·제목·모델 식별자·모델 카드·라이선스 원문 연결이 없다. 아래 URL은 추가 학습용이며 원영상의 빈칸을 채우는 증거로 사용하지 않는다.

| 자료 | 용도 | 한계 |
|---|---|---|
| 제공 dossier | 관찰과 검증 과제 정리 | 원영상 대조 불가 |
| Transformers Quantization 문서 | 저장 표현 관련 일반 개념 학습 | 영상의 적용 기법을 식별하지 않음 |
| Apache License 2.0 원문 | 라이선스 문구 읽기 | 특정 배포물에 적용됨을 입증하지 않음 |

## 추가 확보할 근거

- 원영상 URL과 각 수치의 timestamp, 화면 문맥.
- 모델 저장소 URL·revision·파일 목록·모델 카드.
- 파라미터 수, 저장 규격, 표현 적용 범위.
- 코딩 평가 문제·프롬프트·지표·실행 기록.
- 장치 사양, 런타임 버전, 설정, 메모리·응답 측정.
- 해당 배포물의 LICENSE 및 적용 대상.

## 인용 원칙

관찰, 조건부 계산, 일반 개념, 미확인을 구분한다. 원자료가 확보되면 출처와 측정 기준을 먼저 기록한 뒤 비교표를 갱신한다.
