# Cheatsheet: 빠른 판단 기준

## 개념 구분

| 질문 | 확인할 대상 |
|---|---|
| 모델 값이 몇 개인가? | Parameters 수 |
| 값을 어떻게 표현하는가? | 저장 표현·규격·적용 범위 |
| 다운로드 크기는 얼마인가? | 파일 목록·범위·단위 |
| 장치에서 실행되는가? | 메모리·런타임·설정·실측 |
| 코딩에 쓸 만한가? | 같은 과제·판정 기준의 평가 |
| 문서가 밖으로 나가는가? | 실제 데이터 흐름·외부 호출·저장 |

## 수치 해석

| 주장 | 판단 |
|---|---|
| 약 54GB·3.6GB 비교가 등장 | dossier에서 확인 |
| 54 ÷ 3.6 = 15 | 동일 기준이라는 조건부 계산 |
| 특정 모델의 15배 압축 | 확인 불가 |
| 5.9GB는 실행 메모리 | 확인 불가 |
| 세 가지 값이 특정 bit-width를 뜻함 | 확인 불가 |
| 코딩 성능 유지 | 평가 조건·결과 부족 |
| 공개 가중치면 모든 노트북에서 실행 | 성립하지 않음 |

## 확인 체크리스트

- [ ] 모델명·revision·출처를 확보했는가?
- [ ] 파라미터 수, 표현 방식, 파일 크기를 분리했는가?
- [ ] 비교 파일의 범위와 단위가 같은가?
- [ ] 코딩 평가의 문제·설정·지표가 같은가?
- [ ] 로딩·생성·목표 작업 성공을 구분했는가?
- [ ] 실제 배포물의 라이선스 적용 범위를 확인했는가?
- [ ] 문서의 처리·전송·보관 경로를 확인했는가?

## 기록 문장

> 약 54GB와 3.6GB는 동일 기준일 때 산술적으로 15배 차이다. 모델과 파일 범위는 미확인이며, 5.9GB와의 관계·성능 유지·실행 메모리 요구는 확정할 수 없다.
