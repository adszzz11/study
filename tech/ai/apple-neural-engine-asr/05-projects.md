# Projects: 적용 전 검증

아래 프로젝트는 실습 제안이며 수행 결과가 아니다. 결과에는 기기·버전·입력·설정·반복 횟수와 미측정 항목을 함께 남긴다.

## 1. 실시간 한국어 받아쓰기

- 입력: 짧은 메모, 긴 발화, 중간에 멈추는 발화.
- 절차: 마이크 입력의 첫 표시·확정·수정을 구간별 기록하고 정답 전사문과 비교한다.
- 산출물: 최초 출력 지연, 확정 지연, 수정 빈도, 오인식·누락 표.
- 판단: 사용자가 결과를 보면서 계속 말할 수 있는지, 장시간 지연이 누적되는지 평가한다. 허용 지연 기준은 실행 전에 정한다.

## 2. 전문용어 사전 효과

- 입력: 반복되는 제품명·약어·전문용어가 든 고정 녹음.
- 절차: 설정이 허용되면 사전만 변경해 적용 전후를 비교한다.
- 산출물: 용어 정인식 건수/전체 등장 건수와 일반 문장의 오류 변화.
- 판단: 특정 용어 개선이 일반 문장 오류 증가와 함께 나타나는지 확인한다. 사전 기능의 내부 작동 방식은 별도 근거가 필요하다.

## 3. 녹음 파일 모델 비교

- 입력: 같은 음성 파일과 정답 전사문.
- 절차: 언어·사전 설정을 고정해 모델별 반복 실행을 진행한다.
- 산출물: 아래 표와 모델 선택 이유. 첫 실행/반복 실행은 분리한다.

| 모델·버전 | 입력 길이 | 처리 시간·RTF | 최초 출력 | CER·누락 | 메모리 | 실행 조건 |
|---|---|---|---|---|---|---|
| 실행 후 기입 | — | — | — | — | — | — |

- 판단: 해당 Mac과 입력 유형에 맞는 지연·정확도·메모리 절충을 찾는다. 측정 전 tiny나 large의 성능을 단정하지 않는다.

## 4. 로컬 음성 처리 점검

- 상황: 외부 음성 전송을 피해야 하는 환경.
- 절차: 모델 준비 단계와 받아쓰기 단계를 나누어 네트워크 활동, 결과 저장 위치, 로그·임시 파일을 점검한다.
- 산출물: 관찰 조건·통신 목적의 확인 여부·저장/삭제 동작·추가 확인 필요 항목.
- 판단: 관찰한 실행 범위에서만 결론을 내린다. 앱 전체의 무통신이나 저장 데이터 보호를 자동으로 보장하지 않는다.
