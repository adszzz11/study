> **한 줄 정의**: 원문 Reel의 캡션·화면·음성 증거가 확보되지 않은 상태에서, 내용을 추정하지 않고 증거 수집과 provenance 기록을 먼저 설계하는 social-video research protocol이다.

## Overview

이 URL은 공개 Reel이지만, 조사 시점에는 공개 웹 인덱스의 제목·작성자·캡션·전사본과 로그인 없이 확인 가능한 원문을 확보하지 못했다. 그러므로 이 노트는 Reel의 주제나 도구를 단정하지 않는다. 대신 입력 증거가 도착했을 때 검증 가능한 tool study로 전환하기 위한 **evidence gate**를 정의한다.

- 현재 판정: `insufficient evidence` — 주제, 작성자, 주장, 데모 절차 모두 미확인
- 허용 입력: 캡션 원문, 화면 캡처, 음성 전사, 작성자가 제공한 공개 링크
- 산출물: claim-evidence matrix, timestamped observation, 재현 가능한 learning note

## When To Use

- social post의 주제가 확인되지 않았지만 조사 요청을 기록해야 할 때
- 짧은 영상의 주장·UI·명령을 재현 가능한 근거로 남겨야 할 때
- 캡션, screenshot, transcript가 서로 다를 수 있어 출처별 신뢰도를 분리해야 할 때

## When Not To Use

- 원문의 실제 내용 없이 도구명, 기능, 성능을 소개해야 할 때
- 비공개·권한 제한 콘텐츠를 우회해 수집하려는 경우
- 개인식별정보나 민감한 화면을 동의 없이 보관·공유하려는 경우
