# References

[[tech/ai/https-www-instagram-com-reel-dfjbe2jlnhy/README|README]]의 상태를 재검증할 때 사용할 원문·방법론 출처다. 아래 URL들은 Reel의 주제나 내용을 뒷받침하는 출처가 아니라, 접근 상태·보존·provenance 방법의 근거다.

| 출처 | 용도 |

| https://spec.c2pa.org/specifications/specifications/1.4/index.html | media provenance / Content Credentials 사양 |

재조사할 때는 URL을 다시 열어 결과를 별도 observation으로 기록한다. 이전 실패가 현재의 영구 실패를 의미하지는 않는다.
