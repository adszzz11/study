# References: 출처와 근거의 공백

## 제공 자료

사용자 제공 dossier는 영상의 흐름과 화면 표기를 요약한 2차 자료다. 원본 URL이 없어 영상, 시간대, 수치 문맥을 독립적으로 확인할 수 없다. 특정 모델·논문·저장소로 연결하지 않는다.

## 보조 자료

| 자료 | URL | 사용할 수 있는 범위 |
|---|---|---|
| Apache License 2.0 공식 전문 | https://www.apache.org/licenses/LICENSE-2.0 | 라이선스 문구 확인. 미식별 모델에 실제 적용되는지 증명하지 않음 |

## 추가 확보 목록

- [ ] 원본 영상 URL과 용량·성능·라이선스 언급 시간대
- [ ] 정확한 모델 이름, 버전, 공식 배포 주소와 model card
- [ ] 세 값의 정의, 적용 범위, 학습/변환 방식과 구현 설명
- [ ] 각 용량의 파일 목록, 단위, 설정과 측정 방식
- [ ] 코딩 benchmark의 지표, 입력 조건, 비교 대상과 결과
- [ ] 노트북 사양, runtime, 실행 명령, 측정 로그
- [ ] 배포물의 LICENSE와 가중치·코드별 적용 범위

자료 확보 전에는 수치를 개별 관찰로 남기고, “미확인”을 “실패” 또는 “성공”으로 바꾸지 않는다.
