# Cheatsheet: 결론을 내리기 전 확인할 것

| 질문 | 필요한 확인 | 현재 상태 |
|---|---|---|
| 세 값은 무엇인가? | 정의와 적용 범위 | 미확인 |
| 파라미터가 줄었는가? | 수와 구조 비교 | 미확인 |
| 파일만 작아졌는가? | 동일 모델·파일 구성·설정 | 미확인 |
| 코딩 품질이 유지되는가? | 동일 문제·조건의 실행 평가 | 미확인 |
| 노트북에서 쓸 수 있는가? | 장치·runtime·자원·시간 | 미확인 |
| 문서가 로컬에 머무는가? | 전처리부터 저장까지 데이터 흐름 | 미확인 |
| 가중치를 재현 가능하게 쓸 수 있는가? | 모델 식별·배포물·라이선스·절차 | 미확인 |

## 수치 읽기

- 약 54GB, 약 3.6GB, 5.9GB는 각각 기록한다.
- 같은 모델의 변환 전후 수치 또는 연속 단계로 묶지 않는다.
- 산술 비율을 기술의 검증된 축소율로 보고하지 않는다.

## 빠른 점검

- [ ] 모델과 파일을 식별했는가?
- [ ] 품질과 용량을 분리했는가?
- [ ] 실제 실행 자원과 시간을 측정했는가?
- [ ] 공개 조건과 성능 주장을 구분했는가?
- [ ] 미확인 내용을 결과처럼 쓰지 않았는가?

```text
관찰 → 출처 식별 → 조건 확인 → 실험 → 범위가 명시된 결론
```

이 순서는 검증 절차 제안이며 영상에서 확인된 실행 절차가 아니다.
