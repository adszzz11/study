# AI 모델의 용량 축소와 코딩 성능·로컬 실행 가능성

> AI 모델은 보통 클수록 똑똑합니다. 270억 개 파라미터(27B)짜리 모델이면 원래 16비트 정밀도로 약 54기가바이트(GB)가 필요합니다. 일반 노트북에는 못 들어가는 크기라, 거대 AI는 대부분 데이터센터 서버에서 돌아가고 사용자는 인터넷으로 접속해 쓰는 게 보통이었습니다.
> 
> 그런데 미국 스타트업 PrismML이 2026년 11월 24일 공개한 '터너리 본사이 2.5 27B'는 정반대 길을 보여줍니다. 270억 개 파라미터짜리 거대 모델을 단 5.9GB 파일로 압축했는데, 코딩 도우미 실력은 거의 그대로 유지됐다고 합니다.
> 
> 비결은 3진법(터너리) 압축입니다. AI의 기억 단위인 '가중치'를 마이너스 1, 0, 플러스 1 — 단 세 가지 값으로만 저장하는 방식입니다. 수만 가지 색을 쓰던 그림을 검정·회색·흰색 세 가지로만 다시 그리는 것과 비슷합니다. 색은 줄었지만, 그림이 뭔지는 그대로 알아볼 수 있죠.
> 
> 숫자로 확인해 볼까요? 코딩 실력을 재는 벤치마크 '스웨벤치 베리파이드'에서 75.6점을 받았습니다. 이전 버전은 60.8점, 압축하지 않은 원래 모델(큐원 3.8 27B)은 80.6점입니다. 압축했으면서도 원래 모델과의 격차를 크게 좁힌 셈입니다. 여러 단계의 일을 시키는 '앱월드' 벤치마크에서는 90.5점(이전 51.2점, 원래 모델 93.2점)을 받았고, 이전 버전이 반복에 빠져 0점을 받았던 '딥스웨'에서는 27점으로 올라왔습니다.
> 
> 속도도 빠릅니다. 고성능 서버용 그래픽카드 H100 한 장에서 초당 291토큰, 일반 소비자용 그래픽카드 RTX 4090에서도 초당 204토큰을 만들어 냅니다.
> 
> 다만 현실 조건도 분명합니다. 직접 돌리려면 고성능 그래픽카드가 필요합니다. H100은 서버용, RTX 4090은 고가 소비자용이라 일반 노트북에서 바로 돌리긴 어렵습니다. 대신 맥·아이폰·아이패드에서는 MLX로 돌릴 수 있고, 파일이 5.9GB라 기기에 들어가는 건 맞습니다. 가중치는 아파치 2.0 라이선스로 공개돼 있습니다.
> 
> 왜 중요할까요? 회사 기밀 문서나 개인 파일처럼 클라우드 서버에 올리기 꺼려지는 자료를, 내 컴퓨터 안에서 직접 처리하는 AI를 쓸 수 있는 길이 열렸기 때문입니다. 거대 AI를 내 기기 안에 들여놓는 시대가 조금씩 다가오고 있습니다.
