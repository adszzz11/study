# Cheatsheet: 입력·출력·모델 선택

## 세 축

| 축 | 질문 |
|---|---|
| 입력 | 현재 마이크 음성인가, 기존 파일인가? |
| 출력 | 언제 첫 결과가 필요하고 언제 확정되어야 하는가? |
| 모델 | 동일 조건에서 어떤 크기가 내 기준을 충족하는가? |

## 실험 전

- [ ] Mac·앱·모델 버전과 언어·보조 기능 설정 기록.
- [ ] 같은 파일과 정답 전사문 준비.
- [ ] 허용 오류·첫 출력 지연·결과 대기·자원 기준 결정.
- [ ] 시간 측정 시작·종료 이벤트와 부분 수정 집계 규칙 고정.
- [ ] 모델 로딩·다운로드를 인식 시간과 분리.

## 실험 후

- [ ] 누락·오인식·전문용어·띄어쓰기 오류 분리.
- [ ] 첫 출력과 최종 결과까지의 시간을 각각 기록.
- [ ] 부분 텍스트 수정과 확정 표시 확인.
- [ ] 같은 조건의 반복 결과와 실제 마이크 사용감 확인.
- [ ] 미측정 값과 지원 여부 미확인은 그대로 표시.

## 혼동 방지

- 파일 입력 ≠ 반드시 녹음 후 출력. 마이크 입력 ≠ 반드시 실시간 출력.
- 최초 출력이 빠름 ≠ 전체 처리 완료가 빠름.
- large 선택 가능 ≠ 항상 더 적합. tiny 선택 가능 ≠ 실측상 더 빠름.
- 로컬 음성 처리 설명 ≠ 앱 전체의 완전한 offline 보장.
- 최대 18배·15배 ≠ 재현된 벤치마크 또는 전체 처리 시간 단축률.
- 소개된 기능 ≠ 내부 알고리즘·API·확정 이벤트의 공개.
