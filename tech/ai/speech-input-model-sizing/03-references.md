# References: 자료와 검증 경계

## 제공 자료

| 자료 | 사용 범위 | 추적 가능성 |
|---|---|---|
| 사용자 제공 dossier | Lightning-SimulWhisper 소개 영상 요약, 기능 설명, 평가 원칙 | 원본 URL·게시일·앱 버전 미제공 |

저장소 주소나 공식 문서 URL을 제품명으로 추정해 기재하지 않는다. 이 노트는 원본 영상이나 코드를 직접 검증한 제품 문서가 아니다.

## 주장과 미확인 항목

| 주장·관찰 | 현재 근거 | 추가 확인 대상 |
|---|---|---|
| 무료·오픈소스·Mac 전용 | 수집 자료의 소개 | 공식 배포처·라이선스·지원 OS |
| 마이크·파일 및 tiny~large 선택 | 수집 자료의 화면 설명 | 실제 지원 조합·다운로드 조건 |
| 한국어 및 보조 기능 | 수집 자료의 기능 설명 | 버전별 제공 여부·설정 방법·실제 품질 |
| 로컬 음성 처리 | 영상 설명 | 오디오 전송 여부·네트워크 동작 |
| 최대 18배·15배 가속 | 영상의 성능 주장 | 비교 기준·측정 과정·재현 조건 |

## 도입 전에 확보할 자료

- 원본 영상 URL, 공식 저장소·배포 문서, 앱 및 모델 버전.
- 지원 파일 형식·길이, 모델별 요구 자원, 부분 출력 확정 정책.
- 모델 다운로드·업데이트·진단 정보의 네트워크 정책.
- API·일괄 처리·외부 연동 문서: 자료에 없으므로 지원을 전제하지 않는다.

추가 자료를 확보하면 URL·확인일·버전을 함께 기록하고, 소개 자료의 주장과 직접 측정한 결과를 구분한다.
