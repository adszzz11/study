# 시작하기: 입력과 출력 시점 관찰

## 준비

- Mac, 사용 가능한 Lightning-SimulWhisper 배포본, 짧은 한국어 문장과 그 녹음 파일.
- 앱 설치·모델 획득 방법은 자료에 없다. 공식 배포처와 설치 요건을 확인한 뒤 진행한다.
- 앱·모델 버전, Mac 칩·메모리, 선택 모델, 언어 설정을 기록한다.
- 테스트 문장 예: “오늘 회의에서는 음성 인식 모델의 출력 지연을 비교합니다.”

## 실습

1. 마이크 입력을 선택하고 첫 발화 시점을 기록한다.
2. 첫 텍스트가 보인 시점, 발화 종료 시점, 전체 결과가 준비된 시점을 각각 기록한다.
3. 먼저 출력된 단어나 문장이 이후 바뀌는지 관찰한다. 확정 표시가 없으면 확정 여부는 미확인으로 남긴다.
4. 같은 문장의 녹음 파일을 입력하고 첫 결과와 전체 결과 시점을 별도로 관찰한다.
5. 파일이 재생 중인 것처럼 부분 출력되는지, 끝나고 한 번에 출력되는지 기록한다. 자료에서 보지 못한 동작을 가정하지 않는다.

| 입력 | 출력 방식 | 최초 출력 지연 | 종료 후 결과 대기 | 부분 수정 | 확정 표시 |
|---|---|---|---|---|---|
| 마이크 | 관찰 후 기록 | 측정 | 측정 | 관찰 | 확인 |
| 파일 | 관찰 후 기록 | 측정 | 기준 확인 후 측정 | 관찰 | 확인 |

파일 입력의 시작·종료는 실제 오디오 처리 구간을 알기 어려울 수 있다. 파일 제출·처리 완료 등 관찰 가능한 이벤트를 기록하고 마이크의 발화 기준과 직접 동등 비교하지 않는다.

## 완료 기준

- [ ] 입력 경로와 출력 정책을 따로 설명할 수 있다.
- [ ] 첫 결과와 최종 결과의 시간을 구분했다.
- [ ] 지원되지 않거나 확인할 수 없는 조합은 미확인으로 표시했다.
