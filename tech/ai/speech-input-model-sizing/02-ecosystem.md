# Ecosystem: 방식과 선택지 비교

## 비교 범위

자료에 다른 제품명이 없으므로 경쟁 제품의 기능·성능을 추정하지 않는다. 아래는 자료에 등장한 방식과 선택지의 비교다. 모든 조합의 지원 여부는 별도로 확인해야 한다.

| 비교 축 | 선택지 | 검토할 상황 | 확정할 수 없는 점 |
|---|---|---|---|
| 출력 시점 | 녹음 후 변환 | 녹음 중 텍스트가 필요하지 않음 | 실시간 대비 정확도·총 처리 시간 |
| 출력 시점 | 확실한 부분부터 실시간 출력 | 발화 중 결과 확인 | 실제 지연·수정 빈도·확정 조건 |
| 입력 경로 | 마이크 | 현재 발화 입력 | 소음 품질·장시간 안정성 |
| 입력 경로 | 녹음 파일 | 기존 녹음 전사 | 지원 형식·길이 제한·출력 방식 |
| 모델 크기 | tiny 쪽 | 비교 실험의 시작점 | 빠르거나 자원이 적게 든다는 실측 근거 |
| 모델 크기 | large 쪽 | 동일 입력에서 결과 차이 확인 | 정확도 향상·추가 자원 요구량 |
| 처리 위치 | Mac 내부 | 음성 처리 위치가 중요함 | 전체 네트워크 동작·외부 처리와의 성능 차이 |

## 선택 순서

1. 작업 목적과 허용 오류·대기 시간을 정한다.
2. 실제 입력 경로에서 원하는 출력 정책을 제공하는지 확인한다.
3. 같은 파일·같은 설정에서 모델 크기만 바꾼다.
4. 조건을 충족한 후보를 실제 마이크 사용 환경에서도 확인한다.

마이크+tiny와 파일+large의 결과 차이는 입력과 모델 중 어느 요인 때문인지 분리하기 어렵다. 모델 이름만으로 우승자를 정하지 않는다.
