## 주장별 근거 수준

- **화면 소개 확인**: 파일·출력물·엔터티 그래프, 에이전트, CRM, 대시보드, 조직도.
- **구상 소개**: Claude·Codex 등 여러 클라이언트가 하나의 메모리를 활용.
- **미검증**: 실제 연동, 읽기·쓰기, 갱신 전파, 검색 품질, 작업 인계와 도구 실행 성공.
- **분석적 해석**: 지식·작업·운영의 세 층 모델과 통합형·분리형 설계 비교.

## 후속 수집 체크리스트

- [ ] 원본 영상 URL, 게시자, 게시일, 관련 장면 timestamp 확보
- [ ] 공식 문서의 지원 클라이언트·버전·연동 절차 확보
- [ ] 읽기·쓰기·갱신 전파를 보여주는 재현 가능한 실행 기록 확보
- [ ] 저장·검색·권한·데이터 삭제 정책의 문서 근거 확보
- [ ] 성과 지표 정의와 개별 실행 결과 대조

새 자료를 확보하면 주장별로 URL·확인일·제품 버전·관찰 결과를 붙인다. 현재는 공식 사이트나 문서 주소를 추정하지 않는다.
