# Cheatsheet: 공개 가중치 도입 점검

## 빠른 구분

| 관측 | 곧바로 내릴 수 없는 결론 | 확인할 것 |
|---|---|---|
| 가중치 공개 언급 | 학습 과정 전체 공개 | 코드·데이터·설정 공개 범위 |
| Apache 2.0 언급 | 모든 파일에 같은 조건 적용 | 파일별 적용 범위와 원문 |
| 작은 파일 | 노트북 실행 보장 | runtime·장비·실행 자원 |
| 용량 감소 | 코딩 품질 유지 | 동일 조건 테스트 결과 |
| 로컬 추론 | 시스템 전체 외부 전송 없음 | 입력·추론·저장 경로와 통신 |
| 세 가지 값의 표현 | 특정 quantization 기법 | 값·대상·변환 방법 |

## 수치 해석 주의

- 약 **54GB·3.6GB:** 비교 막대가 등장하나 원본/축소본 관계는 미확인.
- **5.9GB:** 무엇의 크기인지 미확인. 실행 메모리로 단정하지 않는다.
- 세 수치를 동일 모델·동일 조건의 결과로 묶지 않는다.

## 도입 전 체크리스트

- [ ] 모델명·버전·파일·공식 다운로드 위치 확인.
- [ ] 가중치·코드의 라이선스 적용 범위와 원문 확인.
- [ ] 파일 용량과 실행 RAM·VRAM을 별도 기록.
- [ ] 장비·runtime·입력 길이·설정 기록.
- [ ] 동일 코딩 과제의 테스트 결과와 응답 시간 기록.
- [ ] 민감정보 없는 문서로 단계별 처리·저장·통신 확인.
- [ ] 각 결론에 근거와 확인 범위 부착; 미확인은 유지.
