# References: 출처와 증거의 공백

## 현재 자료

제공된 dossier는 영상 요약에 기반한 2차 자료다. 원본 URL이 없어 직접 열람하거나 00:51의 발언 및 화면을 검증하지 못했다. 이 노트의 실습과 프로젝트는 검증 제안이며 영상의 구현 절차가 아니다.

| 주장 또는 표기 | 현재 근거 | 후속 확인 |
|---|---|---|
| Apache 2.0과 가중치 공개 | 제공 요약의 언급 | 원본 영상, 공식 배포 페이지, 파일별 라이선스 |
| 54GB·3.6GB·5.9GB | 요약에 기록된 화면 표기 | 단위의 대상, 동일 모델 여부, 측정 조건 |
| 세 가지 값의 표현 | 요약의 설명 | 실제 값, 적용 대상, 변환법 |
| 코딩 성능 | 성능 저하 여부를 묻는 흐름 | 과제·장비·설정·측정 결과 |
| 회사 문서 로컬 처리 | 로컬/클라우드 대비 | 시스템 구성과 통신 기록 |

## 추가 수집 목록

- [ ] 원본 영상 URL·제목·게시자·게시일과 해당 구간.
- [ ] 공식 모델 식별자·버전·다운로드 URL·파일 목록.
- [ ] 가중치·코드·기타 배포물별 라이선스 원문 및 적용 범위.
- [ ] 실행 문서·runtime 버전·장비·설정.
- [ ] 평가 과제와 결과, 문서 데이터 흐름 증거.

확보한 URL은 해당 주장의 근거와 함께 기록한다. 현재는 실제 URL이 제공되지 않았으므로 추정 링크를 만들지 않는다.

## Sources

- 사용자 제공 dossier: 영상 요약 및 검토 항목. 원본 영상 URL, 제목, 게시자, 게시일은 제공되지 않았다.
- 요약에 제시된 주제 등장 시점: **00:51**. 원본 영상과 직접 대조하지 않았다.
- 출처 URL: **미제공**. 모델 배포 페이지와 Apache 2.0 라이선스 원문 URL도 자료에 없어 기재하지 않는다.
