# 시작하기: 배포물과 실행 조건 식별

## 목표와 전제

공식 배포물과 라이선스가 식별된 뒤 실제 장비에서 검증할 준비를 한다. 현재 자료만으로 실행할 모델이나 설치 명령을 지정할 수 없다. 아래 양식은 실습 제안이다.

## 1. 배포물과 라이선스 연결

| 항목 | 기록할 값 | 현재 상태 |
|---|---|---|
| 모델 | 이름·버전·공식 URL | 미확인 |
| 가중치 | 파일명·형식·다운로드 위치 | 미확인 |
| 라이선스 | 원문 URL·적용 파일·확인한 조건 | 이름만 언급됨 |
| 실행 코드 | 저장소·버전·별도 라이선스 | 미확인 |
| 재현 자료 | 학습 코드·데이터·설정 제공 여부 | 미확인 |

라이선스명 등장과 특정 파일에 적용된다는 증거를 분리한다. 적용 범위가 불명확하면 업무 사용 판단을 유보하고 공식 자료를 추가 확인한다.

## 2. 파일 용량과 실행 자원 구분

- 확보한 파일별 크기를 기록한다. 여러 파일이면 구성과 합계를 함께 남긴다.
- 장비, OS, runtime 버전, 모델 설정, 입력 길이를 기록한다.
- 실행 성공 여부, RAM·VRAM 사용량, 처리 시간을 측정한다.
- 영상의 54GB·3.6GB·5.9GB는 의미 확인 전 기준값으로 사용하지 않는다.

```text
실험 ID:
모델/버전/파일:
파일 크기:
장비/OS/runtime:
실행 설정/입력 길이:
실행 성공 여부:
RAM/VRAM 사용량과 측정 방법:
처리 시간/오류:
근거 파일 또는 로그 위치:
```

## 완료 기준

- [ ] 모델과 배포 파일을 식별했다.
- [ ] 각 파일에 적용되는 라이선스의 근거를 기록했다.
- [ ] 파일 크기와 실행 자원 측정값을 별도로 남겼다.
- [ ] 미확인 항목을 추정값으로 채우지 않았다.
