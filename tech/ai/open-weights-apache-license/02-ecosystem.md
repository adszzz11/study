# Ecosystem: 제품 대신 선택 축 비교하기

## 비교 범위

자료에는 모델·서비스·runtime 이름이 없다. 제품별 순위나 경쟁 구도를 만들지 않고, 자료에서 제시된 선택 축을 비교한다.

| 비교 축 | 선택지 A | 선택지 B | 자료로 가능한 판단 |
|---|---|---|---|
| 처리 위치 | 로컬 처리 | 클라우드 처리 | 회사 문서 처리 방식의 대비가 제시됨 |
| 모델 크기 | 큰 용량의 표현 | 작은 용량의 표현 | 수치의 대응 관계는 불명확 |
| 코딩 품질 | 축소 전 성능 | 축소 후 성능 | 성능 저하 여부가 질문으로 등장; 결론 미확인 |
| 실행 환경 | 노트북 | 다른 환경 | 노트북 실행 가능성이 질문으로 제시됨 |
| 사용 조건 | Apache 2.0 언급 배포 | 다른 라이선스 배포 | 다른 라이선스와의 비교 자료 없음 |

## 판단에 필요한 추가 증거

- 로컬/클라우드: 문서 입력부터 결과 저장까지의 처리 위치와 외부 통신 기록.
- 크기/자원: 정확한 배포 파일의 용량과 실제 실행 중 RAM·VRAM 사용량.
- 품질: 동일 과제·설정·장비에서의 테스트 통과율과 응답 시간.
- 사용 조건: 각 배포물에 적용되는 라이선스 원문과 관련 파일.

작은 파일이라는 사실은 사용 권한이나 업무 품질을 결정하지 않는다. 로컬과 클라우드의 비용·속도·보안 우열도 이 자료로 확정할 수 없다.
