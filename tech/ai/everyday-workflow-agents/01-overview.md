# Overview: What / Why / 특징

## What

AI agent에 요청·역할·목표를 부여해 예약, 조사, 작성, 알림을 수행하거나 지속하도록 구성하는 방식이다. 비교의 중심은 답변 표현력보다 **언제 시작하고, 어떤 단위로 나누며, 사용자 부재 중 어떻게 이어가는가**에 있다.

## Why

| 업무 수요 | 자료에서 관찰된 예 |
|---|---|
| 작업 지속 | Dots: ChatGPT 안에서 사용자 부재 중 작업 지속 |
| 생활 업무 처리 | Muse: 예약·쇼핑·양식 작성·알림·장기 목표 |
| 조직 업무 분담 | Grok Bot: 리서치·영업·마케팅·운영 담당 AI 동료 |
| 요청 접점 단순화 | OpenClaw: 채팅 요청과 백그라운드 서비스 |
| 역할과 환경 구성 | Hermes: 역할·모델·메모리, SkillTree: 부서별 agent·여러 모델 |

## 핵심 특징과 분석 틀

다음은 내부 구현 설명이 아닌, 영상의 기능과 화면을 해석하기 위한 틀이다.

1. **Execution:** Dots의 작업 지속과 OpenClaw의 백그라운드 처리는 매 순간 지시하지 않는 방향을 보여준다. 실행 주기·queue·retry·복구가 같다는 근거는 없다.
2. **Task / Goal:** Task는 입력·산출물·완료 조건을 구체화할 작업, Goal은 여러 작업과 확인 시점으로 관리할 목표다. Muse가 목표 자동 분해나 의존성 관리를 지원한다는 뜻은 아니다.
3. **Role:** Grok Bot은 업무 영역별 담당을, Hermes는 연구자·작성자·검토자라는 산출 과정의 역할을 보여준다. 자동 인계·병렬 실행·독립 검토는 미확인이다.
4. **Configuration:** Hermes의 모델·메모리 설정과 SkillTree의 Claude·GPT·Gemini 통합 공간이 관찰된다. 저장 기간·공유 범위·자동 모델 선택·상호 검증까지 보장하지 않는다.
