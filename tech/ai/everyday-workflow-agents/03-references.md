## 현재 근거

| 자료 | 사용 범위 | 추적성 한계 |
|---|---|---|
| 사용자 제공 dossier | 여섯 도구의 구성, 비교 기준, 실습 제안 | 원본 영상·제품 URL·제목·게시일 없음 |

이 노트 묶음은 dossier를 재구성한 학습 자료이며 제품을 직접 사용해 검증한 리뷰가 아니다. Dots, Muse, Grok Bot, OpenClaw, Hermes, SkillTree라는 이름만으로 공식 사이트나 특정 제품 버전을 확정하지 않는다.

## 주장 구분

- **관찰:** 화면·소개에 등장한 역할, 모델, 업무 범위.
- **해석:** Task / Goal, 업무 영역별 역할과 과정별 역할의 차이.
- **실습 제안:** 상태 전이, 작업 식별자, 평가표. 실제 제품 기능으로 간주하지 않는다.
- **미확인:** backend·API·저장소·배포·가격·개인정보 보호·성능 수치.

## 후속 출처 수집 양식

```text
제품명 / 공식 제품 식별:
원문 URL / 영상 timestamp:
문서 제목 / 게시일 / 확인일:
관찰한 기능 / 적용 버전:
문서상 설명과 직접 실험 결과의 구분:
가격·권한·저장·삭제 정책 근거:
```

원본을 확보하면 주장별 URL과 해당 구간을 기록한다. URL을 확보하지 못한 항목은 미확인으로 유지한다.
