# Ecosystem: 작업 방식으로 비교하기

## 비교표

동일 기능의 직접 경쟁 제품 순위가 아니라 서로 다른 업무 방식의 대안으로 비교한다.

| 도구 | 자료에서 확인되는 구성 | 적합성을 검토할 업무 | 미확인 사항 |
|---|---|---|---|
| Dots | ChatGPT 안에서 사용자 부재 중 작업 지속 | 자리를 비운 동안 이어갈 작업 | 지속 시간·완료 알림·복구 |
| Muse | 예약·쇼핑·양식 작성·알림·장기 목표 | 생활 업무·개인 작업 관리 | 외부 연동·실행 승인 |
| Grok Bot | 리서치·영업·마케팅·운영 AI 동료 | 업무 영역별 담당 구성 | 역할 간 협업·결과 공유 |
| OpenClaw | 백그라운드 서비스·채팅 요청 처리 | 채팅을 통한 요청 접수 | 배포 환경·운영 부담·처리 보장 |
| Hermes | 연구자·작성자·검토자, 모델·메모리 설정 | 조사·초안·검토 절차 | 역할 순서·메모리 동작 |
| SkillTree | 부서별 agent, Claude·GPT·Gemini 작업 공간 | 여러 agent·모델을 함께 사용 | 모델 라우팅·권한·비용 |

## 선택 순서

1. **업무 범위:** 생활 업무, 조직 업무, 산출물 제작 중 무엇인가?
2. **실행 방식:** 대화 중 처리인가, 부재 중 지속할 작업인가?
3. **역할 구성:** 업무 영역별 담당과 과정별 역할 중 무엇이 필요한가?
4. **설정·운영 요구:** 모델·메모리·작업 공간을 어떻게 검증할 것인가?

## 도입 전 미결 항목

영상은 cloud·open-source 구분, 가격, 개인정보 보호, 강점을 선택 기준으로 제시하지만 제품별 값은 제공되지 않았다.

| 확인할 항목 | 확보할 근거 |
|---|---|
| 제품 식별·배포 | 공식 URL, 버전, cloud/open-source 구분 |
| 비용 | 요금표, 실행량·모델별 과금 조건 |
| 개인정보 보호 | 저장·삭제·공유 정책, 서비스 권한 범위 |
| 실행 신뢰도 | 같은 입력으로 측정한 완료율·시간·실패 기록 |
| 실행 승인 | 예약·구매·외부 변경 전에 확인하는 절차 |

이 항목을 채우기 전에는 구매 추천이나 성능 순위를 만들지 않는다.
