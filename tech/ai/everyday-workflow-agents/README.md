# 일상 업무 자동화와 작업 관리를 위한 AI agent 비교

> **한 줄 정의**: 일상 업무 자동화와 작업 관리는 AI agent에 요청·역할·목표를 부여해 예약, 조사, 작성, 알림 등의 작업을 수행하거나 지속하도록 구성하는 방식이다.

## Overview

AI 활용은 질문에 답하는 방식에서 업무를 맡아 처리하는 방식으로 확장되고 있다. 이 노트는 Dots, Muse, Grok Bot, OpenClaw, Hermes, SkillTree를 **업무 범위와 작업 방식의 적합성**으로 비교한다.

- **Interaction:** ChatGPT 내부 작업, 채팅 요청, 통합 작업 공간.
- **Execution:** 사용자 부재 중 작업 지속, 백그라운드 처리.
- **Organization:** 업무별 agent, 연구·작성·검토 역할.
- **Configuration:** 모델·메모리 설정, Claude·GPT·Gemini 통합 공간.
- **검증 범위:** 내부 backend·API·저장소·배포·가격·개인정보 보호 세부 사항은 확인되지 않았다.

완료율·소요 시간·실패 사례가 없어 생산성이나 신뢰도 순위를 매길 수 없다. 관찰된 구성과 학습용 설계를 구분해서 읽는다.

## When To Use

- 예약·알림·조사 등 반복 업무를 agent에 맡길 수 있는지 검토할 때.
- 비동기 작업의 완료 조건과 사용자 확인 시점을 설계할 때.
- 업무 담당 역할과 조사·작성·검토 절차를 구분해 구성할 때.

## When Not To Use

- 가격·보안·개인정보 보호를 검증한 구매 추천이 필요할 때.
- 설치 명령이나 서비스별 연동 방법을 바로 실행하려 할 때.
- 실제 성능 측정 없이 완전 자동 실행이나 완료 보장을 기대할 때.
