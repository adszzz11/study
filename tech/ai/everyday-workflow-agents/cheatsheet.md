# Cheatsheet

## 선택 흐름

```text
업무 범위 → 실행 방식 → 역할 구성 → 설정·운영 요구
                                      ↓
                       가격·개인정보 보호 별도 확인
```

| 필요한 방식 | 살펴볼 도구 | 우선 검증 |
|---|---|---|
| 사용자 부재 중 지속 | Dots | 지속 시간·완료 알림·복구 |
| 생활 업무·장기 목표 | Muse | 연동 범위·실행 승인 |
| 업무 영역별 담당 | Grok Bot | 협업·결과 공유 |
| 채팅 요청·백그라운드 | OpenClaw | 배포·운영·처리 보장 |
| 연구·작성·검토 | Hermes | 역할 순서·메모리 |
| 여러 agent·모델 작업 공간 | SkillTree | 라우팅·권한·비용 |

## 요청 템플릿

```text
작업 ID / 요청:
입력 / 누락 정보:
기대 산출물 / 완료 조건:
기한 / 다음 확인 시점:
사용자 확인이 필요한 시점:
현재 상태 / 결과 위치 / 실패 원인:
```

## 평가 체크리스트

- [ ] Task의 완료 조건과 Goal의 중간 확인 시점을 구분했다.
- [ ] requested / running / needs_input / completed / failed를 구분했다.
- [ ] 역할별 입력·산출물과 인계 내용을 남겼다.
- [ ] 반복 선호와 작업 한정 정보를 구분했다.
- [ ] 누락·추가 질문·근거 없는 주장·수정량을 기록했다.
- [ ] 설정 화면의 존재와 실제 동작 검증을 구분했다.

상태명과 템플릿은 학습용 설계이며 제품 명령어가 아니다. 성능 순위, cloud/open-source 분류, 가격, 개인정보 보호 수준은 제공 자료로 확정할 수 없다.
