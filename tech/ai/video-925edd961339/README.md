# Oracle Always Free 서버로 앱과 자동화 도구를 운영하는 활용법

> **영상 요약**: 영상은 밤새 켜 둘 서버를 마련하는 방법으로 Oracle의 Always Free를 소개하며, 메모리 12GB와 코어 2개라는 사양을 제시한다. 화면의 문서 발췌는 Always Free 자원이 계정 유지 기간 동안 정해진 범위에서 무료라고 설명한다. 활용 예시로 터미널에서 Docker를 연습하고, Coolify로 앱과 대학 프로젝트를 배포하는 화면을 보여 준다. 이어 Twenty를 활용한 고객 관리와 n8n을 통한 문의 자동 응답 흐름을 제시한다. 마지막에는 웹앱에 접속할 수 없는 화면과 80·443 포트 표시, 설정 가이드의 ports 항목을 보여 주며 접속 설정을 다룬다.
