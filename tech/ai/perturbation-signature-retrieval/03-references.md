# References와 근거 상태

## 제공 자료

| 자료 | 확인 범위 | 미확인 |
|---|---|---|
| 사용자 제공 dossier | 영상 00:47에 해당 주제의 논문 제목이 등장했다는 설명 | 영상 URL·정식 논문명·저자·연도·DOI |
| Dossier의 설계·실습 제안 | 검색 계약, 참조 흐름, 평가 관점 | 원 논문에서 실제 채택했는지 여부 |

현재 외부 원문을 직접 검토하지 않았다. 인용 가능한 URL이 없으므로 논문 링크나 서지정보를 추정해 만들지 않는다.

## 원문 확보 후 확인할 항목

- [ ] 영상 URL과 00:47의 정확한 제목·표기 확인.
- [ ] 논문 공식 페이지·DOI·저자·버전 확인.
- [ ] perturbation 종류, signature modality, cell-level의 의미 확인.
- [ ] query·candidate·relevance 및 target annotation 출처 확인.
- [ ] 데이터 분할, baseline, 지표, 성능과 불확실성 확인.
- [ ] 코드·데이터 공개 여부와 이용 조건 확인.

각 사실에는 원문 위치를 기록하고, 해석과 실습 제안은 분리한다. 원문 확보 전에는 논문 재현이나 효능 판단을 진행할 수 없다.
