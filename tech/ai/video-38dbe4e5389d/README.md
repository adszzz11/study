# 핵심 기능 점검부터 보안까지, QA 테스트 12종 소개

> **영상 요약**: 영상은 12가지 QA 테스트를 카드 형태의 인포그래픽으로 소개한다. Smoke testing은 새 빌드의 핵심 기능을 빠르게 확인하고, regression testing은 변경 후 기존 기능을 다시 점검하는 방식으로 설명한다. Exploratory testing은 시나리오 없이 사용하며 버그를 찾고, acceptance testing은 고객이나 기획 기준에 따라 출시 준비 여부를 확인한다. Alpha/Beta testing의 내부 참여자와 실제 사용자 역할을 구분하고, performance testing에서는 응답 속도 측정을 보여준다. 이어 기기·브라우저 간 호환성, 혼란 없는 사용 흐름, 스크린 리더·큰 글자 지원, 권한 우회·정보 유출 점검을 소개하며, 마지막에는 sanity와 load testing을 포함한 전체 12종을 한 화면에 제시한다.
