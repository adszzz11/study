# 여섯 AI agent의 작업 방식과 활용 영역 비교

> **영상 요약**: 영상은 Dots, Muse, Grok Bot, OpenClaw, Hermes, SkillTree를 소개하며 각 도구의 작업 방식과 활용 영역을 비교한다. Dots는 ChatGPT 안에서 사용자가 자리를 비운 동안에도 이어지는 작업을, Muse는 예약·쇼핑·양식 작성·알림·장기 목표 같은 일상 업무를 위한 도구로 제시된다. Grok Bot은 리서치·영업·마케팅·운영 역할을 맡은 AI 동료들로, OpenClaw는 백그라운드 서비스와 채팅을 통한 요청 처리 방식으로 소개된다. Hermes 화면에는 연구자·작성자·검토자 역할과 모델·메모리 설정이 등장하며, SkillTree는 여러 부서의 agent와 Claude·GPT·Gemini를 한 작업 공간에 모으는 구성을 보여준다. 마지막에는 용도별 선택 기준과 cloud·open-source 구분을 제시하고, 가격·개인정보 보호·강점을 비교 항목으로 보여주지만 세부 값은 제공된 관찰만으로 확인할 수 없다.
