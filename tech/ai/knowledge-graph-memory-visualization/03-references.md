# References: 자료와 근거의 범위

## 출처 대장

| 자료 | 상태 | 사용할 수 있는 근거 | 제한 |
|---|---|---|---|
| 사용자 제공 dossier | 현재 노트의 직접 입력 | 영상 요약에 기술된 화면과 구상 | 원본 URL·시점·게시자 미제공 |
| Orbit Agents 홍보 영상 | 요약으로만 접근 | 제품이 강조하는 방향 | 원본 대조·실행 검증 불가 |
| Obsidian 공식 사이트·Help | 보조 URL | 후속 학습 진입점 | Orbit Agents 주장·제품 우열의 증거 아님 |

## 읽을 때 적용할 분류

1. **화면 관찰:** 그래프, CRM, 대시보드, 조직도가 요약에 등장한다.
2. **제품 구상:** Claude·Codex 등이 하나의 메모리에 연결된다.
3. **미검증:** 실제 연동, 검색, 갱신 전파, 권한, 작업 실행 및 성과.
4. **학습 제안:** 이 노트의 schema·실험·프로젝트는 독립적인 설계 연습이다.

## 후속 확인 목록

- [ ] 원본 영상 URL, 게시자, 게시일, 관련 타임스탬프 확보.
- [ ] 공식 제품 문서에서 연결 인터페이스와 접근 조건 확인.
- [ ] 읽기·쓰기·충돌·권한 동작을 실행 기록으로 확인.
- [ ] 기능 주장별 근거와 확인 날짜를 별도로 기록.

URL이 없는 원자료에 임의의 제품 링크를 배정하지 않는다. 공식 자료를 확보하기 전에는 구현 세부사항을 제품 기능으로 기술하지 않는다.
