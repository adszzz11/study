# Ecosystem: 비교와 판단 한계

## 비교 범위

dossier에서 비교 제품으로 이름이 제시된 대상은 Obsidian뿐이다. 아래 공유 메모리와 운영 화면은 별도의 경쟁 제품이 아니라 접근 방식과 화면 구성이다.

| 대상·접근 | 자료에서의 위치 | 메모리 시각화 관점 | 판단 한계 |
|---|---|---|---|
| Orbit Agents | 소개 대상 | 파일·출력물·엔터티 그래프와 운영 화면을 함께 강조 | 실제 연동·실행 미검증 |
| Obsidian | 영상의 비교 대상 | 노트·메모리 도구와의 비교 맥락 | 구체적 항목과 우열 근거 없음 |
| 여러 AI 클라이언트의 공유 메모리 | 제품이 제시하는 구상 | 하나의 메모리에 클라이언트를 연결 | 연결 방식·호환 범위 미확인 |
| CRM·대시보드·조직도 | 등장하는 운영 화면 | 업무·성과·배치 구조 표현 | 그래프와의 데이터 연결 미확인 |

## 판단할 수 있는 것

제품이 강조하는 범위는 단순 노트 시각화보다 넓으며 정보 관계와 에이전트 운영을 함께 다루려는 방향이다.

## 판단할 수 없는 것

- Obsidian 대비 기능 우위나 대체 가능성.
- 메모리 정확도, 검색 품질, 실행 신뢰도.
- 운영 비용, 확장성, 실제 성과 개선.

## 비교 실험 제안

동일한 소규모 자료와 질문을 준비하고, 근거 파일을 찾는 성공 여부·소요 시간·잘못 해석한 관계를 기록한다. 도구 접근 조건을 확인한 뒤 수행할 실험이며 본 자료에 결과는 없다. 단순 탐색 실험을 에이전트 메모리 품질 전체로 일반화하지 않는다.
