# Atticus projects

## 1. Annual report verification workspace

재무제표, ESG 서술, CEO letter를 부서별 evidence와 연결하고 board-ready report를 만든다.

- 산출물: verification matrix, owner map, exception report
- 완료 기준: material claim에 owner·evidence·review status가 있고 미해결 exception에 disposition이 있다.

## 2. Prospectus due-diligence room

law firm, issuer, auditor가 statement별 책임과 근거를 공동 관리한다.

- 산출물: role model, privileged-document handling rule, approval log
- 주의: 외부 참여자 권한과 source document 접근 범위를 최소화한다.

## 3. Sustainability disclosure assurance

ESG metric과 narrative claim에 data owner, 계산 근거, approval history를 연결한다.

- 산출물: metric lineage와 assurance-ready evidence pack
- 점검: reporting boundary, methodology, period가 narrative와 일치하는지 확인한다.

## 4. Glide pilot evaluation

과거 검증 완료 문서를 gold set으로 삼아 annotation/evidence suggestion 품질과 검토 시간 절감률을 측정한다. KPI 정의는 [[tech/ai/atticus-document-verification/04-learning/02-deep-dive|Deep Dive]]를 따른다.

## 5. Disclosure-control integration

Workiva 같은 작성·보고 시스템과 Atticus verification process를 분리하되, release gate에서는 verification completeness를 확인한다. 역할 경계는 [[tech/ai/atticus-document-verification/02-ecosystem|Ecosystem]]을 참고한다.
