# Getting Started

## 목표

Reel을 기술 학습의 출발점으로 바꾸기 전에 최소 증거 세트를 확보한다.

## 절차

1. 원본 화면에서 계정명, 캡션, 해시태그, 제품 UI를 각각 캡처한다.
2. 들리는 제품명과 화면 텍스트를 분리해 전사한다. 자동 자막은 오인식 가능성을 표시한다.
3. 후보 제품의 공식 도메인과 문서를 찾고, Reel의 claim과 일치하는지 확인한다.
4. 다음 표를 채운 뒤에만 제품별 노트를 작성한다.

| 필드 | 예시 형식 |
| --- | --- |
| 제품명 | 공식 표기 |
| claim | 영상의 문장 또는 화면 문구 |
| task | 입력 → 처리 → 출력 |
| evidence | URL / 캡처 / 타임스탬프 |
| open question | 아직 검증하지 못한 점 |

## 완료 기준

- 제품명이 공식 출처로 확인됨
- claim 하나 이상이 입력·출력 조건과 함께 기록됨
