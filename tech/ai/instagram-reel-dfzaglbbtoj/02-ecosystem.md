# Ecosystem Comparison

기술명이 확인되기 전에는 특정 AI tool과의 비교를 만들지 않는다. 대신 식별 후 사용할 비교 프레임을 준비한다.

| 비교 축 | 확인할 질문 | 필요한 근거 |
| --- | --- | --- |
| 작업 유형 | 생성, 검색, 코딩, 자동화 중 무엇인가? | 캡션·UI·공식 제품 페이지 |
| 입력·출력 | 어떤 파일·프롬프트를 받고 무엇을 반환하는가? | 재현 가능한 예시 |
| 실행 환경 | Web, desktop, API, local 중 어디서 동작하는가? | 공식 문서 |
| 비용·제한 | 무료 한도, 과금 단위, 데이터 제한은? | 가격·정책 페이지 |
| 대안 | 같은 job-to-be-done을 수행하는 도구는? | 요구사항 기반 평가 |

Reel의 시연만으로는 이 표의 어느 칸도 확정할 수 없다. 증거가 생기면 [[tech/ai/instagram-reel-dfzaglbbtoj/04-learning/02-deep-dive|Deep Dive]]의 검증 절차를 적용한다.
