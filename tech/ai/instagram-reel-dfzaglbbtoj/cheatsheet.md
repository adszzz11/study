# Cheatsheet

## 빠른 기록 양식

```markdown
- Reel URL:
- 확인 날짜:
- 제품명 (공식 표기):
- 영상 claim (원문):
- 입력 → 출력:
- 증거: URL / 캡처 / 타임스탬프
- 재현 결과:
- 제한·위험:
- 다음 확인 항목:
```

## 판정 규칙

| 상황 | 기록 방식 |
| --- | --- |
| 제품명이 화면에만 보임 | `추정`으로 표시하고 공식 출처로 확인 |
| 캡션이 보이지 않음 | claim을 만들지 않고 `미확인` 기록 |
| 결과만 보임 | 입력·버전·후편집을 open question으로 남김 |
| 공식 문서와 다름 | Reel과 공식 문서를 별도 claim으로 기록 |

현재 대상의 상태는 **미식별**이다. 상세 증거는 [[tech/ai/instagram-reel-dfzaglbbtoj/03-references|References]]에서 확인한다.
