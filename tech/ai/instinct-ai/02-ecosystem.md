# Instinct AI: Ecosystem

## Comparison

| 제품 | 주된 interaction | 강점 | Instinct와의 차이 |
|---|---|---|---|
| Instinct | Text/call + 앱·기기 연결 | 생활 행정용 persistent personal context와 agentic action | 공개 API/MCP·모델·connector catalog 정보가 제한적이며, 개인정보·권한 관리가 핵심 리스크 |
| [ChatGPT agent](https://openai.com/index/introducing-chatgpt-agent/) | ChatGPT task 요청 | visual browser, text browser, terminal, connectors/API를 결합한 research-to-action | Instinct는 personal secretary와 messaging UX를 더 전면에 둔다 |
| [Gemini Spark](https://gemini.google/re/overview/agent/spark/) | Gemini/Google Workspace | Gmail·Calendar·Docs·Sheets·Slides 등 Google ecosystem 중심의 proactive agent | Google-native productivity task에는 Spark가 자연스럽고, Instinct는 cross-app personal assistant 지향 |
| [Claude Cowork](https://claude.com/product/cowork) | Claude desktop/web/mobile task | 파일·문서·browser 기반 knowledge-work 및 multi-step execution | Cowork는 작업 공간/산출물 중심, Instinct는 생활 업무와 전화·메시지 기반 delegation 중심 |
| [Meta Muse](https://ai.meta.com/muse/) | Muse app/WhatsApp | 메시지 기반 개인 agent, connected app 및 web action | interaction 철학은 가깝지만 접근성·지원 지역·연결 서비스는 별도 확인이 필요 |

## Selection Lens

| 질문 | Instinct에 유리한 경우 | 다른 선택지를 먼저 볼 경우 |
|---|---|---|
| Interface | 문자/통화로 assistant를 쓰고 싶다 | browser/terminal의 명시적 작업 환경이 필요하다 |
| Context | 일상적인 개인 맥락과 생활 task가 핵심이다 | 팀 문서·code·파일 산출물이 중심이다 |
| Ecosystem | cross-app 개인 assistant 가능성을 탐색한다 | Google Workspace만으로 task가 끝난다 |
| Governance | 승인·권한·삭제 절차를 직접 설계한다 | enterprise control plane이나 공개 integration 정보를 우선한다 |

비교는 제품 철학과 공개 설명을 기준으로 한 학습용 정리다. 기능 지원 지역, plan, connector availability는 사용 직전에 각 공식 사이트에서 다시 확인한다.
