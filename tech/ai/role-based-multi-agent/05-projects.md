# Projects: 작은 실험에서 적용까지

## 프로젝트 후보

모두 자료의 역할 구성을 응용한 제안이다. 특정 제품의 지원 기능을 의미하지 않는다.

| 프로젝트 | 역할 구성 | 산출물 | 주의점 |
|---|---|---|---|
| 근거 제한형 리서치 dossier | Researcher → Writer → Reviewer | 주장·근거 연결 문서 | 검토자도 원자료 접근 |
| 부서별 업무 브리프 | 리서치·영업·마케팅·운영 | 역할별 의견과 통합안 | 충돌 시 결정 주체 지정 |
| 다중 모델 비교 | 같은 역할의 모델 교체 | 산출물·평가 기록 | 역할과 모델 변화 효과 분리 |
| 지속 작업 단계별 점검 | 실행 담당·검토 담당 | 중간 결과·미해결 목록·완료 보고 | 지속성과 협업 품질 별도 검증 |

## 추천 첫 프로젝트: 근거 제한형 dossier

1. 제공 dossier를 고정 입력으로 사용한다.
2. 근거 장부, 초안, 검토 기록, 최종본을 각각 만든다.
3. single-agent로도 같은 길이·형식·필수 항목의 문서를 만든다.
4. 같은 기준으로 근거 없는 주장, 누락, 수정 횟수와 시간을 기록한다.
5. 역할 분리가 도움이 된 지점과 추가 전달 부담을 함께 적는다.

**완료 기준 예시:** 필수 항목 충족, 근거 없는 확정 주장 0개, 미확인 사항 유지, 사람 승인, 두 방식의 비교 기록 작성. 반복 한도 안에 완료하지 못한 경우도 결과로 남긴다.

입력과 산출물이 명확한 작은 프로젝트에서 정보 손실과 과장을 먼저 관찰한 뒤 부서별 병렬 작업이나 다중 모델로 확장한다.
