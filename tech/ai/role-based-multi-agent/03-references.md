# References: 근거와 미확인 사항

## 현재 근거

이 노트 묶음의 근거는 사용자 제공 dossier다. dossier는 영상 요약의 관찰을 전달하지만 원본 URL·제목·제작자·게시일은 포함하지 않는다. 따라서 제품 식별과 최신 기능 검증에는 한계가 있다.

| 구분 | 내용 | 노트에서의 처리 |
|---|---|---|
| 자료상 관찰 | Grok Bot 역할, Hermes 역할·설정, SkillTree 작업 공간 | 제공 자료 기준으로 한정 |
| 설계적 해석 | 책임 분리가 판단 기준을 명확히 함 | 성능 개선 주장과 구분 |
| 실습 제안 | 근거 장부, 순차 handoff, 승인·반복 제한 | 특정 제품의 구현으로 기술하지 않음 |
| 미확인 | 메시지 전달, 자동 위임, 공유 메모리, orchestration | 미상으로 유지 |
| 미제공 | API, 가격, 개인정보 보호, 성능 측정값 | 우열·지원 여부 판단 보류 |

## 후속 조사 체크리스트

- [ ] 원본 영상 URL과 해당 장면의 timestamp 확보.
- [ ] 동명 제품을 구분할 공식 제품명·운영 주체·URL 확인.
- [ ] 역할 배정과 handoff를 실제 실행으로 관찰.
- [ ] 메모리의 개인·공유 범위, 저장 기간, 접근 권한 확인.
- [ ] 실패·재작업·종료·사람 승인 절차 확인.
- [ ] 가격·API·배포·데이터 처리 문서의 확인 날짜 기록.
- [ ] 같은 자료·목표로 single-agent와 역할 분리 결과 측정.

## 기록 형식

```text
제품 / 공식 URL / 확인 날짜 / 문서 또는 영상 위치
관찰한 사실 / 뒷받침하는 문장 또는 장면
확인하지 못한 사항 / 설계 제안과의 차이
```

확인하지 않은 URL을 출처로 추가하지 않는다. 후속 조사에서 확보한 사실은 기존 설계 제안과 분리해 기록한다.
