# Ecosystem: 구성과 선택 기준

## 비교 범위

제공된 영상 요약의 포지셔닝을 비교한다. 성능 순위나 특정 기능의 부재를 의미하지 않는다. 제품 식별 정보와 공식 URL이 없어 실제 도입 전 원본 확인이 필요하다.

| 도구 | 자료에서 확인되는 구성·용도 | 역할 협업과의 관계 | 선택 전 확인 |
|---|---|---|---|
| Dots | ChatGPT 안에서 사용자 부재 중에도 이어지는 작업 | 지속 실행 관점 | 역할 분담, 전달, 완료 보고 |
| Muse | 예약·쇼핑·양식 작성·알림·장기 목표 | 일상 업무 범위의 대안 | 업무 연결, 사람의 승인 시점 |
| Grok Bot | 리서치·영업·마케팅·운영 AI 동료 | 기능별 역할 사례 | 정보 전달, 결과 통합 |
| OpenClaw | 백그라운드 서비스, 채팅 요청 처리 | 실행 환경·인터페이스 관점 | 내부 agent 구성, orchestration |
| Hermes | 연구자·작성자·검토자, 모델·메모리 설정 | 단계별 역할 사례 | 실행 순서, 메모리 범위, 재작업 |
| SkillTree | 여러 부서 agent와 Claude·GPT·Gemini 작업 공간 | 조직·다중 모델 구성 | 공통 상태, 모델별 권한, 작업 연결 |

영상의 비교 항목에는 cloud·open-source, 가격, 개인정보 보호, 강점도 등장한다. 제품별 세부 값이 제공되지 않아 배포 유형이나 비용·보안 우열을 판단할 수 없다. API와 실제 성능도 미확인이다.

## 선택 순서

1. 단계별 품질 관리인지, 부서별 업무 분담인지 문제를 정한다.
2. 역할별 산출물과 통합 책임자를 정한다.
3. 장시간 실행·채팅 접근성·예약을 별도 요구사항으로 확인한다.
4. 권한·메모리 범위·가격·배포 조건을 공식 자료와 실험으로 확인한다.
5. 같은 입력의 single-agent 기준선과 비교한 뒤 확대한다.

agent 수나 모델 종류가 많다는 사실만으로 더 적합하다고 판단하지 않는다.
