# Projects

## 1. Design-aware landing-page agent

“dark editorial fintech”를 `search_sites`로 탐색하고, 사람이 2–5개를 선별한다. `create_design_brief`를 React/Tailwind 구현의 input으로 쓰고, 최종적으로 local build의 band map을 reference와 비교한다.

**완료 기준**: hierarchy, rhythm, contrast 원칙을 설명할 수 있고 원본 asset·copy는 사용하지 않는다.

## 2. Creative QA pipeline

reference와 staging URL을 capture해 section height, background 전환, scroll 구조의 regression을 찾는다. viewport와 load condition을 고정하고, visual delta는 reviewer가 판정한다.

## 3. Motion research library

`get_motion_dna`와 filmstrip으로 GSAP, Three.js, scroll interaction의 pattern을 inspiration note로 축적한다. 구현에서는 easing·duration·trigger 같은 원리를 재해석하고, source media를 복제하지 않는다.

## 4. Design-system discovery

여러 수상작에서 CTA/footer/hero element를 찾고 component token 후보를 만든다. 예를 들어 spacing scale, contrast tier, button prominence를 관찰한다. 브랜드 고유 layout이나 illustration을 design-system token으로 일반화하지 않는다.
