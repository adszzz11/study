# Instagram Reel 리서치 참고자료

| 자료 | 용도 |
|---|---|
| [제공 Reel](https://www.instagram.com/reel/DfLt9CrCLxN/) | 조사 대상 permalink |
| [Instagram Graph API](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api) | API 범위·인증·권한 확인 |
| [IG User Media](https://developers.facebook.com/docs/instagram-platform/instagram-graph-api/reference/ig-user/media) | media endpoint와 소유 계정 범위 확인 |
| [Instagram oEmbed](https://developers.facebook.com/docs/instagram/oembed) | embed 제공 조건 확인 |
| [Meta Content Library](https://transparency.meta.com/researchtools/meta-content-library/) | 연구 목적 접근 도구의 별도 조건 확인 |
| [Instagram Terms of Use](https://help.instagram.com/581066165581870/) | 서비스 이용·수집 관련 정책 확인 |
| [Instagram Help Center](https://help.instagram.com/) | 공개성·계정·콘텐츠 접근 관련 도움말 |

공식 문서는 API 또는 embed의 가능 범위를 설명하지만, 특정 Reel의 실제 내용이 현재 접근 가능하다는 증거는 아니다. 대상별 관찰 결과는 [[tech/scraping/instagram-reel-research/04-learning/01-getting-started|조사 기록]]에 남긴다.
